# 𝓛𝓾𝓬𝓮𝓷𝓽

### 現代 · 極簡 · 泰然自若的深藏不露

**一款筆記與任務管理應用，其內建助理能切實觸及你的資料——封存於你自己設備上的加密資料庫之中，通曉十四種語言，且在 GitHub 上只需按下單一按鈕即可從第一行構建至最後一行。它同時推出口袋版與桌面版——Android APK 與 Windows 安裝程式——共享同一顆心跳，整裝待發以探索更廣闊的天地。**

## 核心構想

市面上絕大多數筆記應用，都慷慨地邀請你在三種優點中任選其二：美觀、隱私或聰慧。選好你的一對，便只能對剩下的一項付之闕如、無奈妥協。Lucent 則委婉地謝絕了這場交易。你落筆的一切皆封存於絕不離開設備的加密資料庫中。助理可以是付費訂閱的雲端模型、直接運行於眼前這臺設備上的本地模型，或者乾脆付之闕如。而且整套工程完全無需任何一行本地構建工具：在 GitHub 上按一下按鈕，自去漫步，回來時便有一份 APK 或 Windows 安裝程式安然等候。

## 一款應用，隨遇而安

Lucent 是一件擁有單一共享心臟的產品：本舍鐵律要求每一項功能皆須進駐所發布的每一個平臺。你的口袋與桌面說著完全相同的語言：

- **`:app`** —— Android 應用（Kotlin 與 Jetpack Compose、基於 SQLCipher 的 Room、透過 NDK 調用的 llama.cpp）。由 `.github/workflows/build.yml` 構建為已簽名的正式發布版 APK。
- **`:desktop`** —— 桌面端應用，現已支援 Windows（Compose for Desktop、純 JVM、基於 JDBC 的 SQLite、編譯為 DLL 的 llama.cpp）。由 `.github/workflows/build-windows.yml` 構建為連按兩下即可安裝的 `.exe` 安裝程式。
- **`:shared`** —— 兩個平臺共同編譯的單一原始碼樹：業務邏輯、資料層、大部分介面，以及一份涵蓋十四種語言的翻譯目錄。修改一處，兩臺設備同步變更。

凡可共享者皆安居於 `shared/`；極少數無法共享之物——`SettingsRepository`、`Daos`/`Db`、`DocumentExport` 以及若干最大的螢幕介面——因其接縫過深，仍按平臺各留一份。原生構建階段皆各自獨立可選，因此某一環節受挫時，留在你手邊的是一款完好的可用應用，而非一間無盡的候診室。

## 有手——而非只有意見——的助理

此乃界定 Lucent 靈魂的功能。自帶模型——流暢支援 OpenAI、Anthropic 與 Google 的請求結構，可保留多份設定檔並一鍵切換——亦或直接在設備上本機運行全套流程。若隻字不提，助理便安靜隱去；筆記應用本身毫髮無損。

使其真正值得青睞之處，在於它具備*行動力*：建立、讀取、編輯、標色、釘選、歸檔及刪除筆記；建立、完成、重新開啟、排程與設定任務優先級；使用真正的篩選語言進行搜尋；以及附加、重新命名或移除檔案。在它動手改動任何內容之前，它會以你的母語向你精確展示其意圖——在一只本身即為編輯器的對話方塊中，任何尚存爭議的欄位皆可在寫入任何一個位元組之前進行編輯。你的話語永遠是一錘定音的終審裁決。空有意見而無雙手者不過是場清談聊天；這則是一位懂得先敲門的管家。

對話可隨你心意無限綿延並與你隨行，而你上次逗留的那場對話，便是再次開啟時映入眼簾之處。回覆以工整規範的 Markdown 呈現——標題、清單、程式碼——模型的思考推理過程摺疊收納於上方，待你需要時再行展開；追蹤歷程中每次工具呼叫各佔一行，並標註所耗費的時間。對話上方陳列著四個面板：助理工作時維護的待辦清單、其所依循的規劃、已啟動的後臺任務，以及所召喚的子代理，每一項皆可即時觀摩、隨時終止或追加指示。交付予它一個目標，它便會一輪接一輪地全力推進，直至大功告成、主動暫停，或坦誠回報受阻為止。

## 助理身後的工坊

筆記與任務是迎賓的前廳。在它們背後，只需撥動 Settings → Advanced → Toolkit 中的開關，便是一間獲准助理踏足的工坊。它擁有一個由你親自挑選的工作區資料夾——檔案選取器可瀏覽整部設備，而非僅限於共享儲存空間——其間備齊了真正的工具：讀取、寫入、搜尋、透過 diff 進行編輯、建立快照以及版本回滾。它能執行帶有逾時設定與工作目錄的指令，將耗時漫長的指令保持為後臺任務，並向你展示執行輸出。它能建立並編輯 Word、Excel 與 PowerPoint 檔案——這些格式完全由 Lucent 原生寫入，底層未依賴任何 Office 函式庫——並能讀取 PDF、將其算繪為圖片、分割與合併。它能藉由 Git 進行 clone、diff、commit 與 push，提出與檢視 GitHub issue、pull request 及 CI 日誌，擷取並閱讀網頁，查詢 SQLite，並在設備所能提供的環境下，於 Docker、PRoot 或純粹的 shell 中運行工作。

它透過三種維度銘記於心：這場對話、這個專案，以及你本人。它維護著一份隨時可供你檢視的規劃，將各項技能銘刻成文以告別對你個人慣例的反覆摸索，並能在任務繁重足以立案時召喚子代理。子代理、快照、設備控制與螢幕存取共處於一個專屬頁面：Toolkit，接著是 Assistant abilities。

任何體積龐然之物皆被摒除於安裝程式之外：Linux 使用者空間環境、附帶各類文件函式庫的 Python、LibreOffice、Node.js、瀏覽器引擎、OCR 與多媒體工具皆被列為外掛模組，唯有經你要求，方從專案官方伺服器或高速鏡像站下載，端看何者率先回應。安裝外掛需要 shell——手機端為 Lucent 內建的 Linux 環境，Windows 端則為 winget——且 Lucent 凡事三思而後行：在下載任何內容前皆會先行審視外掛，以便在耗費頻寬之前、而非之後，精準指出缺失的 shell、無法寫入的下載目錄，或是沉寂無聲的鏡像站。當下載或安裝失敗時，Lucent 會彈出對話方塊指明緣由，展示 shell 的原始輸出並列出補救之道。進行中的下載只需輕觸按鈕即可中止，且中止之後雁過無痕、片瓦不留。各項權限各居其位，共闢專頁——讀取、寫入、刪除、命令執行、網路、Git、GitHub、網頁瀏覽、工作區以外的空間，以及設備本體——每一項皆可設定為允許、詢問或封鎖，且每次工具呼叫皆會記錄於活動日誌中，供你隨時檢閱與清空。

在手機上，同一個工坊更延伸至設備本體：讀取螢幕、點擊、鍵入、滑動、擷取螢幕畫面、列出並開啟應用程式、讀取通知、存取剪貼簿與手電筒，並在內建的 Linux 環境中運行實打實的命令列工具。它亦通曉 MCP，因此任何與之對接的伺服器皆能化為工具包的一員。

## 記得自己前世的筆記

每一次有意義的編輯都會留存快照，讓你隨時得以重睹筆記過往的字句，並在某次信心十足的重寫最終被證實不過是一場盲目樂觀時，將其完好復原。鍵入 `[[購物清單]]` 它便化作可點擊的連結；指向一個尚不存在的標題，連結便會泛起紅光示警，直至你優雅一擊，將該筆記應聲喚生。Markdown 在你需要時流暢算繪，不需要時則精準保持原樣素顏。核取清單是頭等公民：原地重修項目措辭，當隨手記下的小項目驟然萌生宏圖大志時，更可開啟寬敞的彈出式編輯器。標籤、色彩、釘選、逐一單獨加密的附件、富文本、為言辭所不能及的思緒預留的塗鴉畫布，以及附帶專屬門鎖的私密空間——草稿箱亦靜臥於垃圾桶身旁，讓未竟之思永遠不至淪為棄子。

空白筆記提供四款一鍵啟動的預設模版——日記、會議、專案構想、清單——隨後才是真正見真章的妙筆：屬於你自己的自訂範本。保存一份範本，往後每一頁空白頁皆會向你含笑致意；長按即可編輯或除役其中任何一份，內建模版亦不例外。

## 真正言之有物的截止日期

子任務、優先級、重複排程，以及在重啟後依然屹立不搖的提醒。截止日期直接由日常語言中解析——*下週五傍晚6點*化作一枚切實的時間戳記與一聲貨真價實的鬧鈴——重複節奏是不折不扣的頭等公民，而非一句最終落得食言投降的精巧話術。完成一項任務，會連同其底下的整套清單一併勾銷，已完成的任務則優雅除役至專屬頁面，各得其所。

## 亦或直接在設備本機運行全套流程

匯入 `.gguf` 檔案（或內含該檔案的 `.zip`），助理便會透過直接運行於設備之上的 llama.cpp 進行應答——無需帳號、無需 API 金鑰、無需連網，且在你退出版應用的瞬間立即卸載模型。約 1–4 GB 的 Q4 模型在手機上恰如其分、臻於化境；桌面端則大可承載更宏大的野心。本機工具採用自選開啟，GPU 加速則是在明確警告後方供決擇：CPU 始終穩健如初，而意見不合的 GPU 亦能優雅回退。視覺能力同樣可供選用——匯入 mmproj 檔案，助理便會端詳照片，並以一位略帶先知通靈氣質的圖書館員口吻與你暢談探討。

## 四種語言，流轉自如無須拘禮

English、中文、日本語、한국어——覆蓋每一個畫面、對話方塊、日期格式與範本。切換語言，整套應用在同一影格內全盤隨之流轉，因為自始至終只有一份目錄，且為介面讀取的唯一來源：每個詞彙只存錄一次，此乃架構設計之必然，而非細心呵護之偶得。

## 它的容貌：坦蕩磊落，淬於琉璃

一抹流動的漸層在毛玻璃面板後方悠然漂移，將其下方掠過的一切溫柔模糊，幾乎從不重複，且其開銷皆經設備預先首肯。橫跨八大風格系列的豐盛調色盤，輔以自動循環或隨機漫步的伴隨功能，在其間從容穿行。淺色、深色、跟隨系統，以及一系列 Monet 莫內色調的主題——在 Android 12 或更高版本上，調色盤更會借取你當日桌布的色彩精髓。小工具（Widgets）將同樣晶瑩剔透的玻璃質感延伸至你的啟動器；在 Windows 上，應用則悄然隱入系統匣，並由側邊欄取代底部標籤列——因為一幅寬螢幕理應享有比將手機佈局橫向拉伸更為尊崇的禮遇。

## 真正管用的鎖，以及與你同行的備份

應用程式鎖是一套真刀真槍的防暴力破解策略，而非一句客套的請求：層層遞增的冷卻時間、重啟後依然存續的持久計數器、可選的安全提問、可選的自毀機制，以及在整個冷卻期內彬彬有禮地暫停告退的指紋辨識（Android）或 Windows Hello（Windows）。資料庫在靜態下全面加密，附件個別獨立加密；備份則是一個可用密碼保護的 `.lcb` 檔案，攜帶著筆記、任務、歷史、聊天記錄、附件與設定跨設備遷徙——在改動任何一項之前皆先行預覽，並可武裝就緒自動運行。一份無人能讀的備份只配稱作紀念品而非備份，因此這份備份在匯出出門時被讀取檢視，在匯入進門時亦再次接受覆核。

## 根植於結構之中的隱私，而非空口承諾

在你親自將其匯出、或給予模型充足理由去查閱之前，絕無任何資料會擅離設備。分享面板整合功能預設關閉；診斷資訊預設關閉並僅留存本機；你所連接的助理服務完全取決於你的自決；雲端鏡像同步則是一個由你透過 WebDAV 自行配置的模組。對加密唯一刻意為之的例外——匯出為 Markdown、Word、PDF 或 Excel——正是一份能讓你在任何其他地方隨意開啟的檔案，而這恰恰是其存在的真諦。

## Rust，但只在它名副其實之處大顯身手

兩處高負載熱門路徑以 Rust 撰寫並透過 JNI 呼叫——坐鎮於備份與附件加密背後的 PBKDF2 及 AES-256-GCM 常式，以及流動背景背後的數學演算法。當原生程式庫缺席時，兩者皆會優雅回退至完全相同的 Kotlin 實作，因此應用絕不會淪為編譯器脾氣的人質。

## 構建它（沒錯，穿著睡袍在手機上就能辦到）

無需 Android Studio，無需本地 SDK，無需命令列。推送到 GitHub，打開 **Actions**，運行你心儀的工作流程，接著下載產出物——一份經過嚴謹簽名的正式版本，或是一個連按兩下即可安裝的安裝程式。工作流程直接安居於儲存庫之中，因此配方就在盒子裡，而非留在作者的腦海深處；構建過程如同原始碼本身一般，任君檢閱審查。

## 專案結構

```
shared/       唯一的單一共享原始碼樹——業務邏輯與大部分 UI 在此僅此一份，且
              :app 與 :desktop 皆編譯它。在此編輯一個檔案，兩平臺同步變更。
app/          Android 模組 (:app)——Activity 外殼、Room 資料庫層、JNI 橋接、桌面小工具，
              以及其他真正專屬於 Android 的程式碼
desktop/      桌面端模組 (:desktop)——Compose for Desktop 外殼、android.* 的 JVM 墊片、
              JDBC 資料庫核心、針對引擎 DLL 的原生 CMake 構建
rust/         Rust 加速器（跨平臺共享）
.github/      build.yml (Android APK)、build-windows.yml (Windows 安裝程式)、check.yml
```

## 它下一步要去哪

Lucent 相較於一張待辦清單而言未免過於龐大，而它從未為此道過半句歉。具有記憶的筆記、具備鋒芒獠牙的任務、有雙手亦懂規矩禮節的助理、信守承諾的加密，以及一面值得駐足凝思的外觀表面。帶走它體驗一週，觀察你注意到了什麼；相伴一個月，你會發現自己已不再刻意留意。

### 以及我們效仿的駕馭框架

Lucent 的助理遵循 **DeepSeek Harness** (dsh) 以及 **[DSHA](https://github.com/DSH-APP/DSHA)**（遵循 MIT 授權條款）的工具語彙與工作慣例——後者乃是在無 root 且無 Termux 的手機上實現該套駕馭框架的 Android 專案。Lucent 兩者皆未打包：工具、迴圈、面板與目標推進皆為原創的 Kotlin 程式碼，旨在再現這兩者所確立的行為模式。結束代碼（exit code）作為執行結果而非錯誤呈現、檔案在寫入前必先經讀取、目標擁有專屬的推進輪次、輔助代理可供對話與中止，且任何存有疑義之處皆必先詢問請示。模式歸功於他們，並在此致敬銘謝；程式碼則出自我們之手。
