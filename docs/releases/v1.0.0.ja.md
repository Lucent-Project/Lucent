# 初光——記憶を持つノートと、ノックする執事

Lucent は、静かに時代遅れな三つの確信から始まる。あなたが書いたものはあなた以外の誰のものでもないということ。助手は物事について意見を持つだけでなく、実際に何かをできるべきだということ。これほど実用的なソフトウェアには、醜いという言い訳がないということ。そこから生まれるのは、記憶と錠、そして入る前にノックする執事を備えたノートとタスクのアプリである。ポケットサイズとデスクサイズの二つが、ひとつの心臓から届く。

**ノートとタスクは履歴を保つ。** 意味のある編集はすべてスナップショットとして残るので、先週の火曜日にそのノートが何と言っていたかを読み、書き直しが楽観的すぎたと分かったときに元に戻せる。`[[Shopping list]]` と入力すれば、それはタップできるリンクになる。まだ存在しないタイトルを指せば、リンクは赤く光り、タップひとつでそのタイトルが生まれる。Markdown は望めば描画され、望まなければ打ったとおりのまま残る。チェックリストは正真正銘の市民である。項目はその場で書き換えられ、ゆとりのあるポップアウトエディタが開き、加算記号を忘れたせいで失われるものは何もない。タグ、色、ピン留め、添付。タスクにはサブタスク、優先度、繰り返しの予定、そして再起動を生き延びるリマインダーが付き、期限は日常の言葉から解析される——*来週の金曜日の 6 時*は、本物の時刻と本物のアラームになる。

**助手には手があり、意見だけではない。** 自分のモデルを持ち込んでもよく、モデルをひとつも動かさなくてもよい。Lucent の助手はノートとタスクを作成し、読み、編集し、色を変え、ピン留めし、アーカイブし、削除できる。何かを変える前に、自分が何をするつもりかを正確に告げ、あなたの返事を待つ。意見はあるが手がないものは、チャットである。これはノックする執事であり、自分の予定ではなくあなたの指示に従って働く。手を伸ばす道具はごく普通のもの——タイトル、タグ、色、期限——なので、平易な言葉での頼みは、目に見え、読み返せ、取り消せる変更になる。

**すべては封印され、しかもなかなか美しい。** データベースは保存時に暗号化され、添付ファイルは個別に暗号化され、アプリロックは丁寧なお願いではなく本物の総当たり対策を課す。バックアップは単一の持ち運べるファイルとして旅をし、戻す道でひとつの項目も変わる前に全体がプレビューされる。だから復元は飛躍ではなく、ひとつの決定になる。ガラスの向こうでは、柔らかな色が曇りガラスのパネルの背後で揺れる。豊富なテーマとパレットが設えを引き受け、四つの言語が儀式なしに切り替わる——ラベルも日付もすべて。この静けさは後から足した飾りではない。暗号化と同じ判断から生まれている。

ひとつの製品、二つのサイズ。署名済みの Android APK と Windows インストーラーは、GitHub でボタンをひとつ押し、やかんを火にかけに行くあいだに端から端まで出来上がる。業務ロジック、データ、そしてインターフェースの大半は一度だけ存在し、各プラットフォームは本当に自分に属する継ぎ目だけを足す。記憶を持つノート、歯のあるタスク、礼儀をわきまえた助手、約束を守る暗号化。
