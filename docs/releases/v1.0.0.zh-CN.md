# 初光：有记忆的笔记，和一位会敲门的管家

Lucent 始于三个安静而不合时宜的信念：你写下的东西只属于你自己；助手应当能做事，而不只是对事情抱有自己的看法；如此实用的软件，没有理由长得难看。接下来是这样一款笔记与任务应用：它有记忆，有锁，还有一位进门前先敲门的管家——口袋与桌面两种尺码，出自同一颗心脏。

**笔记与任务都留有历史。** 每一次有意义的编辑都会留下快照，于是你可以读到某条笔记上周二说了什么，并在重写显得过于乐观时把它恢复。输入 `[[Shopping list]]`，它就会变成可以点开的链接；指向一个尚不存在的标题，链接会泛红，直到轻点一下把它变出来。Markdown 在你想要时渲染，不想要时原样留着你敲下的字。清单是堂堂正正的公民：就地改写条目，打开宽敞的浮出编辑器，不会因为忘了那个加号而丢掉什么。标签、颜色、置顶、附件。任务带着子任务、优先级、重复日程，以及能挺过重启的提醒，截止日期则从日常语言里解析出来——*下周五 6 点*会变成一个真正的时刻，连同真正的闹钟。

**助手有手，而不只有看法。** 自带模型，或者一个模型也不跑。Lucent 的助手能创建、读取、编辑、上色、置顶、归档和删除笔记与任务；在改动任何东西之前，它会说清自己打算做什么，然后等你的答复。一个有看法却没有手的东西，只是一场聊天。这是一位会敲门的管家，它按你的吩咐行事，而不是按自己的日程。它伸手去拿的都是些寻常工具——标题、标签、颜色、截止日期——于是一句平常话里的请求，最后变成一处你看得见、读得回、也撤得掉的改动。

**一切都封存起来，而且相当好看。** 数据库静态加密，附件逐一加密，应用锁执行的是真正的暴力破解对策，而不是发出一句礼貌的请求。备份以单个可携带文件的形式出行，在回程中任何一项改变之前先完整预览，于是恢复是一次决定，而不是一跃。玻璃之后，柔和的颜色在磨砂面板背后流动；丰盛的主题与配色负责装饰；四种语言无需仪式即可切换，每一个标签与日期都在其中。这份平静不是事后添上的装饰；它与加密出自同样的决定。

一个产品，两种尺码：一个签名的 Android APK 和一个 Windows 安装程序，从头到尾都由在 GitHub 上按下一个按钮、然后去烧水泡茶完成。业务逻辑、数据与大部分界面只存在一份，各平台只补上真正属于自己的接缝。有记忆的笔记，有牙齿的任务，有礼数的助手，守得住承诺的加密。
