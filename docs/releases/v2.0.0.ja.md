# 第二の視力——助手は見ることを覚える

助手はいまや写真を見て、それについて語り合える。打つのではなく話したいときには、聞きもする。そのまわりで、書くための面には太字と斜体、落書きのキャンバス、保存されたビューが加わった。パレットには八つの背景ファミリーにまたがる三十二のテーマが加わり、すべての確認には編集欄が加わった。そのすべてが Android と Windows に同じ日に届く。心臓はまだ一つしかないからだ。

**助手は見ることを覚えた。** 手元のモデルの隣に mmproj ファイルを読み込めば、助手は——いまもすべてをあなた自身のハードウェアの上で動かし、いまもインターネットには何一つ告げずに——写真をよく眺め、少しだけ千里眼の効いた司書のようにそれについて語る。マイクはいま、ノート、タスク、チャットの中に控えている。Android では設定が一切要らず、Windows はすでに設定済みの文字起こしサービスを静かに借りる。素早いモデル切り替えが両方のプラットフォームに座り、小さなモデルと無料枠のためには Caveman Mode がある。これは賢い内部プロンプトをわきに置き、ただモデルに語らせる。

**書くことが豊かになった。** 太字、斜体、そしてその仲間たち。書き出したファイルも書式をそのまま保つ。言葉の手が届かない考えのための落書きキャンバス。下書きはゴミ箱の隣で行儀よく座り、消えるのではなく待っている。ノートは自分だけの錠の後ろに隠れられる。打ち続けている検索は、それ自体の保存されたビューとして残せる。だから「期限切れで重要」は打ち直す一言ではなく、訪れる場所になる。まさに約束どおりである。これらのどれも、あなたの仕事を置いた場所に置いたままにする。新しい面は古い面を置き換えるのではなく、その上に重ねられる。

**この場所の佇まいが大人になった。** 三十二のテーマ、八つの様式ファミリーの背景、そして気の向くままにその間を歩く Random の伴。漂う塊は画面のフレームクロックを借りず、自分のスレッドで壁時計の鼓動を守る。だから界面がどれほど忙しくても、フレームが戻った瞬間に彼らはちょうどいるべき場所にいる。ガラス、グラデーション、色彩は一緒に届き、そのどれも注目を求めない。自分の時間を守る背景は、そのとき機械がほかに何をしていようと、位置を外したところを決して見つけられない背景である。

**家事は良くなり、確認は一人前になった。** ノートでもタスクでも会話でも、きちんとしたファイルとして共有できる。あるいは自動バックアップを予定どおりに刻ませておける。同じ暗号化された持ち運びやすい形式が、端末を越え、プラットフォームを越える。変更を加える提案はどれも、それ自体が編集欄である対話の中に届く。議論の余地のある項目はすべて埋められ、編集もでき、そのうえで書き込みが起きる。だから「いや、やはりやめておく」に費用はかからず、何も残らない。対話は変更を考え直せる最後の場所であり、このリリースはそこを、断るのに心地よい場所にした。共有はひと押しで、出来上がるファイルは、二度見せずに送り出せるほどきちんとしている。

あなたがそうと言うまで、データベースには何も届かない。前もって見せずに持ち運び可能な形で外へ出るものも何もない。下書き、個別の錠、保存された検索、書き出しは、どれもこの基準を満たす。同じ四つの言語が、到来のたびに名を呼んで迎える。そして最初の視力は、新しい視力の後ろにいまもあり、静かな仕事を続けている。
