# 第二视力：助手学会了看

助手如今能看一张照片，并就它聊上几句，也能在你更愿意说而不是打的时候听着。在这之外，书写界面添了粗体与斜体、一块涂鸦画布与保存好的视图；调色板添了三十二套主题，分属八个背景家族；每一次确认都添了一个编辑器。这一切在同一天落到 Android 与 Windows 上，因为心脏仍然只有一颗。

**助手学会了看。** 在本地模型旁边导入一个 mmproj 文件，助手——仍然完全跑在你自己的硬件上，仍然对互联网只字不提——就会细看一张照片，像一个多少有点通灵的图书管理员那样跟你谈论它。麦克风如今候在笔记、任务与聊天里：在 Android 上它不需要任何设置，Windows 则悄悄借用你已经配置好的转写服务。一个快速的模型切换器待在两个平台上，而对小模型与免费额度，还有 Caveman Mode，它把那些聪明的内部提示词搁到一边，干脆让模型自己说。

**书写变得更丰盛了。** 粗体、斜体，以及它们的伙伴，导出的文件会把这些格式完整留住。一块涂鸦画布，给文字够不着的念头。草稿彬彬有礼地待在回收站旁边，是在等着，而不是没了。一条笔记可以藏在自己的独立锁后面。一个你反复输入的搜索可以留成它自己的已保存视图，于是「逾期且重要」成了你会去的地方，而不是你要重新打一遍的句子，正如当初所承诺的那样。这些当中的每一项都让你的活儿留在你放下的地方，新的界面是铺在旧的之上，而不是取代旧的。

**这个地方的模样长大了。** 三十二套主题、八个风格家族的背景，还有一个 Random 同伴，按自己的时刻表在其中漫步。那些漂浮的光斑在自己的线程上守着墙钟的心跳，而不是借用屏幕的帧时钟，所以界面无论多忙，当帧率恢复的那一刻，它们都恰好在它们该在的地方。玻璃、渐变与色彩一起到来，而它们没有一个在讨要关注。一块守着自己时间的背景，是一块你怎么也抓不到它错位的背景，无论当时机器还在忙些什么。

**家务有了改善，确认也长大成人了。** 把任何一条笔记、一件任务或一段对话分享成一个整整齐齐的文件，或者让自动备份按着计划一格一格走下去；同一种加密的、便于携带的格式跨过设备，也跨过平台。每一项会改动东西的提议都抵达一个本身就是编辑器的对话框，每个可争辩的字段都填好了，也都可以改，然后才写下任何东西，于是「其实，不用了」不花什么代价，也不留下任何东西。对话框是一件改动可以被重新考虑的最后地方，而这次发布让这里成了一个舒服的说不的地方。分享是一次轻点，得到的文件整齐到不必再看第二眼就能发出去。

在你开口之前，没有任何东西会抵达数据库；也没有任何东西会不经预览就便携地离开。草稿、独立锁、已保存的搜索与导出都符合这个标准。同样的四种语言按名字迎接每一次到来，而第一视力仍然在那新的后面，做着自己安静的事。
