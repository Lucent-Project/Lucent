# 礼儀、記憶、そしてより静かな手

執事はより良い礼儀と、より長い記憶を身につけた。操り手は持ち場を守り、会話は自分のファイルを手放さず、そのノック——ノートやタスクに触れる前に、これから何をするつもりかを正確に見せる確認——はどの道筋でも、両方のプラットフォームでも聞こえるようになり、そのぶん界面の小さな作法は短くなった。これは、気づかないことによって気づく類のリリースである。

**助手の操り手は持ち場を守る。** どのボタンも一押し目に応える。どのパネルも同じ整列に落ち着く。テーマが何であれ、その前にどの画面があったとしても変わらない。助手の画面、対話、チップ、行は一つの振る舞いに収まり、Lucent の操作は、ソフトウェアと交渉することではなくソフトウェアを操作することになる。この磨きは、ある画面と次の画面のあいだの時間にも及ぶ。良い仕事はそこで、見られるのではなく感じられる。ただ自分の務めを果たすボタンが、そこでの野心のすべてである。華はない。正確であり、執事とはまさにそういうもののためにいる。目指すのは、自分勝手な意見を持たない表面であり、前回手を伸ばしてから動いていない操り手である。

**会話は自分のものを手放さない。** メッセージは、それが触れたファイルを連れて歩く。どの道筋でも、両方のプラットフォームでも同じだ。問いとともに届いた添付は答えのそばに残り、その記録は電話でも机の上でも同じに読める。取り消しは清い。動作を止めた場所に、書きかけのものが放置されることはなく、戻ってくる状態は去ったときの状態であり、ファイルも元の場所にある。戻るボタンへの当てのない一押しに任されるものは何もない。取り消しの但し書きは短い。動作は止まり、状態は待つ。会話は、明日も同じ会話であると信じられる。どちらの機械の上でも。

**どの動作もノックから始まる。** 確認の流れは、執事のノックが必ず聞こえ、許可証と取り違えられないところまで広げられ、鍛えられた。提案は実行の前に必ず示され、争いの余地のある項目はまずあなたの検分に供される。同意とは、あなたが与えるものであって、ソフトウェアが勝手に前提にするものではない。バックアップは約束したものを運ぶから、あなたが本当に惜しむ材料こそ最も丁寧に保たれる。同じ丁寧さが、勤めの一日を満たす小さな対話やチップや行にも流れている。執事は面白い必要がない。そこにいて、正しい必要がある。あなたに求めるのは、その決定そのもののほかには何もない。

その下では、共有された心臓が両プラットフォームの歩調を合わせている。一つのソースツリー、業務ロジックと画面は、電話のためにも机のためにも一度だけコンパイルされる。変更履歴は車の整備記録のように読める。より清く、より落ち着き、製造元の仕様どおりに締められている。その結果が気づかれずに終わることは、執事にとって得られる最高の褒め言葉である。そこに二度見を要する箇所は一つもない。
