# 礼节、记性，与更稳的一只手

管家学会了更好的礼节，记性也更长了。它的控件守着自己的位置，它的对话留着自己的文件，而它那声敲门——在碰到一条笔记或一件任务之前，先如实说明自己打算做什么的那次确认——如今在每一条路径上、两个平台上都听得见，界面上那些小小的仪式也因此短了些。这是那种你主要靠没注意到它来注意到的版本。

**助手的控件守着自己的位置。** 每一个按钮都在第一次按下时就回应。每一块面板都归到同一条对齐线上，无论用的是哪套主题，无论前一个屏幕是什么。助手的各个屏幕、对话框、标签与行都落进同一种举止里，于是操作 Lucent 像是在操作软件，而不是在跟它交涉。这份打磨一直伸进一个屏幕与下一个屏幕之间的那些时刻——好活儿在那里是被感觉到，而不是被看到的——在那里，一个只是把自己的事做好的按钮就是全部的野心。它不风光，它精确，而这正是管家该管的事。目标是一层没有自己主张的表面，是一个自从你上次伸手去够之后就不再挪动的控件。

**对话留住了属于自己的东西。** 消息带着它提到过的文件一起走，走每条路径，在两个平台上都一样：跟着一个问题到来的附件会留在它的答案身边，同一段记录在手机上和在桌面电脑上读起来一样。取消是干净的。你在哪里叫停一个动作，那里就不会留下写了一半的东西摊着，你回到的状态就是你离开时的状态，文件还在原处。没有什么被寄望于在返回键上的侥幸一按。取消这件事的细则很短：动作停下，状态等着。一段对话可以让人放心，明天还是同一段对话，在哪一台机器上都是。

**每一个动作都从一声敲门开始。** 确认流程被一路延长、加固，直到管家的敲门声总是听得见，也从不会被误认成一张通行证。每一项提议都在被执行之前先摆出来，值得争一争的字段先交给你过目，于是同意是你给出的东西，而不是软件替你假设的东西。备份带上了它们承诺的东西，于是你真正会为之哀悼的材料，正是被保管得最仔细的材料，而同一份仔细贯穿了填满整个工作日的那些小对话框、标签与行。管家不需要有趣；它需要在那儿，而且需要是对的。除了那个决定本身，它对你一无所求。

在底下，那颗共有的心脏让两个平台步调一致：一棵源码树，业务逻辑与屏幕只为手机和桌面电脑编译一次。更新日志读起来像一份汽车保养记录——更干净、更平稳，紧到厂商规格上去。结果不被人注意到，对管家来说，这是能得到的最高恭维。它没有任何一处需要再看第二眼。
