# The Butler Tidies the House

Housekeeping beneath the floorboards, done properly, so the house stands straighter. Android and Windows now draw their shared logic from one source tree, the installer is watched over by a build that reads the weather before it panics, and both platforms report one version number. There is nothing new here to discover and rather more to rely on, which is the shape a patch release ought to have. The floorboards are solid. This is the first release built on that foundation.

**One heart now serves two platforms.** Seventy-eight shared source files — the business logic and most of the interface — live once in a single module that both the Android app and the Windows installer compile. An edit there is an edit on both platforms in the same commit, so the two cannot drift apart; agreement is a property of the build rather than a habit of the maintainer. The platform seams stay where they belong, in their own trees: Room against JDBC, the JNI and DLL native bridges, the Android shims, the Activity and Desktop shells. Each platform keeps only what is genuinely its own, and everything else is compiled from the same page.

**The build reads the weather.** On 2 September 2026 all three artifact repositories — Google Maven, Maven Central and the Gradle Plugin Portal — were unreachable from the Windows runner for roughly thirteen minutes. The warm-up step now classifies each outcome from its own log text: network and repository markers earn up to six attempts with escalating backoff, totalling well beyond any outage observed, while a genuine build problem is reported at once rather than buried under retries. A pipeline that knows when to wait and when to stop. The retry policy is documented in the workflow itself, so the reasoning travels with the code that acts on it.

**The numbers agree, and the installs settle.** Both platforms report the same user-facing version, and the desktop package version rises with it, so a Windows installation upgrades in place rather than standing beside its successor. The version is stamped in one place and read on two machines, so neither platform can quietly fall behind, and the installer recognises the copy it is replacing. The workflow that produces the APK and the installer lives in the repository itself, naming the cause precisely when a build needs attention. Anyone who wants to know how the release was made can follow it step by step. The recipe stays in the box, where anyone who needs it can read it.

A launch that behaves the same on both platforms; a feature added to one arriving on the other in the same breath; nothing left for you to keep an eye on. The butler has tidied the house with the lights off, and everything is where it will be in the morning. That is the whole of the promise, and it is kept.
