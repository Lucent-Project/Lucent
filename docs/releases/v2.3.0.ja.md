# 9月に行われた春の大掃除

このリリースは新奇の集合ではなく、基準の集合だ。16の項目、4つの新しいMonetテーマ、126の背景色を、AndroidビルドとWindowsインストーラへ同じ回に当てる。Lucentは2台のマシンの上をひとつの心で走り、掃除とはその設計が配当を払う瞬間である——100の小さな面が、ひとつの午後にひとつの基準へと連れて行かれる。それをすべきでない月などない。

**プライベートな領域は、訪ねていく場所だ。** 隠された領域に置かれたノートは、求めに応じてその詳細ページを開き、隠しリストはそれをグリッドの中の角の丸い四角いカードとして、同じ家を分け合う隠しタスクの隣に示す。クエリの層はノートとタスクをまったく同じ条件で受け入れるので、プライベートな領域は扉のある部屋のように振る舞う。入り、読み、出てくる。隠されたノートと、それを読むことの間に立つものは何もない。履歴のページは全体がトークンで色づけられているので、復元された版はその周りのすべてと同じパレットに座る。

**リストは自分の行をきれいに返す。** 項目を取り除き、その取り除きを元に戻すのは、ふたつの仕草の喜びであり、アニメーションもその一部だ。削除のあと、リストは自分の行を礼儀正しく落ち着かせるので、自らの消滅を確かめるボトムシートは、画面と別れ話をしているようには見えない。古いノートの版を復元すると、それが置き換えた状態はその瞬間の時刻印を持つ新しい履歴の項目として記録される。復元がインターフェースから来ようと、アシスタント自身のツールから来ようと同じだ。スクロール端の操作子はひとつの場所にあるひとつの円盤で、その矢印はこれから連れて行く方向へ向きを変える。

**期限切れの区分は完了を祝う。** 終わったタスクは終わったタスクであり、タスクの世界は走る世界に同意する。期限切れの項目に印をつければ、その場で期限切れの区分から消える。サブリクエストも含めてだ。チャットも同じ基準を守る。「もう一度尋ねる」は小さく右下に、あなたのバブルの外に座る。会話のヘッダーは余分な会話ボタンを携えない。添付はファイル名の行として現れ、そのひとつひとつがタップで、作法なしにビューアで開く。設定は小規模モデルの最適化をMemoryの下の自らのカードに保ち、モデルのドロップダウンは名前で曖昧に検索するので、半分しか覚えていない識別子で足りる。

**両方のプラットフォームが一緒に掃除された。** チェックボックスも、スクロール位置も、トーストも、AndroidとWindowsで同じ意味を持つ。ロック画面は試行回数を伴う総当たりのはしご、適応するエラーの色合い、任意の自己破壊を走らせ、ロックアウトの文言は4つの言語を話す。Crash Shieldは有効にされていれば起動の際に自らを導入する。取られたバックアップは自らの成功か失敗を報告し、落書きの書き出しはノートの印をつけたキャンバスをひとつの複数ページPDFにまとめる。4つの新しいMonetテーマがパレットに加わり、126の背景色に重複はない。背景のドリフトは自らの30 fpsのガバナーを守るので、ページの切り替えはフレームを損なわない。

その結果は、よい片づけの感覚だ。ひとつの物を指させるわけではないが、部屋は広くなっている。プライベートな領域が開き、リストが落ち着き、期限切れの区分が赦し、ダイアログが自らの角を保ち、両方のマシンがひとつの心の掟を守る。それは哲学であり、予定表ではない。
