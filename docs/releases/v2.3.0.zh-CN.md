# 一场在九月进行的大扫除

这次发布是一组标准，而不是一组新奇：十六个项目、四套新的 Monet 主题与 126 种背景色，在同一趟里落到 Android 构建与 Windows 安装程序上。Lucent 以一颗心跑在两台机器上，而一次清扫正是这种设计分红兑现的时刻——上百个小表面，在一个下午里抵达同一个标准。做这件事没有哪个月份是不对的。

**私密区域是一个你会造访的地方。** 放进隐藏区域的笔记按需打开它的详情页，而隐藏列表把它显示为网格中一张圆角方形卡片，与同住一个家的隐藏任务并排。查询层以完全相同的条件接纳笔记与任务，于是私密区域像一间有门的房间：你走进去，你阅读，你走出来。在一条隐藏笔记与阅读它之间，什么也不立着。历史页面通篇由 token 着色，于是一个被恢复的版本坐在与它周围一切相同的调色板里。

**列表干净地收回它们的行。** 移除一项再撤销这次移除，是两下手势的愉快，而动画也是其中一部分。删除之后，列表有礼貌地把自己的行安顿回去，于是一个确认自身消失的底部面板做这件事时，并不显得在跟屏幕闹分手。恢复一条旧的笔记版本，会把它所取代的那个状态记为一条崭新的历史条目，时间戳落在那一刻，无论恢复来自界面还是来自助手自己的工具。滚动边缘的控件是唯一处的一个圆盘，它的箭头转向它将要带你去往的方向。

**逾期分区为完成而庆祝。** 任务完成了就是完成了，而任务世界与跑步世界意见一致：勾掉一项逾期内容会当场把它从逾期分区里清除，子请求也包括在内。聊天守着同一个标准。「再问一次」小小的待在右下角，在你的气泡之外；对话标题栏不携带多余的对话按钮；附件以文件名行的样子出现，每一条都能轻点一下、不带仪式地在查看器中打开。设置把「小模型优化」留在 Memory 下它自己的卡片里，而模型下拉框按名字做模糊搜索，所以一个记了一半的标识符也够用。

**两个平台被一起清理。** 复选框、滚动位置和提示浮层在 Android 与 Windows 上意思相同。锁屏跑着一架带尝试计数的暴力破解阶梯、自适应的错误色调和一个可选的自我销毁，而锁定提示的文案讲四种语言。Crash Shield 在被启用时于启动之际自行安装。一次备份会报告自己的成功或失败，而涂鸦导出会把一条笔记里被勾选的画布合并成一份多页 PDF。四套新的 Monet 主题加入调色板，而 126 种背景色中没有重复。背景的漂移守着自己 30 fps 的调速器，于是翻页不会让它损失帧。

结果是那种整洁得当的感觉：你指不出某一件东西，但房间变大了。私密区域打开，列表安顿下来，逾期分区予以宽恕，对话框守住自己的边角，而两台机器守着同一颗心的规矩。这是一种主张，不是一张日程表。
