# 32の気分と、本気の猫

背景はひとつの命を持たされ、起動時の猫は急ぐように言われ、アプリの外見は16のテーマから32へと育った。どれもが本当に異なる色で、本当に異なる名前を備え、その下には8つの背景スタイル・ファミリーが控えている。これは最良の意味での磨き上げのリリースだ。使っているアプリはそのままに、あらゆる角が滑らかに撫でられ、その足もとに新しい気分の床が一枚敷かれた。

**起動はさっさと進む。** 開始アニメーションは1.3倍速くなった——起動速度の定数が0.8から0.615へ移った——が、猫は今も手を振り、まばたきし、ガラスになる。ただ、その作法はかなり少なくなった。途中で描かれる形、振られる前脚、そのまばたき、ガラスへの変わり方は手つかずのままで、変わったのはその訪問にどれだけ時間がかかるかだけだ。コードはあの定数の隣のコメントに痩身の履歴をすべて保っているので、その数字と、その背後にある理由は一緒に旅をし、次の調整は既知の地点から始まる。

**背景は自分の時間を刻む。** 漂うブロブは壁時計の時刻を基準に、自分専用のDefaultディスパッチャのコルーチンの上で進む。だからその位置は時計の関数であり、インターフェースがほかになにをしていようと関係がない。自動サイクルの位相も同じ仕方で、やはり専用のディスパッチャの上で進む。8つのスタイル・ファミリー——Dawn、Blossom、Evergreen、Aqua、Sunfire、Vivid、Earth、Velvet——が42のボードとそこに含まれる126の固有の色を担い、それぞれが15ないし18を数える。Cycleの隣にはRandomが座り、20秒ごとにパレットを変え、同じものを繰り返すことを辞さない。Randomには専用の設定行と短いヒントがあり、両方のプラットフォームで配線されている。

**32のテーマは、そのすべてが本物だ。** System、Light、Darkが32のカラーテーマと並び、明暗の組を8つずつ描いていく。HoneyとUmber、MintとDeep Moss、PeriwinkleとBlueberry、CoralとBrick、SnowdropとObsidian、HoneydewとFir、LinenとWalnut、FrostとAbyss。背景の色はひとつとして重複せず、名前もひとつとして重複せず、4つのインターフェース言語がそのすべてを名で知り、それぞれ自らのラベルと説明を持つ。外観設定はそのセクションをファミリーの一覧からそのまま描画するので、この8つの組がこの並びの唯一の源になっている。

**見える場所で外見を選ぶ。** 設定はテーマごとに、その色見本、あなたの言語での名前、そして実際の背景色を並べて見せる。形容詞を選んで塗料に期待をかける人はいない。ロック画面では1秒ごとに刻むライブのカウントダウンが走り、誤ったパスワードのヒントは最後の試行から3秒後に自ら消えるので、古びた帯が長居する場所はない。起動の猫も、ブロブも、テーマも、ガラスも、両方のプラットフォームで同じだ。2台の機械がひとつの心を分け合っているからであり、このリリースはその取り決めの上に建っている。

コンポーザーとリストの面は同じ息で整えられ、テンプレートのチップは正しいアイコンを携え、ドリフトの時計と自動サイクルはそれぞれの鼓動を守っている。32のテーマ、8つの背景ファミリー、4つの言語、2つのプラットフォーム、ひとつの鼓動、そしてより速く手を振る猫。その足もとの床は広く、そこに載るどの色にも名前がある。
