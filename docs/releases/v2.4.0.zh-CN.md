# 三十二种情绪，和一只认真的猫

背景有了自己的生命，启动时的猫被吩咐快一些，而这款应用的外观从十六套主题长到了三十二套。每一套都是真实、彼此不同的颜色，各自带着真实、彼此不同的名字，其下还立着八个背景风格家族。这是一次最好的意义上的打磨发布：还是你在用的那款应用，只是每一条边都被摩挲得光滑，底下多铺了一层新的情绪。

**启动过程自己往前走。** 开场动画快了 1.3 倍——启动速度常量从 0.8 移到 0.615——猫依旧挥手、眨眼、化作玻璃，只是仪式感少了许多。它沿途画出的形状，挥动的爪子、那一次眨眼、转为玻璃的那一下，都未曾改动；改变的只是这场拜访要花多久。代码在那个常量旁边的一条注释里保留着完整的瘦身史，于是那个数字与它背后的理由一同流传，下一回调校便从一处已知的地方起步。

**背景按自己的时间走。** 漂移的光斑依据墙钟时间，在自己的 Default 调度器协程上前进，因此它们的位置是时钟的函数，而无关界面此刻可能在做的任何别的事；自动循环的相位以同样的方式推进，也在它自己的调度器上。八个风格家族——Dawn、Blossom、Evergreen、Aqua、Sunfire、Vivid、Earth 与 Velvet——承载着 42 个版面与其中 126 种独一无二的颜色，每个家族十五或十八种。Cycle 旁边坐着 Random，每二十秒更换一次调色板，并拒绝重复自己。Random 有自己的设置行和一句短短的提示，两个平台都已接通。

**三十二套主题，全部名副其实。** System、Light 与 Dark 与三十二套颜色主题并立，按八组明暗配对一次画出：Honey 与 Umber、Mint 与 Deep Moss、Periwinkle 与 Blueberry、Coral 与 Brick、Snowdrop 与 Obsidian、Honeydew 与 Fir、Linen 与 Walnut、Frost 与 Abyss。整套之中，每一个背景色都独一无二，每一个名字都独一无二，四种界面语言都能叫出其中每一个的名字，并各有自己的标签与描述。外观设置直接从家族列表渲染各个分区，于是那八个分组便是这一排布的唯一起源。

**外观在你看得见的地方被挑选。** 设置里为每套主题预览它的色块、它在你语言中的名字，以及它真正的背景色，于是没有人会先挑一个形容词再指望刷上漆。锁屏跑着一个每秒滴答一次的实时倒计时，输错密码的提示会在最后一次尝试三秒后自行清除，于是过时的横幅无处久留。启动的猫、光斑、主题与玻璃在两个平台上完全一致，因为这两台机器共用一颗心，而这次发布正是建立在这一安排之上。

输入框与列表界面在同一口气里被整理干净，模板标签带上了正经的图标，漂移时钟与自动循环各守自己的心跳。三十二套主题、八个背景家族、四种语言、两个平台、一颗心，还有一只挥得更快的猫。它脚下的地很宽，地上的每一种色调都有名字。
