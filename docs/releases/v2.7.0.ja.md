# すべてに居場所がある

Lucentのどのバージョンも、正しいものを、見つけられる場所に置くことについてだった。この版は、それが見える場所に置くことについてだ。メモとタスクが生まれるページは、いまやひとつの静かな段の上で開く。項目を設定するものはすべて、タップ一回の距離にあり、アプリの形を決める設定も同じ原則に従う。書いているものは目の前に残り、決めているものは折りたたみの後ろで行儀よく待つ。

**すべてに居場所を。** メモとタスクのコンポーザーは、書いているものだけを見せる。タイトル、詳細、添付、保存、そしてまっさらなメモで使えるワンタップのテンプレート。項目を設定するものはすべて、一段下がったところ、ラベルのついた「その他のオプション」の折りたたみの後ろに住む——モード、色、タグ、固定、優先度、リマインダー、繰り返し——共有モジュールでMoreOptionsFoldとして一度だけ組み立てられ、両方のプラットフォームが使う。折りたたみは新しいコンポーザーごとに畳まれた状態で始まり、作業中は自分の状態を覚えているので、長い編集がふとしたタップに邪魔されることはなく、編集の面はページと同じ幅のまま保たれる。

**色は壁紙から。** 設定 → 外観はMaterial Youの動的な色から始まる。Android 12以降では壁紙のパレットがアプリ内で最優先され、テーマ、背景、インク、漂うブロブは、その主色・副色・第三色から自らを塗り直す。保存された選択が壊れることはない。動的な色は読み取りの経路を上書きし、それを切れば、テーマとパレットはバイト単位でそのまま、同じフレームのうちに戻ってくる。テーマと背景のページにあるバナーがこの取り決めを明確に説明し、デスクトップは自前のパレットを保ってこのフラグを無視する——その違いも、はっきりと明言される。

**応えるピッカーと、あなたが変われば変わる日付。** アシスタントの「写真」の入口はシステムの写真ピッカーを開く。第三者のアプリがアルバムへ至る最も確かな道であり、ベンダーのギャラリーがとりわけ気難しい場所では、ドキュメントのピッカーがタップ一回の距離にある。クラウドストレージは、本物のクラウドの提供元が入っているときに差し出され、無いときには説明される。言語を切り替えると、共有された言語キー付きの整形ヘルパーを通じて、すべてのメモとタスクのカードの下の日付が同じフレームで変わる。ゴミ箱の二つの接尾辞も、属するカタログと同じ一息で4つの言語を話すので、どの言語も同時に追いつく。

**錠は数え、バックアップは追いつく。** アプリ内のあらゆるパスワード入力——ロック画面、アプリロックの解除、危険な操作、非表示エリア、バックアップの復元——がひとつの共有カウンターに課金される。残り試行回数のヒント、再起動を生き延びるライブのmm:ssカウントダウン、そして任意の自動消去を伴う。解錠に成功すればそれはリセットされ、「非表示」が何を意味するかの定義はひとつだけになり、それがすべての金庫の関門に仕える。バックアップのマニフェストv12は、保存済み検索を含むユーザーに見える設定をすべて運び、自動バックアップはAndroidでもWindowsでも起動時に自ら支度をする。Material Youの一セッションをまたいでも、スイッチをどちらへ倒しても、外観の選択はすべてバイト単位で同じままだ。

残るのは、あなたが感じ取るものだ。新しいメモはひとつの静かなページであり、折りたたみは尋ねられるまで中身を抱え、言語を変えれば日付はすぐに動き、アシスタントの「写真」ボタンはあなたのギャラリーを開き、どの錠も同じ時を刻み、バックアップは、設定したことさえ忘れていた好みまで見つけ出す。
