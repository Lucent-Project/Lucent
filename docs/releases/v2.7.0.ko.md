# 모든 것에 제자리가 있다

Lucent의 모든 버전은 알맞은 것을 찾을 수 있는 곳에 두는 일에 관한 것이었다. 이번 버전은 그것을 눈에 보이는 곳에 두는 일에 관한 것이다. 노트와 할 일이 태어나는 페이지는 이제 하나의 차분한 층 위에서 열리고, 항목을 설정하는 모든 것은 탭 한 번 거리에 있으며, 앱의 모양을 정하는 설정도 같은 원칙을 따른다. 쓰고 있는 것은 눈앞에 남고, 결정하고 있는 것은 접힌 층 뒤에서 예의 바르게 기다린다.

**모든 것에 제자리를.** 노트와 할 일 작성기는 쓰고 있는 것만 보여 준다. 제목, 세부 내용, 첨부, 저장, 그리고 새 노트에서의 한 번 탭 템플릿. 항목을 설정하는 모든 것은 한 층 아래, 이름표가 붙은 “추가 옵션” 접힘 뒤에 산다—모드, 색, 태그, 고정, 우선순위, 알림, 반복—공유 모듈에서 MoreOptionsFold로 한 번 만들어 두고 두 플랫폼이 함께 쓴다. 접힘은 새 작성기마다 접힌 채로 시작하고 작업하는 동안 자기 상태를 기억하므로, 긴 편집이 엉뚱한 탭에 방해받는 일이 없고 편집 면은 페이지와 정확히 같은 너비로 남는다.

**색은 당신의 배경화면에서.** 설정 → 모양은 Material You 동적 색상으로 시작한다. Android 12 이상에서 배경화면 팔레트는 앱 안에서 가장 높은 우선순위를 가지며, 테마와 배경, 잉크, 흐르는 블롭은 그 주색·보조색·3차색에서 스스로를 다시 칠한다. 저장된 선택은 결코 파괴되지 않는다. 동적 색상은 읽기 경로를 덮어쓰고, 그것을 끄면 테마와 팔레트가 바이트 단위로 그대로, 같은 프레임 안에서 돌아온다. 테마와 배경 페이지의 배너가 이 준비를 분명히 설명하고, 데스크톱은 자기 팔레트를 지키며 이 플래그를 무시한다. 그 차이도 분명하게 밝힌다.

**대답하는 선택기와, 당신이 바꾸면 바뀌는 날짜.** 어시스턴트의 “사진” 항목은 시스템 사진 선택기를 연다. 서드파티 앱이 당신의 앨범에 이르는 가장 믿을 만한 길이며, 제조사 갤러리가 유난히 고집스러운 곳에서는 문서 선택기가 탭 한 번 거리에 있다. 클라우드 저장소는 진짜 클라우드 제공자가 설치되어 있을 때 제시되고, 없을 때에는 설명된다. 언어를 바꾸면 공유된 언어 키 기반 서식 헬퍼를 통해 모든 노트와 할 일 카드 아래의 날짜가 같은 프레임에서 바뀌고, 휴지통의 두 접미사도 자신이 속한 목록과 같은 호흡으로 네 언어를 모두 말하므로, 모든 언어가 한꺼번에 따라간다.

**잠금은 세고, 백업은 따라간다.** 앱 안의 모든 비밀번호 입력—잠금 화면, 앱 잠금 해제, 위험 구역, 숨김 영역, 백업 복원—이 하나의 공유 카운터에 값을 매긴다. 남은 시도 횟수 힌트, 재시작을 견디는 실시간 mm:ss 카운트다운, 그리고 선택적인 자동 삭제가 함께한다. 잠금 해제에 성공하면 카운터는 초기화되고, 숨김이 무엇인지에 대한 정의 하나가 이제 모든 금고의 문을 맡는다. 백업 매니페스트 v12는 저장한 검색을 포함해 사용자에게 보이는 모든 환경설정을 싣고, 자동 백업은 Android와 Windows 모두에서 시작 시 스스로 준비한다. Material You 세션을 가로질러도, 스위치를 어느 쪽으로 넘기든, 모든 모양 선택은 바이트 단위로 동일하게 남는다.

남는 것은 당신이 느끼는 것이다. 새 노트는 하나의 차분한 페이지이고, 접힘은 물을 때까지 내용을 품고 있으며, 언어를 바꾸면 날짜가 곧바로 움직이고, 어시스턴트의 “사진” 버튼은 당신의 갤러리를 열며, 모든 잠금은 같은 시간을 지키고, 백업은 당신이 설정한 줄도 잊었던 환경설정까지 찾아낸다.
