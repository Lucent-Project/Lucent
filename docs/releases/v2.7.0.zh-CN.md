# 每样东西都有它的地方

Lucent 的每一个版本，都在把对的东西放到你找得到的地方。这一个版本，是把它们放到你看得见的地方。笔记与任务诞生的页面，如今平静地铺开在一层之上，配置一个条目所需的一切都只差一次点按，而塑造这款应用的设置也遵循同一个原则。你正在写的东西留在你眼前；你正在决定的东西，则礼貌地等在折叠区后面。

**每样东西都有地方。** 笔记与任务的撰写界面只显示你正在写的东西：标题、详情、附件、保存，以及全新笔记上的一键模板。配置条目的一切都住在下面一层，藏在一个带标签的“更多选项”折叠区之后——模式、颜色、标签、置顶、优先级、提醒与重复——在共享模块里作为 MoreOptionsFold 建造一次，两个平台共用。折叠区在每个新建的撰写界面里都从收起状态开始，并在你工作期间记住自己的状态，于是漫长的编辑过程不会被一次误触打断，编辑面始终和页面一样宽。

**颜色来自你的壁纸。** 设置 → 外观以 Material You 动态取色打头：在 Android 12 及更高版本上，壁纸调色板在应用里享有最高优先级，主题、背景、墨色与漂移的光斑都从它的主色、次色与第三色为自己重新上色。已存储的选择从不会被销毁；动态取色覆盖读取路径，关掉它，你的主题与调色板逐字节复原，就在同一帧内。主题页与背景页上的横幅把这一安排讲得清楚，而桌面端保留自己的调色板、忽略这个标志，并把这份区别明明白白地说出来。

**会应答的选择器，与随你而变的日期。** 助手的“照片”入口打开系统相册选择器，这是第三方应用通往你相册最可靠的路径；在厂商相册格外有主见的地方，文档选择器只差一次点按。云存储会在真正装有云服务商时提供，没有的时候也会得到说明。切换语言会在同一帧内改动每一张笔记与任务卡片下方的日期，靠的是一个共享的、以语言为键的格式化辅助函数；回收站的两个后缀与它们所属的目录在同一遍里说齐四种语言，于是每一种语言都同时跟上。

**锁会计数，备份跟得上。** 应用里的每一处密码提示——锁屏、关闭应用锁、危险操作、隐藏区、备份恢复——都记在同一个共享计数器上，配有剩余尝试次数的提示、能挺过重启的实时 mm:ss 倒计时，以及可选的自动销毁。一次成功的解锁会把它归零，“隐藏”的唯一定义如今服务于每一道保险库的门。备份清单 v12 携带每一项用户可见的偏好，已保存的搜索也在其中；自动备份在 Android 与 Windows 上都会在启动时自行待命。跨越一次 Material You 会话，无论开关朝哪边扳，每一种外观选择都保持逐字节一致。

留下来的，是你感觉得到的东西：一条新笔记就是一个平静的页面，折叠区在被问起之前一直握着自己的内容，语言一换日期立刻跟上，助手的“照片”按钮打开你的相册，每一把锁都按同一个时间走，而一份备份连你已经忘了自己设过的偏好也找得到。
