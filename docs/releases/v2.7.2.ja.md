# 約束は最後まで果たされる

約束の値打ちは、その背後にある取り決めで決まる。二段構えのコンポーザーは配線され、両方のプラットフォームから届く。間違ったパスワードを数える錠は、数えている間ずっと近道を断る。漂う背景は、画面自身のフレームコールバックと時を合わせる。そしてテンプレートは、あなたが書くものになる。ここに新しい発想はない。ここにあるのは、押せば応える取り決めだけだ。

**本気の錠。** 誤ったパスワードの回数は時間についての約束であり、ロック画面はそれをリアクティブに読む。一回分の誤入力が終わった瞬間、Androidの指紋ボタンとデスクトップのWindows Helloは部屋から下がり、代わりにライブのカウントダウンが座る——再コンポーズを生き延び、アプリを閉じて再起動しても残る。アプリ内のすべてのパスワード関門にとって、PasswordAttemptsが唯一の永続する真実の源だからだ。クールダウンが始まった時点で既に開いていた生体認証のプロンプトは、解錠の前にカウンターと照合し直される。ロックアウトは、どちらのプラットフォームでも曖昧さのない状態である。

**画面と時を合わせる背景。** ドリフトの時計は、インターフェーススレッド自身のフレームコールバックの上を進むようになり、丸ごとのvsyncに量子化される。60 Hzなら2つ、90なら3つ、120なら4つ。位置は経過時間の純粋な関数なので、再描画は等間隔に届く。スケジューラの揺らぎも、バックグラウンドスレッドからのスナップショット書き込みも、インターフェースが忙しい間に溜まるものもない。Randomオプションは約1.8秒かけて次のパレットへクロスフェードし、その選びはシード付きで、前の一つを決して繰り返さない。動きはこれまでと同じ動きであり、ただ時間どおりに届く。

**二段構えのコンポーザーと、自分で書くテンプレート。** 先頭への固定はメインの段、タイトルのすぐ下に座り、色、タグ、モードの切り替え、優先度、リマインダー、繰り返しは折りたたみの後ろで待つ。モードをオンにすれば、そのエディターがメインの段に現れる。4つの組み込みの後に並ぶ「新しいテンプレート」のチップは、空白のコンポーザーをテンプレートのエディターに変える。そこではタイトルが名前になる。保存したテンプレートは帯に加わり、長押しで一つを削除でき、作成の途中で離れれば下書きが預けられ、「未完成のテンプレートを続ける」として戻ってくる。アシスタントのヘッダーは新しい会話のための「＋」を携え、長いタイトルは綺麗に省略される。

**色は減り、そして説明がつく。** テーマの選択肢はちょうど18の色調、明るいものが9つ、暗いものが9つ。背景の選択肢は36のボード。似通ったものは刈り込まれ、名前もhexも固有であることが確かめられ、退役した選択肢の保存キーも依然として解決できるので、既存の選択が追い出されることはない。AndroidでMaterial Youが有効なときは2つの色の行が隠れ、バナーは残る。フラグが有効な間は外観ページの上端を占め、無効になれば行が戻ってくる。「（自動）」の添え書きは4つの言語すべてから去り、10の新しいテンプレート文字列が加わった。つまりこれは群衆ではなく、カタログである。

バックアップはv13へ進み、Material Youのフラグ、複数添付の会話、自作テンプレート、作成中の下書きを運ぶ。リリースのパイプラインはリポジトリの中にあり、バイト単位で同一のまま、検分できる。データベースの移行は要らなかった。テンプレートも下書きも設定のJSONだからだ。錠は本気で、背景は時を守り、色は正直で、あなた自身のテンプレートが組み込みの後ろで待っている。
