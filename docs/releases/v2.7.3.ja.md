# 日付は言語に従い、細部もそれに倣う

リリースと一週間暮らしてみると、どんなチェックリストよりも厳しい目になる。この版は、その一週間が出した結論だ。日付はインターフェースと一緒に言語を変え、折りたたみには息をつく余白が生まれ、テンプレートのチップは作りからして隣同士そろい、背景は自分のフレーム予算を自分で取り決め、初めての共有ロジックのテストがパレットの算術を見張っている。ここに大きなものはない。ここにあるのは、正確さだけだ。

**日付は、あなたが選んだ言語に従う。** Lucentを中国語に切り替えてリストへ戻れば、すべてのメモとタスクの下の日付が中国語になっている——同じフレームの中で、再起動も待ち時間もなく。Glass.ktの共有ヘルパーが、整形された説明文をタイムスタンプと現在の言語にまとめて結びつけているので、言語が変わった瞬間、組み上げ済みのカードがすべて描き直される。AndroidとWindowsは同じ共有ソースから描き、同じ答えを出す。日付は文法の一部であり、いまや両方の機械で、それが書かれている言語に属している。

**枠のある折りたたみと、同じ布のチップ。** 両方のプラットフォームで、「その他のオプション」の行は、どのコンポーザーでも添付の行のちょうど16 dp上に座る。枠のついた扉である。自作テンプレートのチップはFilterChipDefaultsをまとい、組み込みのチップと同じ角丸の矩形、塗り、輪郭、ラベルの作法を分け合うので、チップの帯はひと目でひとつの家族に見える——自作のチップを見分ける手がかりは、作者が誰かということだけだ。どちらの変更も小さく、正確で、コンポーザーを開くたびに目に入りながら、考える必要のない類のものだ。余白もまた、文法のひとつなのである。

**予算を自分で取り決める背景。** ひとつのガバナーが、実際に届いた再描画どうしの間隔を見ている。遅れが6回続けば段をひとつ落とし——毎秒30から24、そして20フレームへ——18回続けて間に合えばまた登っていく。このゆっくり漂う曲線では、20 fpsと30 fpsは見た目に区別がつかず、そこで空くフレーム予算は、非力なGPUでのページ遷移がちょうど必要とするものだ。段を下げるときには、ダークモードの処理経路で最も高価な部分も手放す。30 fpsを保てる端末は、このいずれにも気づかない。ガバナーは証拠だけに従って動く。

**約束を数字に突き合わせるテスト。** 初めての共有ロジックのユニットテストが、いまではどのビルドでも走る。テンプレートと保存済み検索の往復、パスワード試行のはしご、そしてパレットを留める2つのテスト——色調はちょうど18、ボードはちょうど36、どの項目も固有で、隠された項目もすべて保存されたキーを解決できる。Windowsではこの一式がネイティブの作業より先に走るので、壊れた規則は数分のうちに報告される。エンジンがまだ静かなうちに。したがってこのリリースの数字は宣伝ではない。ビルドが守ると宣言した事柄である。ひとつのテスト一式が、いま2つのプラットフォームの代わりに答える。

言語を切り替えれば、日付がついてくる。折りたたみには枠があり、チップはひとつの家族で、背景は自分に払えるフレーム時間だけを求める。AndroidとWindowsは同じ共有ソースから同じ歩調を保ち、その小さく正確な歩みは、いまテストに覆われている。
