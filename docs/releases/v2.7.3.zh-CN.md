# 日期跟随语言，细节也照此办理

与一个版本相处一周，是比任何清单都更严格的审阅者，而这一版正是那一周交出的那份答卷：日期随界面一同更换语言，折叠区有了呼吸的余地，模板标签与左右邻座从构造上就一致，背景自己谈定帧预算，还有第一组共享逻辑测试，守着调色板的算术。这里没有庞然大物。这里的一切都分毫不差。

**日期跟随你选择的语言。** 把 Lucent 切到中文，再回到列表，每一条笔记和任务下面的日期都是中文——同一帧内完成，不必重启，也无需等待。Glass.kt 里一个共享的辅助函数，把格式化后的说明文字同时系在时间戳与当前语言上，于是语言一变，每一张组合好的卡片立刻重绘。Android 与 Windows 取自同一份共享源码，给出同一个答案。日期是语法的一部分，而如今在两台机器上，它都属于自己书写所用的那种语言。

**有边框的折叠区，与同一块布裁出的标签。** 在两种平台上，每个撰写界面里的“更多选项”一行，如今都清清楚楚地待在附件行上方 16 dp 处：一扇带门框的门。自定义模板标签穿上 FilterChipDefaults，与内置标签共享同一个圆角矩形、填充、描边与文字样式，于是整条标签带一眼看去就是一家人——只有署名能让一个自定义标签显出区别。这两处改动都小，都准确，属于每次打开撰写界面都会看见、却从不需要去想的那一类。留白，说到底也是一种语法。

**自己谈预算的背景。** 一个调速器盯着每次重绘之间真实的间隔。连续 6 次迟到，就降一档节奏——每秒 30 帧降到 24，再到 20——连续 18 次准时，则把它升回去。在这些缓慢漂移的曲线上，20 fps 与 30 fps 在视觉上无从分辨，而它让出的帧预算，恰好是性能较弱的 GPU 做一次页面过渡所需要的那一份。降档时，它还会一并卸下深色模式管线里最昂贵的那一段。一台能稳住 30 fps 的设备对此毫无察觉：调速器只依据证据行事。

**让承诺对得上数字的测试。** 第一批共享逻辑单元测试如今在每次构建时运行：模板与已保存搜索的往返，密码尝试次数的阶梯，以及两个钉住调色板的测试——恰好 18 种色调，恰好 36 个版面，每一个条目都独一无二，每一个被隐去的条目也都仍能解析出已存储的键。在 Windows 上，这套测试在任何原生工作开始之前运行，于是一条被破坏的规则会在几分钟内被报出，此时引擎还安静着。因此，这一版里的数字不是宣传；它们是构建会为之辩护的断言。一套测试，如今同时替两个平台作答。

切换语言，日期随之而变。折叠区有了自己的框，标签是一家人，背景只索要它负担得起的帧时间。Android 与 Windows 从同一份共享源码出发，步伐一致，而那些小而准确的步子，如今都在测试的照看之下。
