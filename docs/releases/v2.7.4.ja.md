# 背景は自分のレースを走る

携帯電話のスクリーンショット二枚と長押し一回が、このリリースの大半を占めている。バージョンがそうやって時間を使うのも、もっともな話だ。確認ダイアログの三つの決定は一行に並び、「磨き続ける」には、アプリ自身が書く追い質問を伴う手順が定まり、テンプレートのチップはどれも一つの家族に属して長押しの背後にメニューを持ち、Androidの背景は自前のスレッドと自前の時計を持つレンダラーで走る。

**一行に、三つの決定。** アシスタントの確認ダイアログは、どの端末でも「磨く」「追加」「取り消し」を一行に載せ、ラベルはすべて本来の大きさのままだ。ラベル間の余白は詰め、フォントは自然な大きさのまま、maxLines=1が番をしている。行は決定が進む順に左から右へ読む——磨くか、追加するか、しないか。狭い画面も広い画面と同じ一行を得る。それこそが決定行の要点である。ひと目で、三つの選択、スクロールなし。行を収めるために何かが省略されることはない。

**「磨き続ける」は言ったとおりに働く。** 磨くことを選んでも何も書き込まれない。追い質問はアプリがあなたの言語で組み立て、あなたの答えは保留された提案をシステムプロンプトに添えたまま次のターンへ運ばれる。アシスタントはあなたの調整を反映してその項目を再び提案し、もう一度ツールを呼ぶ。やがて確認ダイアログが改訂された項目とともに戻ってくる。最後の「はい」は常にあなたのものだからだ。同じ手順がクラウド経路と端末内経路の両方で走るので、どのモデルが答えているかで挙動は変わらない。磨きは会話であり、いまやそこにはターンがある。

**一つの家族のチップ、その背後に一つのメニュー。** テンプレート列のすべてのチップ——組み込みも自作も——は本物のFilterChipであり、色、大きさ、角の丸み、ベースラインはどんなテーマでも構造上一致する。長押しで両方の家族に「編集」と「削除」が開く。組み込みは隠せて、隠した状態は持続し、隠れた組み込みは列から復帰できる。自作テンプレートは編集モードで開き、自分自身に上書き保存される。組み込みの形を読み込んで自分のものとして保存することもできる。列が一つのものとして振る舞うのは、それが一つのものだからだ。

**自前のスレッドを持つ背景。** Androidでは背景はインターフェースから完全に離れて描画される。レンダラーが自分のワーカースレッドで、自分の時計に従って各フレームをダブルバッファーの半分解像度ビットマップへラスタライズし、UIスレッドは安価なテクスチャ描画を一度だけ行う。ページ遷移がアニメーションを飢えさせることはない。ページスレッドを争うアニメーションが存在しないからだ。動きの数式、モーフ、つぶれ、回転は変わらず、適応段階は今も適用され、アプリが休めばこの面も休む。その一方で新しいタグ欄は、既定の高さの0.8という端正な姿で中央に収まっている。

Windowsは共有のGPU駆動経路を保つ。この隔離は、電話の問題に対する電話なりの答えだからだ。四つの言語すべてが新しい文字列を運び、隠されたテンプレートはバックアップの設定ブロックを旅し、単体テストは今も毎回のビルドで走る。背景は自分のレースを走る。インターフェースはあなたのレースを走るために空いている。
