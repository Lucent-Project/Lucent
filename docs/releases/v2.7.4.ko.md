# 배경은 자기 경주를 달린다

휴대폰 스크린샷 두 장과 긴 누르기 한 번이 이 릴리스의 대부분을 차지한다. 한 버전이 그렇게 시간을 쓰는 것도 합당하다. 확인 대화 상자의 세 가지 결정은 한 줄에 앉고, '계속 다듬기'에는 앱이 직접 쓰는 후속 질문이 따르는 절차가 생겼으며, 모든 템플릿 칩은 하나의 가족에 속해 긴 누르기 뒤에 메뉴를 두고, Android 배경은 자기 스레드와 자기 시계를 가진 렌더러 위에서 달린다.

**한 줄, 세 가지 결정.** 어시스턴트의 확인 대화 상자는 이제 모든 기기에서 다듬기, 추가, 취소를 한 줄에 싣고, 모든 레이블은 원래 크기 그대로다. 레이블 사이 여백은 좁혔고, 글꼴은 자연스러운 크기로 두었으며, maxLines=1이 줄을 지킨다. 줄은 결정이 진행되는 순서대로 왼쪽에서 오른쪽으로 읽힌다——다듬거나, 추가하거나, 하지 않거나. 좁은 화면도 넓은 화면과 같은 한 줄을 얻는다. 그것이 결정 줄의 요점이다. 한눈에, 세 가지 선택, 스크롤 없음. 줄을 맞추기 위해 무엇 하나 줄여 쓰지 않는다.

**'계속 다듬기'는 말한 대로 한다.** 다듬기를 고르면 아무것도 쓰이지 않는다. 후속 질문은 앱이 당신의 언어로 짓고, 당신의 답은 대기 중인 제안을 시스템 프롬프트에 붙인 채 다음 차례로 실려 간다. 어시스턴트는 당신의 조정을 반영해 그 항목을 다시 제안하고 도구를 다시 호출한다. 그러면 확인 대화 상자가 수정된 항목과 함께 돌아온다. 마지막 '예'는 언제나 당신의 것이기 때문이다. 같은 절차가 클라우드 경로와 기기 내 경로에서 똑같이 돌기에, 어느 모델이 답하든 동작은 달라지지 않는다. 다듬기는 대화이고, 이제 거기에는 차례가 있다.

**한 가족의 칩, 그 뒤에 하나의 메뉴.** 템플릿 줄의 모든 칩——기본 제공이든 사용자 정의든——은 진짜 FilterChip이라서 색, 크기, 모서리 반경, 기준선이 어떤 테마에서도 구조적으로 일치한다. 길게 누르면 두 가족 모두에게 편집과 삭제가 열린다. 기본 제공은 숨길 수 있고, 숨김은 유지되며, 숨겨진 기본 제공은 줄에서 되살릴 수 있다. 사용자 정의 템플릿은 편집 모드로 열려 자기 자신 위에 저장되고, 기본 제공의 모양을 불러와 당신의 것으로 저장할 수도 있다. 줄이 하나처럼 행동하는 것은 그것이 한 가지이기 때문이다.

**자기 스레드를 가진 배경.** Android에서 배경은 인터페이스와 완전히 떨어져 렌더링된다. 렌더러가 자기 작업 스레드에서 자기 시계에 맞춰 각 프레임을 이중 버퍼의 절반 해상도 비트맵으로 래스터화하고, UI 스레드는 값싼 텍스처 그리기를 한 번만 한다. 페이지 전환이 애니메이션을 굶길 수 없다. 페이지 스레드를 두고 다투는 애니메이션이 없기 때문이다. 움직임의 수학, 모프, 눌림, 회전은 그대로이고, 적응 단계는 여전히 적용되며, 앱이 쉬면 이 면도 쉰다. 한편 새 태그 입력란은 기본 높이의 0.8이라는 반듯한 모습으로 가운데에 있다.

Windows는 공유된 GPU 기반 경로를 지킨다. 이 격리는 휴대폰의 문제에 대한 휴대폰의 답이기 때문이다. 네 언어 모두 새 문자열을 싣고, 숨겨진 템플릿은 백업의 설정 블록을 타고 가며, 단위 테스트는 여전히 빌드마다 돈다. 배경은 자기 경주를 달린다. 인터페이스는 당신의 경주를 달릴 자유를 얻는다.
