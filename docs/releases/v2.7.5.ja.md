# 雲がやって来て、沈黙は沈黙として読まれる

ストリーミングモデルはいつも言葉を送ってくるわけではない。問いと答えの間には純粋な思考の区間がしばしばあり、回線はその区間を何もないという形で表す。ストリーミング層はその区別に通じている。どのプロバイダーのどの断片にもnullガードが掛かり、考えるモデルは静かに考え、会話は会話のままにとどまる。同じリリースが、あなたのバックアップに雲の中の住まいを与え、新しいタグ欄に落ち着くべき比率を与える。

**すべての断片を、すべてのプロバイダーから、ガードする。** 推論モデルは答えより先に断片を流し、テキストを運ばない断片は言葉ではなくプロトコルの正規の一部である。この区別は重要だ。明示的なJSON nullは「テキストは送られなかった」という陳述であり、たまたまそう名づけられている四文字の単語ではない。ストリーミング層は扱うすべての欠片をそのように読む——OpenAIとDeepSeekのcontent、ツール引数、Anthropicのtextとpartial_jsonの断片、Googleのpartテキスト。nullは何もないままにとどまるので、思考から始まる返答は沈黙から始まり、用意ができたときに届く。会話は会話のままであり、考えるモデルとのチャットにとってそれは仕様のすべてである。

**バックアップのための雲の住まい。** 設定リストにはエディターとセキュリティの間にクラウドのセクションが加わる。バックアップ機能が住むのに自然な場所だ。それはWebDAVを話す——Nutstore（坚果云）、Nextcloud、Koofr、そして任意のカスタムエンドポイントがすでに知っている唯一の方言である。URLとユーザー名、そして各プロバイダーがまさにこの用途のために発行する種類のアプリパスワードを持ってくればよい。接続テストのボタンが取り決めを確認し、パスワードは暗号化して保存され、保存先フォルダーは初回使用時に自らを作る。三つの決定は別々のままだ。自動バックアップはクラウドにも複製してよく、一つのボタンは即座にクラウドへバックアップし、復元リストは選んだバックアップをローカル復元と同じ「まず確かめ、それから確定する」流れへダウンロードする。複製の失敗がローカルバックアップを失敗させることはない。複製は人質ではない。

**小さな箱、正確な比率、そして持ち運ばれる設定。** 新しいタグ欄は真の0.8高さ、45 dpの箱で、その内側の余白は高さに合わせてある。だからプレースホルダーは欠けることなく中央に収まる。小さく、箱らしく、読める、指定どおりに。クラウド設定は他のあらゆる好みと同様、暗号化されたバックアップのマニフェストに乗って運ばれるので、復元した電話は自分のクラウドが使える状態で見つける。AndroidとWindowsは同じ共有ソースから続き、単体テストは毎回のビルドで走り、ガードは各プロバイダーのストリームを、GeminiとClaudeの隅まで含めて覆う。ネットワークから届くものはテキストか、さもなければ何もない。アプリはそれぞれに応じて扱う。

ストリーミング層を慎重な読者だと思えばよい。書かれているものは受け取り、残りをでっち上げることはしない。モデルが考える間もあなたの会話は静かで、バックアップには電話の外に行く先があり、タグ欄はあるべき形そのままだ。
