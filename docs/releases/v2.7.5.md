# The Cloud Arrives, and Silence Reads as Silence

A streaming model does not always send words. Between the question and the answer there is often a stretch of pure thinking, and the wire represents that stretch with nothing at all. The streaming layer is fluent in that distinction: every fragment from every provider is null-guarded, so thinking models think silently and a conversation stays a conversation. The same release gives your backups a home in the cloud and gives the new-tag field its settled proportions.

**Every fragment, from every provider, guarded.** Reasoning models stream fragments before they stream answers, and a fragment carrying no text is a legitimate part of the protocol rather than a word. The distinction matters: an explicit JSON null is a statement that no text was sent, and it is not the four-letter word that happens to name it. The streaming layer now reads every piece it handles that way — OpenAI and DeepSeek content, tool arguments, Anthropic's text and partial_json pieces and Google's part text. A null stays nothing, so a reply that begins in thought begins in silence and arrives when it is ready. A conversation remains a conversation, which for a chat with a thinking model is the whole of the specification.

**A cloud home for your backups.** The Settings list gains a Cloud section between Editor and Security, where a backup capability naturally lives, and it speaks WebDAV — the one dialect Nutstore (坚果云), Nextcloud, Koofr and any custom endpoint already know. Bring a URL, a username and an app password of the sort every provider issues for exactly this purpose. A test-connection button confirms the arrangement, the password is stored encrypted, and the destination folder creates itself on first use. Three decisions stay separate: automatic backups may also mirror to the cloud, one button backs up to the cloud immediately, and a restore list downloads the backup you choose into the same inspect-then-confirm pipeline the local restore uses. A failed mirror never fails the local backup; a mirror is not a hostage.

**Small box, exact proportions, and a configuration that travels.** The new-tag field is a true 0.8-height box of 45 dp, and its interior padding is matched to that height, so the placeholder sits whole and centred: small, boxy, legible, exactly as specified. The cloud configuration rides the encrypted backup manifest like every other preference, so a restored phone finds its cloud ready to go. Android and Windows continue from the same shared sources, the unit tests run on every build, and the guard covers each provider's stream, Gemini's and Claude's corners included. What arrives from the network is text or it is nothing, and the app treats each accordingly.

Think of the streaming layer as a careful reader: it takes what is written and declines to invent the rest. Your conversations stay quiet while a model thinks, your backups have somewhere to go beyond the phone, and the tag box is exactly the shape it should be.
