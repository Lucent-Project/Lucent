# 云端到来，沉默读作沉默

流式模型并不总是发送词语。问题与答案之间往往有一段纯粹的思考，而线路用“什么都没有”来表示这一段。流式层通晓这一区别：来自每一家供应商的每一个片段都做了空值防护，于是思考型模型安静地思考，对话始终是对话。同一个版本还让你的备份在云端有了一个家，并给新标签输入框定下了它该有的比例。

**每一个片段，来自每一家供应商，都有防护。** 推理模型先流式送出片段，再送出答案，而一个不携带文本的片段是协议中合法的一部分，不是一个词。这一区别要紧：显式的JSON null是一句“没有文本送出”的陈述，而不是恰好用来称呼它的那个四字母单词。流式层现在以这种方式读取它处理的每一片——OpenAI与DeepSeek的content、工具参数、Anthropic的text与partial_json片段、Google的part文本。null保持为空，于是一段从思考开始的回复也从沉默开始，准备好了才抵达。对话仍然是对话，而对于与思考型模型的聊天来说，这就是规格的全部。

**备份的云端之家。** 设置列表在编辑器与安全之间新增了云分区，备份能力住在这里再自然不过；它说WebDAV——坚果云（Nutstore）、Nextcloud、Koofr以及任何自定义端点都已经认得的唯一方言。带上一个URL、一个用户名，以及各家供应商正是为此事签发的应用密码。一个测试连接按钮确认这套安排，密码加密存放，目标文件夹在首次使用时自己创建。三个决定各自独立：自动备份也可以同步到云端，一个按钮立刻备份到云端，恢复列表会把你选中的备份下载下来，送进本地恢复所用的同一条“先查看、再确认”的流程。同步失败绝不会让本地备份失败；备份不是人质。

**小方框，精确比例，以及会随行的一段配置。** 新标签输入框是真正0.8高度、45 dp的方框，内边距与该高度匹配，于是占位文字完整而居中地待着：小、方正、清楚，与规格分毫不差。云端配置像其他每一项偏好一样，随加密的备份清单一起旅行，于是恢复后的手机发现自己的云端已经就绪。Android与Windows继续来自同一套共享源码，单元测试在每次构建时运行，防护覆盖每一家供应商的流，包括Gemini与Claude的角落。从网络到来的东西要么是文本，要么什么都不是，应用分别相待。

把流式层想成一位细心的读者：写下来的它收下，其余的它不肯编造。模型思考时你的对话保持安静，你的备份有手机之外的地方可去，标签框正是它该有的形状。
