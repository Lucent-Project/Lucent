# 言葉を減らし、色を増やす

設定ページは今やスイッチから始まり、それ以外は静けさとしてあなたに返された。四十七件のカタログ項目が四つの言語すべてから引退した。残ったのは、より野心的な色、それぞれの周期を歩く三つの重み、そして単一のリストから導かれるセクションモデル——だからカードは必ず一つの場所にだけ属する。ダイアログは一言も変わらず、あなたのデータも置いた場所のままにある。

**ページは短く、残る言葉はすべてその座に値する。** スイッチの下にあった説明の段落——Markdownが何をするか、リッチテキストが何を費やすか、メモリ階層とは何か、履歴の上限はなぜあるのか——は引退し、長すぎた三つのナビゲーション副題もともに去った。タイトル、スイッチ、値、空の状態、そして何かが使えない理由を説明するすべての通知は残っている。47件のカタログ項目が四つの言語すべてを離れたので、英語・中国語・日本語・韓国語のページはいずれも短くなった。確認、同意の告知、警告はどれも一言も違わず元の場所にある。説明がその座に値するのはそこだからだ。

**三つの色と、自分なりの意見を持つグラデーション。** 三つの色の重みはそれぞれ自分の周期でパレットをゆっくり歩く——一歩あたり37秒、49秒、61秒——その間ずっとクロスフェードし、互いにパレットの三分の一だけ離れた位置から始まる。その下の波はもっと短い周期、23秒、29秒、37秒で走る。三秒後の実測変化は一チャンネルあたり8/255、八秒後は22/255、それでも隣り合う二つのピクセルの差は5/255を超えない。だからこの面は輪郭ではなく柔らかさとして読める。動きを減らす設定は波を凍らせ、色は歩き続ける。

**一つのリスト、一つのセクション、その間にずれはない。** セクションモデルはページが描画するのと同じリストから導かれるので、両者が食い違うことはありえない。あるテストがセクションの順序と、項目がそのうちのちょうど一つに現れるという規則の両方を固定している。だからカードは必ず一つの場所に属し、そこに留まる。この単一の真実の源が、その種の不一致を、単に起こらないのではなく不可能にする。

**書き込みは起きたことを記録して、そのまま続く。** 背景の書き込みは結果を端末内のイベントログに記録して走り続けるので、どの書き込みにも記録上の結果があり、流れはそれに関わらず続く。あなたが実際に待つ四つの書き込み——ノートの保存、タスクの保存、そしてピン留めの切り替え二方向——はあなたの言語で報告する。これはCrash Shieldがしばらく前からインターフェーススレッドに約束してきた礼儀であり、いまは背景も同じものを守っている。待っていようといまいと、すべての書き込みに結果がある。AndroidとWindowsは今も一つの共有ソースツリーをコンパイルする。

あなたのデータに変わったところはない。新しい設定もなく、スキーマの変更もなく、.lcbバックアップと暗号化ストアはそのままの姿である。ページは静かになり、色は大きくなり、どのカードも自分の居場所を知っている。
