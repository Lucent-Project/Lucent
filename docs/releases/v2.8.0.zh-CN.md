# 少些文字，多些色彩

设置页面现在以开关开场，其余的都当作安静还给了你：四十七条目录条目从四种语言中一并退休。留下的是更有野心的色彩，三道各走各的周期的色阶，以及一套由单一列表推导出来的分区模型——于是一张卡片永远只属于一个地方。对话框一字未动，你的数据也仍在原处。

**页面更短，每个字都当得起。** 开关下面那段解释——Markdown做什么、富文本要付什么代价、记忆层级是什么意思、历史记录为什么有上限——已经退休，三条过长的导航副标题随它一同离开。标题、开关、数值、空状态，以及每一则说明某项功能为何不可用的提示，都留了下来。全部47条目录条目离开了四种语言，所以英文、中文、日文、韩文的页面都一样短了。每一处确认、每一份知情告知、每一条警告都一字不动地留在原处，因为那才是解释当得起的位置。

**一道有三种颜色、也有自己主张的渐变。** 三道色阶各自沿自己的周期在调色板上缓行——每步37、49、61秒——全程交叉淡入淡出，彼此的起点相隔三分之一个调色板；它们下方的波纹则跑在更短的周期上：23、29、37秒。三秒后每通道的实测变化为8/255，八秒后为22/255，而相邻两个像素的差值从不超过5/255，于是这一片看上去是柔和，而不是边界。减弱动态会冻结波纹，颜色照旧行走。

**一份列表，一个分区，两者之间不会漂移。** 分区模型取自页面所渲染的同一份列表，因此两者不可能彼此不一致。一项测试同时钉住分区的顺序和“一个条目只出现在其中一个分区”这条规则，于是一张卡片永远只属于一个地方，并且一直待在那里。这个唯一的真相来源让整类不一致变得不可能，而不只是恰好没有发生。

**写入会记下发生了什么，然后继续。** 后台写入把结果记入设备内的事件日志，并继续运行，因此每一笔写入都在记录里有一个结果，数据流无论如何都接着走。你真正会等待的那四笔写入——保存一条笔记、保存一项任务，以及两个方向的置顶切换——会用你自己的语言回报。这与Crash Shield一段时间以来为界面线程许下的礼数相同，如今后台也一并守住了：无论你是否在等，每一笔写入都有结果。Android和Windows仍然编译同一份共享源码树。

你的数据没有任何改变：没有新增设置，也没有模式变更，.lcb备份和加密存储一切如故。页面更安静了，颜色更响了，每一张卡片都知道自己住在哪里。
