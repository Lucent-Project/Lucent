# アシスタントが途中式を見せる

アシスタントに何か尋ねると、今は途中式を見せてくれる。見せると選んだ推論の、生きた折りたたみ可能な記録、呼び出した道具ごとの一行、そしてその呼び出しが完了したのか、失敗したのか、取り消されたのか。そのまわりで、検索は文字を打つ欄の中へ移り、どの一覧も最初のフレームで本当に保存されているものを描き、一つの固定コントロールは言ったとおりのことをする。ここに覚えることは何もない。アプリはただ、アプリらしく振る舞う。

**途中式を見せるアシスタント。** 記録は飾りのアニメーションではなく、モデルの流れから来る本物の出来事に動かされ、返信とともに保たれる。だから古い会話を開き直しても途中式はそこにあり、バックアップもそれを運ぶ。道具の呼び出しは結果を伴う一行だ。完了、失敗、取り消し。アシスタントは九つのノート道具を得たので、ノートとタスクは同じ会話の中で整理し、名づけられる。チャットページのモデル切り替えは、すでに選んだモデルを並べる。一度だけ取得し、まとめて選ばれる。

**どの最初のフレームも本当のことを言う。** 五十余りの設定が、起動時に種をまかれるキャッシュから来るようになった。だからどのスイッチも、一覧も、下位ページも、Material You のカードも、まさに最初のフレームで本当に保存されているものを描く——最初も、その後も、保存されている値のまま。どの一覧も——アーカイブ、下書き、非表示、ゴミ箱、完了、そしてノートの下位ページ——どこまでスクロールしていたかを覚えている。プライバシー領域から開いたノートはプライバシー領域へ閉じ戻り、戻る矢印とシステムのジェスチャーは同じことをする。

**効く固定がひとつ、そして言ったとおりに書く書き込み。** 固定のコントロールはひとつだけで、それが効く。保存、固定、並べ替えは、意図したものだけを書き、それ以外は書かない。だから一か所でした編集はそのまま残る。すべてを消去すればノートブックも消え、どちらの結果でもそれを報告する。

**いくらか命のある色とカード。** 三つの大きな色相の帯が一方の対角線に沿って走り、もう一方の対角線にはゆっくりとした滲みが流れる。だからいくつもの色が画面全体を分け合い、なめらかに消えていく。窓いっぱいに、端から端まで。あなたの Material You の壁紙の色は、平坦なテーマにだけ留まらず、このグラデーションに乗る。指を下ろしている間、ドラッグはどのカードもゼリーのようにそっと揺らし、あるカードを別のカードの上へ運ぶと入れ替わりが生きたまま予告される。指を離すまで本当には何も動かない。何もないところで離せば、すべてが元の位置へ跳ね戻る。

エディタは打ち込んだ分だけ育ち、連続する空行を保ち、本物の全画面へ広がる。Markdown とリッチテキストは一つのノートに同居できる。初期設定では、住所を内蔵した六つの API の選択肢、二十のプロファイル、そして四角いチェックボックスの付いたモデル選択があり、チェックしたものを覚えている。このリリースが手元に残すのは、最初のフレームから正しいアプリ、返信とともに保たれる記録、そして言ったとおりのことをする固定である。
