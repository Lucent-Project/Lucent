# 助手展示它的过程

向助手提个问题，它现在会展示自己的过程：一段实时、可折叠的痕迹，记录它选择给你看的推理；它每调用一个工具就是一行，以及那次调用是完成了、失败了，还是被取消了。在它周围，搜索搬进了你打字的那只输入框，每一张列表在第一帧就渲染出真正存着的内容，而一个固定控件只做它说的那一件事。这里没有什么需要预先学会；应用只是照它自己的样子行事。

**会展示自己过程的助手。** 这段痕迹由模型流中的真实事件驱动，而不是一段装饰性的动画；它随回复一起保存，所以重新打开一段旧对话，过程还在那里，备份也会把它带上。一次工具调用是一行，带一个结果：完成、失败或取消。助手获得了九个笔记工具，于是笔记与任务可以在同一段对话里归档、命名。聊天页上的模型切换器列出你已经选好的那些模型，取一次，一起选定。

**每一帧初始画面都说真话。** 五十来项设置现在来自一份在启动时播种的缓存，于是每一个开关、列表、子页面和 Material You 卡片，在最初那一帧就渲染出真正存着的内容——第一次以及此后每一次，都是存着的那个值。每一张列表——归档、草稿、隐藏、回收站、已完成，以及笔记的各子页面——都记得你滚动到了哪里。从隐私区域打开的笔记，关闭时回到隐私区域，返回箭头和系统手势做的是同一件事。

**一个确实管用的固定，以及名副其实的写入。** 固定控件只有一个，而且它管用。保存、固定和重新排序写下的恰好是它们想写的东西，不多写别的，于是一处改动做完就留在那里。清空全部也会把笔记本一起清空，并且无论结果如何都会说明。

**有几分生气的颜色与卡片。** 三道宽阔的色相带沿一条对角线铺开，另一条对角线上则是一层缓慢的晕染，于是几种颜色共处整块屏幕，平滑地淡出，铺满窗口，直达边缘；你的 Material You 壁纸颜色会随渐变一起流动，而不只是待在平铺的主题里。手指按住时，拖动会让每一张卡片像果冻一样轻轻摇晃；把一张卡片拖到另一张上面，会实时预览这次交换：松手之前什么都不会真的移动，而松开一场空，一切都会弹回原处。

编辑器随你输入的内容生长，保留连续的空行，并能展开成真正的全屏；Markdown 与富文本可以在同一条笔记里共存。初始设置提供六个内置地址的 API 选项、二十份配置文件，以及一个带方形勾选框、会记住你勾了哪些的模型选择器。这个版本留给你的，是一个第一帧就已经正确的应用，一段随回复一起保存的痕迹，以及一个说到做到的固定。
