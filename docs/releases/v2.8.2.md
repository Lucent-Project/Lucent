# The Local Model Learns to Use Its Tools

The local assistant can now do the thing rather than describe it. Ask for a note to be filed, a task created or a search run, and it chooses the tool, calls it, reads the result back and continues to the next step of the same task. When a tool call will not parse, it says so plainly. Four arrangements make that dependable, and the bundled engine moves up two years of upstream work to b11057. The toolbox is now genuinely in reach of the model holding it.

**Tools that arrive intact.** The protocol sits at the end of the prompt, where truncation reaches it last, so the instructions are still there when the model goes looking for them. The local tool list is one line per tool rather than a paragraph each, which keeps the catalogue inside the space available, and the conversation is trimmed to the engine's budget before it is ever sent, so the history cannot crowd out the rules. Tool results return as an ordinary user message in the format the prompt asks for, so the second step of a task lands in the same turn, with an outcome recorded for every call.

**A newer engine, and exactly three changes.** The bundled engine moves from llama.cpp **b9888** to **b11057**, which required exactly three API changes: the mmap flag became a load mode, the multimodal helper gained an options argument, and the multimodal input text now carries its own length instead of being measured with `strlen`. A new upstream hash dependency links in alongside. Both builds pin the engine at the same revision and prefetch it from the same CMake files, so Android and Windows ship one engine between them. The desktop GPU engine also gets the same 4096 context as the CPU one, and a prompt that will not fit says so plainly in the log.

**Small mercies, correctly placed.** Material You sits back above Theme and Background on the Appearance page, and the theme blurbs describe only their colour rather than repeating whether they are light or dark. The built-in API providers ask only for what they need; only Custom shows an address field, and it starts empty. The attachment row now matches the due-date row exactly, and the local-model entry is offered on every device. Back leaves the editor: with a note or task open for editing, the back gesture returns you to the list you came from. Dragging follows your finger exactly, all the way across the list, and a long press that goes nowhere leaves no trace — no dim, no lift, no shadow, nothing to dismiss afterwards.

Nothing outside the local-model module needs to change, which is the point: the cloud path, the tools themselves and your data were not part of the move. The assistant on your phone reads the manual, picks the tool, and finishes the job it was asked to do.
