# 本地模型学会使用它的工具

本地助手现在能真的去做那件事，而不只是描述它。让它归档一条笔记、创建一项任务，或者跑一次搜索，它会自己挑选工具、调用它、把结果读回来，然后继续同一项任务的下一步。当某个工具调用解析不了时，它会直说。四项安排让这一切可靠起来，而随附的引擎则一举向前推进了两年份的上游工作，来到 b11057。工具箱如今真正处在握着它的模型的伸手可及之处。

**完好抵达的工具。** 协议放在提示词末尾，也就是截断最后才会触及的地方，于是模型去找这些指令时，它们还在那里。本地工具列表是每个工具一行，而不是各占一段，这样目录就能待在可用的空间之内；对话在发送出去之前会先裁剪到引擎的预算，因此历史记录挤不掉规则。工具结果以普通用户消息的形式、按提示词要求的格式返回，于是一项任务的第二步落在同一轮里，每一次调用都有结果记录。

**更新的引擎，恰好三处改动。** 随附引擎从 llama.cpp **b9888** 升到 **b11057**，这恰好需要三处 API 改动：mmap 标志变成了一种加载模式，多模态辅助函数多了一个选项参数，多模态输入文本现在自带长度，而不再用 `strlen` 去量。一个新的上游哈希依赖也随之链入。两份构建都把引擎钉在同一个修订版上，并从同一批 CMake 文件预取，因此 Android 与 Windows 之间共用同一个引擎。桌面端 GPU 引擎也拿到了与 CPU 端相同的 4096 上下文，而装不下的提示词会在日志里直说。

**小小的恩惠，放在该放的地方。** 在外观页面上，Material You 回到了主题与背景之上，而主题的简介只描述自己的颜色，不再重复说明自己是浅色还是深色。内置的 API 提供方只索取自己需要的东西；只有 Custom 会显示地址栏，而且它一开始是空的。附件行现在与截止日期行完全对齐，本地模型入口在每一台设备上都会出现。返回键会离开编辑器：当一条笔记或任务处于编辑状态时，返回手势会把你带回原来那张列表。拖动完全跟着手指走，一路穿过整张列表，而一次落空的长按不留痕迹——不压暗、不抬起、不投影，事后也没有任何东西需要关掉。

本地模型模块之外没有任何东西需要改动，而这正是关键：云端路径、工具本身以及你的数据，都不在这次迁移之内。你手机上的助手会读手册、挑工具，然后把它被要求做的事情做完。
