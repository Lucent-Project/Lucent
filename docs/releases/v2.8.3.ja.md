# スワイプが自然になる

ノートとタスクの間を行き来しながら、「ただ、スワイプできたら」と思った瞬間があるだろう。今はできる。下部バーはこれまでどおり使える——いくらでもタップすればいい、誰もそれを取り上げたりしない——それでいて、横にスワイプすればタブの間をすっと渡れるようになり、なぜ最初からそうなっていなかったのかと不思議になる。ページャーは居場所を保ち、どの画面にいたかを覚えていて、戻ってきたときにすべてを一から組み直したりはしない。一度使えば、初めからそこにあったとしか思えない、そういう機能だ。

動くものをこしらえている間に、テキストエディタにも静かだが同じくらい重要な改良が入った。入力欄がカーソルの位置を追い、キーボードの上に見えるようにスクロールする。見えないまま打つことも、キーボードがせり上がったあとに自分の居場所を探すことも、もうない。選択範囲の変更、削除、編集につきものの取り散らかりの中でも、スクロールはカーソルについてくる。だから見ている場所が、そのまま打ち込んでいる場所になる。

設定の各ページにも、ささやかなお祓いが入った。そのうちのいくつか——言語、テーマ、背景、記憶——は、本当の設定が届く前に一瞬 `null` になりうる初期値を使っていた。そのためページは、落ち着く前に半端に描かれた状態をちらつかせていた。今は、値が実際にそこに来るまで何も見せない。ちらつきも、描きかけのページもなく、ただ期待した設定が、期待したとおりの時に現れる。

バージョン 2.8.3 はリリースの流れそのものを世に送り出した。これ以降のリリースはすべて、APK と EXE が自動でビルドされ、アップロードされる。README はそれ自身の声で書き直した。製品の説明は製品のように響くべきだからだ。暗号化されたデータは今も暗号化され、バックアップは今もバックアップし、アシスタントは今も手を貸す——あなたを守るものについては何も変わっていない。変わったのは、毎日触れるものだけだ。

**タブ間をスワイプ**——HorizontalPager と状態同期、組み直しはゼロ。
**カーソルは視線を追う**——入力欄の自動スクロールが、居場所をキーボードの上に保つ。
**動かない設定**——本当の値が現れる前に、何もない画面がちらつくことはもうない。
**自動ビルド**——どのリリースも、手作業なしで APK と EXE を手にする。
**同じ暗号化、同じバックアップ、同じアシスタント、大事なものはすべて同じ。**
