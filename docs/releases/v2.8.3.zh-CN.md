# 滑动成为本能

你大概熟悉这样的时刻：在笔记与任务之间来回切换，心里想着“要是能直接滑一下就好了”。现在可以了。底部栏照旧好用——尽管点，谁也不会把它从你手里拿走——而现在，一次横向滑动就能带你穿行于各个标签页之间，流畅得让人纳闷它为什么不是一直就在那里。翻页器替你守着位置，记得你之前停在哪一屏，回来时也不会把一切推倒重来。这类功能，用过一次之后，就会觉得它本来就一直在那里。

在让东西动起来的同时，文本编辑器也得到了一项更安静、却同样重要的改进：输入框现在会跟踪光标的位置，并自动滚动，让光标留在键盘上方可见。不必再盲打，也不必在键盘弹出之后满屏找自己写到哪儿。无论是改变选区、删除内容，还是编辑时那些寻常的忙乱，滚动都跟着光标走，于是你看到的地方，永远就是你正在输入的地方。

设置页面也各自经历了一场小小的驱魔。其中有几个——语言、主题、背景、记忆——用到的初始值在真正的设置到达之前会短暂地为 `null`，于是页面会先闪出半渲染的状态，随后才安定下来。现在它们会等到值真正就位，再显示任何东西。没有闪烁，没有画了一半的页面，只有你预期的那项设置，在你预期的时候出现。

版本 2.8.3 也把发布流程带到了世上，此后每一个版本都会自动构建并上传自己的 APK 与 EXE。README 用自己的声音重写了一遍，因为产品说明本就该听起来像那个产品。你的加密数据依然加密，你的备份依然备份，你的助手依然协助——保护你的那些东西没有变，变的只是你每天触碰的那些。

**在标签页之间滑动**——采用 HorizontalPager 并同步状态，零重建。
**光标跟着视线走**——输入框自动滚动，让你的位置留在键盘上方。
**不再跳动的设置**——真正的值出现之前，不会再闪过一片空白。
**自动化构建**——每个版本都无需人工，就拿到自己的 APK 与 EXE。
**同样的加密，同样的备份，同样的助手，同样是一切要紧的东西。**
