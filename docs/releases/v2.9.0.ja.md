# 権限、来歴、そしてより静かな更新

Lucent 2.9.0 は、設定の一番下に扉をひとつ加える。その奥にあるのは、ふだんはデスクトップのシェルに属する種類の権限である。扉は既定では閉じている。そこが肝心だ。その隣で、「アプリについて」のページが、誰がこれを作り、何から組み立てられ、あなたがどのバージョンを手にしているかを記す——四つの言語で、小さな活字で、行儀よく育てられたアプリがするように。どちらのページも声を張らない。どちらも荷重を支えている。

**「詳細設定」のページは、求めに応じて鍵を手渡す。** 設定 → 詳細設定の最上部にはスイッチがひとつだけあり、あなたが入れるまで切れている。それを入れると、Lucent は Shizuku にシェルの身元を尋ねる。ページは、Shizuku が導入されているか、そのサービスが動いているか、権限がすでに与えられているかを報告し、足りないものに対してボタンをただひとつ差し出す——Shizuku を入手する、開く、あるいは許可する。特権を要する操作はどれも同じスイッチの後ろで待っている。いったん特権が与えられれば、ページは uid を記すので、adb の 2000 と root の 0 はひと目で見分けられる。

**「アプリについて」のページは証憑を残す。** バージョンとビルド番号、著作権の行、開発者の名前が、Lucent が抱えるすべてのオープンソースコンポーネントの目録の上に並ぶ——Kotlin、Compose、SQLCipher、llama.cpp、Shizuku、そのほか——それぞれに権利者と、ライセンス全文へのリンクが付く。長い法的段落は画面には出さず、それらのリンクの向こうに置く。そこが本来の居場所だからだ。ホームページ、サポートの宛先、そして完全な第三者への告知が、同じ小さな活字で続く。そこにあるものはすべて、講釈ではなくリンクである。

**更新は、インストーラーの行列なしに届くことがある。** 「アプリについて」のページにある二つ目のスイッチは既定で切れており、入れると自動更新が有効になる。入れておけば、起動のたびに GitHub へ最新の公開リリースを尋ね、手元のバージョンと比べ、新しいものがあれば、何かをする前に確認を求める。承諾すれば、Lucent は APK をダウンロードし、Shizuku に渡して静かにインストールする。その特権がなければ、それは脇へ退き、システムのパッケージインストーラーに任せる。同じ道筋が、デスクトップでは Windows インストーラーを取ってくる。

**設定のページは、あなたの値のまま開く。** 設定の中のスイッチも選択も、最初の一フレームから、あなたが選んだとおりに表示される。だからページは、あなたが離れたときのままの姿をしている。下部のバーでは、タブを叩けばそのタブへまっすぐ移り、スワイプに属するような横の移動はない。四つの言語の目録がそのすべてを覆う——English、中文、日本語、한국어——新しいページも、特権についての一行一行も。

ここにあるものは、どれもあなたに代わって入れてあるわけではない。それが 2.9.0 の形だ。権限は掛け金の向こうに置かれ、来歴は書き留められ、更新は求められたときに静かに届く。あなたのノートは暗号化されたままで、.lcb のバックアップはこれらの設定をひとつ残らず携えていき、扉はあなたが開けるものだ。
