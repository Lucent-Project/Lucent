# 权限、出处，以及一次更安静的更新

Lucent 2.9.0 在设置的最下面添了一扇门，门后是通常属于桌面 shell 的那一类权限。它默认关着，而这一点正是关键。门旁边，关于页面写明这是谁做的、由什么构成、你手上是哪一个版本——用四种语言，用小字，像一个有教养的应用那样。两页都不喧哗。两页都承重。

**高级页面按你的要求把钥匙交给你。** 在设置 → 高级的顶部有一个开关，在你打开它之前一直关着。拨动它，Lucent 会向 Shizuku 索取 shell 的身份。页面会报告 Shizuku 是否已安装、它的服务是否在运行、权限是否已经授予，然后针对缺失的那一项只给一个按钮：获取 Shizuku、打开它，或授予。每一项需要特权的操作都等在这同一个开关之后；特权一旦授予，页面会写出 uid，于是 adb 的 2000 与 root 的 0 一眼就能分清。

**关于页面留有凭据。** 版本与构建号、版权行、开发者的名字，排在 Lucent 所携带的每一个开源组件目录之上——Kotlin、Compose、SQLCipher、llama.cpp、Shizuku，以及其他——每一项都附有持有人和通往完整许可证的链接。冗长的法律段落留在屏幕之外、留在那些链接之后，它们本来就属于那里。主页、支持地址，以及完整的第三方声明，同样以小字跟在后面。页面上的一切都是链接，而不是说教。

**更新可以不必有安装程序的仪仗。** 关于页面上的第二个开关默认关闭，打开它便启用自动更新。开启之后，每次启动都会向 GitHub 询问最新发布的版本，与你手上的版本比较，若有更新的版本，先问过你再行动。你说好，Lucent 便下载 APK，交给 Shizuku，静默安装。没有那份特权时，它退到一边，让系统包安装器接手；同一条路径在桌面上取回 Windows 安装程序。

**设置页面一打开就是你的选择。** 设置里的每一个开关、每一项选择，从第一帧起就已经显示你选定的样子，于是页面看起来和你离开时一样。在底部栏上，轻点某个标签会直接切到那个标签，没有那种属于滑动的横向位移。四语目录覆盖了这一切——English、中文、日本語、한국어——包括新的页面和每一行关于权限的文字。

这里没有任何东西是替你打开的。这就是 2.9.0 的形状：权限留在门闩之后，出处写下来，更新在被要求时安静地到来。你的笔记保持加密，一份 .lcb 备份把这些设置一并带走，而那扇门由你来开。
