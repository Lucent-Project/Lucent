# ペンと、番人と、居場所を覚えているページ

Lucent 2.9.1 は、小さな気配りのリリースである。離れたときのページは戻ればそこにあり、スイッチは自分の意見ではなくあなたの設定を映し、ペンが名前を書いてからインクを静かに逃がしていく。

**「外観」に筆記体が加わる。** 設定 → 外観に「起動アニメーション」のページが増えた。最上部にスイッチがひとつ、その下に二つの選択肢。ねこは手を振り、まばたきし、ガラスになって、既定のまま残る。ペンは新顔だ。左から入ってきて、中央に Lucent を筆記体で書き、インクを淡く消していき、あなたのメモだけを残す。スイッチを切れば、Lucent はあなたの作業へまっすぐ進み、読み込みの間はテーマと動く背景だけを見せる。

**設定はあなたの値のまま開く。** 自動バックアップのスイッチもクラウドの各欄も、設定ページが共有する同じキャッシュから状態を取るので、ページは現れた瞬間からあなたの選択を映している。間隔のボタンも保持数のステッパーも同じだ。クラウドも同じく控えめで、スイッチが切れている間、下の行は呼ばれるまで脇に控える。

**タブは離れた場所に着く。** タブを叩けば同じフレームでそのページに入り、しかも前回いたページに入る。積み重ねの一番上ではない。書きかけのメモを残してアシスタントへ、あるいは設定の下位ページを残してメモへ、戻ればそのままの姿で見つかる。あなたに代わって保存もせず、捨てもしない。静かな保存の問いは、アプリを離れるその瞬間のために取ってある。

**API ページは、あなたが求めるまで書き留めない。** モデルの取得と選択は下書きに置かれるだけになり、名前、提供元、アドレス、鍵、モデルの一覧は「API を保存」を押したときにまとめて書き込まれる。未保存の間は小さな一行がそう告げる。

**エディタはキーボードに追いつく。** カーソルが動くと書き込み欄がキーボードの上へ浮き、編集中の行は見えたままになる。保存ボタンはプラス記号を落として文字を中央に据え、隣の下書きボタンもカプセルの真ん中に収まる。

**Shizuku には番人がつく。** 詳細設定のスイッチが入っている間、Lucent は一分ごとに Shizuku の様子を尋ねる。返事が途切れれば、スイッチは自ら切れ、見つけた状況に合わせた案内が出る。入っていなければ公式の GitHub リリースをブラウザへ渡し、止まっていれば開くことを申し出し、動いていて権限がなければ権限を求め、確認は Shizuku 自身のダイアログに委ねる。スイッチが切れれば、番人は呼び戻されるまで下がる。

**更新は後片付けをする。** 更新は静かにダウンロードされ、あなたが頷いたときにインストールされ、終われば自分のインストーラーを片づける。二十分以内にファイルが揃わなければ、Lucent は欠けた断片を消してそう告げる。「あとで」を選べば、次にアプリを開いたときにまた尋ねる。「更新を確認」の下の小さな一行は、三秒で消える。

**アシスタントは、自分が今つくったものを手放さない。** 作成・変更した項目は会話に添えた短い一覧に残るので、「それに一行足して」が正しいメモに届く。題名は文字どおりではなく意味で照合し、見つからなければ近い実在の題名を並べる。

**細やかな手入れ。** ログを消去すると記録も止まり、消したログは再び入れるまで消えたままになる。小規模モデル向けの最適化は、アシスタントの残りの気質とともに「パーソナライズ」へ移った。設定はページごとに居場所を覚えている。フォントの一覧は一行減り、インポートのボタンは場所を半分にした。

メモは端末上で暗号化されたまま、.lcb バックアップはこれらの選択をひとつ残らず携え、ログは一歩ずつを記録し続ける。
