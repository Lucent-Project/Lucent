# 펜과, 파수꾼과, 자리를 기억하는 페이지

Lucent 2.9.1은 작은 배려에 관한 릴리스다. 떠날 때의 페이지는 돌아오면 그대로 있고, 스위치는 자기 생각이 아니라 당신의 설정을 보여 주며, 펜은 이름을 쓰고 나서 잉크를 조용히 흘려보낸다.

**외관에 필기체가 들어온다.** 설정 → 외관에 시작 애니메이션 페이지가 생겼다. 맨 위에 스위치가 하나, 그 아래에 두 가지 선택. 고양이는 손을 흔들고 눈을 깜빡이고 유리가 되며, 기본값으로 남는다. 펜은 새로 온 쪽이다. 왼쪽에서 들어와 가운데에 Lucent를 필기체로 쓰고, 잉크를 옅게 지워 당신의 노트만 남긴다. 스위치를 끄면 Lucent는 곧바로 당신의 작업으로 들어가고, 불러오는 동안에는 테마와 움직이는 배경만 보여 준다.

**설정은 당신의 값으로 열린다.** 자동 백업 스위치와 클라우드 항목들은 설정 페이지가 함께 쓰는 같은 캐시에서 상태를 가져오므로, 페이지는 나타나는 순간 이미 당신의 선택을 담고 있다. 간격 버튼과 보관 개수 스테퍼도 마찬가지다. 클라우드도 한결 조용하다. 스위치가 꺼져 있는 동안 아래 줄들은 불릴 때까지 비켜 서 있다.

**탭은 떠난 자리에 도착한다.** 탭을 누르면 같은 프레임에 그 페이지로 들어가고, 게다가 지난번에 있던 페이지로 들어간다. 더미의 맨 위가 아니라. 쓰다 만 노트를 두고 어시스턴트로, 혹은 설정 하위 페이지를 두고 노트로 갔다가 돌아오면 그대로 있다. 당신 대신 저장하지도, 버리지도 않는다. 조용한 저장 확인은 앱을 실제로 떠나는 순간을 위해 남겨 둔다.

**API 페이지는 청하기 전에는 쓰지 않는다.** 모델을 가져오고 고르는 일은 이제 초안에만 담긴다. 이름, 제공자, 주소, 키, 모델 목록은 API 저장을 누를 때 함께 기록되며, 저장 전에는 작은 한 줄이 그렇게 알린다.

**편집 화면은 키보드를 따라간다.** 커서가 움직이면 쓰는 칸이 키보드 위로 올라가, 고치고 있는 줄이 계속 보인다. 저장 버튼은 더하기 표시를 내려놓고 글자를 가운데에 앉혔고, 옆의 임시 저장 버튼도 캡슐 한가운데에 놓인다.

**Shizuku에게 파수꾼이 생긴다.** 고급 스위치가 켜져 있는 동안 Lucent는 1분마다 Shizuku의 안부를 묻는다. 대답이 끊기면 스위치는 스스로 꺼지고, 발견한 상황에 맞춘 안내가 뜬다. 설치되어 있지 않으면 공식 GitHub 릴리스를 브라우저로 넘기고, 멈춰 있으면 열어 보자고 하고, 돌고 있지만 권한이 없으면 권한을 청하며, 확인은 Shizuku 자신의 대화상자에 맡긴다. 스위치가 꺼지면 파수꾼은 다시 불릴 때까지 물러난다.

**업데이트는 뒷정리를 한다.** 업데이트는 조용히 내려받고, 당신이 허락할 때 설치되며, 끝나면 자기 설치 파일을 치운다. 20분 안에 파일이 다 오지 않으면 Lucent는 잘린 조각을 지우고 그렇게 알린다. "나중에"를 고르면 다음에 앱을 열 때 다시 묻는다. 업데이트 확인 아래의 작은 한 줄은 이제 3초 뒤 사라진다.

**어시스턴트는 방금 만든 것을 놓지 않는다.** 만들거나 고친 항목은 대화에 딸린 짧은 목록에 남아, "거기에 한 줄 추가해"가 알맞은 노트를 찾는다. 제목은 글자 그대로가 아니라 뜻으로 맞추고, 빗나가면 가장 가까운 실제 제목을 알려 준다.

**자잘한 손질.** 로그를 지우면 기록도 함께 멈추므로, 지운 로그는 다시 켤 때까지 빈 채로 남는다. 소형 모델 최적화는 어시스턴트의 나머지 성향이 있는 개인 설정으로 옮겼다. 설정은 페이지마다 있던 자리를 기억한다. 글꼴 목록은 한 줄을 덜어냈고, 가져오기 버튼은 자리의 절반만 차지한다.

노트는 기기에서 암호화된 채로 남고, .lcb 백업은 이 선택들을 하나도 빠뜨리지 않고 함께 지니며, 로그는 걸음마다 기록을 남긴다.
