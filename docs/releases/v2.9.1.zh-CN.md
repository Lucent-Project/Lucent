# 钢笔、守望者，以及记得住来处的页面

Lucent 2.9.1 是一份关于小小体贴的更新：你离开时的那一页，回来还在；开关显示的是你的选择，而不是它自己的主张；一支笔写下名字，再让墨迹慢慢散去。

**外观里添了书法。** 设置 → 外观新增「开屏动画」一页。最上方是一个开关，下面两个选项。小猫招手、眨眼、化作玻璃，依旧是默认的那一个。钢笔是新来的：它从左侧入场，居中把 Lucent 写成花体，再让墨色淡去，只留下你的笔记。关掉开关，Lucent 直接进入你的工作，加载期间只显示主题与流动的背景。

**设置一打开就是你的值。** 自动备份开关与云存储各项字段，都取自设置页面共用的同一份缓存，因此页面一出现便已是你的选择；间隔按钮与保留份数一并如此。云存储同样收敛：开关未开时，下方的各项都安静地让开，等你需要时再出现。

**标签页落在你离开的地方。** 轻点标签，同一帧内便进入该页，而且进入的是你上次停留的那一页，而非列表顶端。为助手放下一半的笔记，或为笔记放下一层设置子页，回来时都原样还在。不会替你保存，也不会替你丢弃；那句轻声的保存提醒，留给你真正走出应用的那一刻。

**API 页面等你开口才落笔。** 抓取与挑选模型如今只写进草稿；名称、提供方、地址、密钥与模型清单，都在你点击「保存 API」时一并写入，未保存期间会有一行小字如实相告。

**编辑页跟得上键盘。** 光标移动时，书写区域会抬到键盘之上，正在修改的那一行始终看得见。保存按钮摘掉了加号，文字居中；旁边的草稿按钮，也正正地落在胶囊中央。

**Shizuku 有了一位守望者。** 高级开关开启期间，Lucent 每分钟问候 Shizuku 一次。问候落空时，开关自动关闭，弹窗说明该怎么做，并且依所见的状况而定：未安装，便把官方 GitHub 发布页交给浏览器；未启动，便提出打开它；已启动而未授权，便去索取权限，确认交给 Shizuku 自己的弹窗。开关一关，守望者便退下，直到你再次唤他。

**更新会自己收拾。** 更新静静下载，等你点头才安装，装完把自己的安装包删掉。若二十分钟内没能下载完整，Lucent 会清除残缺的文件并如实相告。选择「稍后」，下次打开应用时它会再问一次。「检查更新」下面那行小字，现在三秒后自行隐去。

**助手记得住它刚做的东西。** 它新建或改动过的条目，会留在随对话携带的一份短名单上，于是「给它加一行」能找到那张笔记；标题按含义匹配，而不是逐字比对，落空时也会列出最接近的真实标题。

**细处的打理。** 清除日志的同时也会停止记录，于是清空之后保持清空，直到你重新开启。针对小模型优化移到了个性化设置，与助手的其余性情放在一处。设置会记住你所在的位置，逐页记住。字体列表少了一行，导入按钮只占原来一半的地方。

你的笔记依旧在本机加密，一份 .lcb 备份把这些选择一并带走，日志也仍旧记下每一步。
