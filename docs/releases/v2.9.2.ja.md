# タスクとメモが同じ部屋に引っ越し、ライブラリには引き出しができました

Lucent 2.9.2 は家具の配置換えです。何も捨ててはいません。それぞれに自分の部屋が与えられ、部屋同士が、分別のある人が歩く順番でつながりました。

**ホームには二つのリストが住んでいます。** Android の最初のタブはホームになり、タスクとメモが並んで暮らしています。ページ上部には二つのラベルがあり、それぞれの横に小さな点があります。塗りつぶされた点が現在地の印です。もう一方をタップすると、ページは 4 分の 1 秒で横に滑り、どちらのリストも離れたときのままです。書きかけのメモも、スクロール位置も、開いた詳細も。ホームは最後に使った方を覚えていて、次回はそこから開きます。

**引き出しにはライブラリがあります。** 左上の三本線を押すと、左端からすりガラスのパネルが現れます。中身は順に、ノートブック、下書き、アーカイブ、ゴミ箱、そして開いたことがあれば非表示。各行には控えめな件数が添えられ、一覧は今のモードに従います。メモではアーカイブ済みのメモ、タスクでは完了したタスクです。引き出しの上部にも同じ二つの点があるので、閉じずにリストを切り替えられます。戻るボタンは、何よりも先に引き出しを閉じます。

**ノートブックに専用のタブができました。** 二番目のタブはノートブックで、作成したすべてのノートブックと、上部に合計数が並びます。ノートブックからメモやタスクを開いて閉じると、中身を広げたままのノートブックにそのまま戻ります。ノートブックやアシスタントで戻るボタンを押すと、アプリを閉じるのではなくホームへ戻ります。

**検索は一つ、並びは的確に。** ホームの検索欄はあなたについて回ります。タスクで語句を入力してメモに切り替えても、言葉は一緒に来ます。見ているリストの結果が先頭に並び、はっきりした区切り線の下に、Lucent が知っている残りのすべてが続きます。どれもスクロール一回分の距離です。

**Windows のサイドバーは少し長くなりました。** デスクトップのサイドバーは、タスクとメモ、次にノートブック、下書き、アーカイブ、ゴミ箱、そしてアシスタント、検索、概要、設定の三つのまとまりで並びます。下書き、アーカイブ、ゴミ箱には同じ二つの点があり、一つのページでメモとタスクの両方を扱えます。アーカイブしたメモを開いて閉じるとアーカイブに戻り、下書きはそのままエディターで開きます。

**点検はより念入りに。** すべての変更は、お手元に届く前により長い検査を通ります。共有ロジックは一つのテスト群で Android とデスクトップの両方で試験され、デスクトップのテストは Windows 上でも実行されます。暗号化は Linux と Windows の両方でエンドツーエンドに証明され、整頓チェックが括弧の対応とファイルの大きさを確かめます。各実行の最後には、試験内容の整った表が添えられます。

メモは引き続き端末上で暗号化され、.lcb バックアップは最後に開いていたページを含むすべての設定を運びます。ログは新しい部屋での一歩一歩を記録します。モードの切り替えも、引き出しを開いたことも、開いたページも。
