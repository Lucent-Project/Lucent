# 任务与笔记搬到了一起，资料库也有了抽屉

Lucent 2.9.2 重新摆放了家具。什么都没有扔掉，只是每样东西都有了自己的房间，而这些房间按照一个讲究的人会走的顺序连在了一起。

**首页是两份清单的家。** 安卓上的第一个标签现在叫首页，任务和笔记并排住在这里。页面顶部有两个标签，各自旁边一个小圆点，实心的那个标明你所在的位置。点一下另一个，页面在四分之一秒内滑过去，每份清单都保持你离开时的样子：写到一半的笔记、滚动的位置、打开的详情。首页记得你上次用的是哪一个，下次就从那里打开。

**抽屉里放着资料库。** 左上角的三条横线会从左边缘拉出一块磨砂面板。里面依次是：笔记本、草稿、存档、回收站，以及你打开过的隐藏区。每一行都带着一个安静的计数，列表会跟随你当前的模式：在笔记下，存档是已归档的笔记；在任务下，则是已完成的任务。抽屉顶部也有同样的两个圆点，想不关抽屉就换清单也可以。返回键会先关上抽屉，再做别的事。

**笔记本有了自己的标签。** 第二个标签是笔记本，里面是你建过的所有笔记本，顶部还有一个总数。从笔记本里打开一条笔记或任务，关掉后会直接回到那个笔记本，内容依旧展开着。在笔记本或助手页按返回键，会带你回到首页，而不是退出应用。

**一个搜索，顺序得当。** 首页的搜索框现在会跟着你走：在任务下输入关键词，切到笔记，文字也一起过来。你正在看的清单的结果排在最前；一条清晰的分隔线之下，是 Lucent 知道的其余一切，任何东西都不过一次滚动之遥。

**Windows 的侧边栏更长了。** 桌面端侧边栏现在依次是任务和笔记，然后是笔记本、草稿、存档、回收站，再是助手、搜索、概览和设置，分成整齐的三组。草稿、存档和回收站各带同样的一对圆点，一页同时照顾笔记和任务。打开一条已归档的笔记再关掉，会回到存档页；草稿则直接在编辑器里打开。

**检查更加周全。** 每一处改动在到达你手上之前都要经过一轮更长的检验。共享逻辑用同一套测试在安卓和桌面端各跑一遍，桌面端测试还会在 Windows 上亲自运行，加密在 Linux 和 Windows 上都做端到端验证，一次整洁度检查确认括号成对、文件大小合理。每次运行最后都会给出一张整齐的测试清单。

你的笔记依旧加密保存在设备上，.lcb 备份会带上所有设置，包括你上次打开的页面；日志会记录你在新房间里的每一步：每次切换模式、每次打开抽屉、每个打开的页面。
