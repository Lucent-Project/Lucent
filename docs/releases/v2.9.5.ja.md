# ノートブックに本棚ができ、執事は筆を取る

Lucent 2.9.5 は、ノートブックがただの一覧から本棚になる版です。5 色の表紙、背表紙の下に刷られた名前、検索欄、日付フィルターと並べ替えとゴミ箱を開くシェブロン、そしてドラッグで書架そのものを並べ替えられます。執事も筆を取れるようになりました。クラウドとローカル、それぞれにスイッチがあり、どちらでも文字の書式を整えられます。

**ノートブックは本であり、本棚はあなたが整えるもの。** ノートブックは表紙のグリッドで開きます。クリムゾン、オーシャン、フォレスト、アンバー、プラムの 5 色で、作成時に選び、あとから変更もできます。名前は表紙の下、項目数はそのまた下に。最上段はメモとタスクのページと同じ検索欄、同じシェブロン、同じ丸いプラスボタンで、3 ページがピクセル単位で揃います。シェブロンの奥には日付フィルター、4 つの並べ替え、ゴミ箱があります。本をドラッグすると棚が隙間を埋め、並べ替えは自動的にカスタムへ切り替わります。削除したノートブックは専用のゴミ箱で 30 日待ち、復元すればまとめていた項目もいっしょに戻ります。

**ノートブックの中で書け、すべてが同期します。** プラスボタンから、その場でメモやタスクを作れます。ノートブックの中で作ったメモはごく普通のメモです。保存した瞬間にメモのページ、検索、ウィジェット、そしてあらゆるバックアップに現れます。実体は常に一つだけだからです。そこで編集し、隠し、削除すれば、アプリの他の場所もすぐに追従します。各行には編集・ノートブックから外す・削除のメニューがあり、このページを離れずに整理できます。

**執事には二つのモードがあり、それぞれが自分で決めます。** エージェントモードはスイッチになり、しかも二つあります。クラウドモデルのページに一つ、ローカルモデルのページに一つ。オンなら、考え、ツールを呼び、各手順を表示します。オフなら、プロバイダー既定の推論のまま、ツールの往復を挟まず最速で答えます。二つのモデルはもう互いを待ちません。それぞれが自分の記憶を持ち、クラウドは検索と API プロファイルを、ローカルはウェブ検索、GPU、ツールのスイッチを保ち、片方が動く間もう片方を凍結していた仕組みは取り除かれました。ローカルモデルはクラウドと同じツール一式を備えています。

**執事は文字を整えられ、設定は今どこにいるかを告げます。** リッチテキストのツールが揃いました。太字、細字、斜体、ハイライト色、文字色を、指定した語句にぴたりと適用できます。メモでもタスクでも同じです。末尾に文章を足しても元の内容は乱れず、項目を隠し、戻し、並べ替え、Markdown・リッチテキスト・自動のいずれかで表示できます。ノートブックにも表紙の色、棚の順序、ゴミ箱がつきました。設定の見出しは階層をたどって追随します。設定、外観、起動アニメーション。どの語もひとつ上の階層へのリンクで、未保存の変更を残したまま離れようとすると先に確認します。Material You カラーをオンにすると、テーマと背景は灰色になるのではなく、そっと道を譲ります。更新カードから GitHub の更新内容へ飛べるようになり、プライバシーポリシーは 4 言語で公開され、「アプリについて」から一度のタップで読めます。

起動アニメーションも画面を独占します。動く背景はアニメーションの終了を待ってから流れ始めるので、最初の数秒はなめらかなままです。残ったのは、手に取れるノートブック、そこに分類も筆もできる執事、そしてようやく並行して働く二つのモデルです。
