# The Notebooks Get Their Shelf, and the Butler Picks Up a Brush

Lucent 2.9.5 is the release where notebooks stop being a list and become a shelf: five cover colours, a name under every spine, a search field, a chevron that opens the date filter and the sort and the bin, and a drag that rearranges the library by hand. The assistant has learned to hold a brush, on either model, each with its own switch.

**A notebook is a book, and the shelf is yours to arrange.** Notebooks open on a grid of covers now: crimson, ocean, forest, amber or plum, chosen when the notebook is made and changeable afterwards, the name printed underneath and the item count below it. The top row carries the same search field, chevron and round plus button as the notes and tasks pages, so the three line up to the pixel. Behind the chevron sit the date filter, four sort orders and the trash. Drag a book and the shelf closes the gap behind it, flipping the sort to Custom. Deleted notebooks wait in their own bin for 30 days.

**You can write inside a notebook, and everything stays in step.** The plus button offers a note or a task, written where you are standing. A note made inside a notebook is an ordinary note: it appears on the notes page, in search, in the widget and in every backup the moment it is saved, because there is only ever one copy of it. Edit it, hide it or delete it from there and the rest of the app follows at once. Each row carries a menu with Edit, Remove from notebook and Delete.

**The assistant runs in two modes now, on its own terms.** Agent mode has become a switch, and there are two: one on the cloud model page, one on the local model page. On, the assistant thinks, calls its tools and shows every step. Off, it answers as fast as the provider's own reasoning allows, with no tool round trip in the way. Each model keeps its own memory now, the cloud its search and API profiles, the local model its web search, GPU and tool switches, and the freeze that locked one while the other ran is gone. The local model carries the cloud's whole tool set.

**The assistant can style your writing, and Settings now says where you are.** Bold, light, italic, a highlighter colour and a text colour can be set on the exact words you name, in a note or a task. Text can be appended, an item hidden, unhidden or reordered, and a note shown as Markdown, rich text or automatic. Notebooks are covered too, with cover colours, shelf order and their bin. The settings header follows you down the tree, each word a link back up, and asks before leaving unsaved edits behind. Turn Material You colours on and the theme and background rows step out of the way.

The animated backdrop also waits for the opening animation to finish before it starts moving, so the first seconds stay smooth. The update card links to the release notes on GitHub, and the privacy policy ships in all four languages, one tap from About. What is left is a notebook you can hold and an assistant that can write in it.
