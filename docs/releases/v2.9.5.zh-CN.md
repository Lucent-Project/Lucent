# 笔记本有了书架，助手握起了画笔

Lucent 2.9.5 让笔记本不再只是一张列表，而是一排书架：五种封面颜色、书脊下写着名字、一个搜索框、一个展开日期筛选与排序与回收站的箭头，还有拖动就能亲手重新排布整个书架。助手也学会握笔了——云端与本地各自拥有开关，都能为你的文字设置格式。

**笔记本就是一本书，书架由你摆。** 笔记本现在以封面网格打开：绯红、海洋蓝、森林绿、琥珀或李子紫，新建时挑选，之后也能更换；名字印在封面下方，条目数量再下一行。顶部一行与笔记、任务页完全一致——同一个搜索框、同一个箭头、同一个圆形加号，三页对齐到像素。箭头后面是日期筛选、四种排序和回收站。拖动一本书，书架会合上它留下的空隙，排序自动切到自定义，与笔记和任务列表的做法一致。删除的笔记本在自己的回收站里等候 30 天，恢复时连里面归组的条目一起回来。

**可以直接在笔记本里写作，一切保持同步。** 加号按钮现在可以就地新建笔记或任务。在笔记本里写下的笔记就是普通笔记：保存的那一刻，它就出现在笔记页、搜索结果、桌面小组件和每一份备份里——因为它始终只有一份。在这里编辑、隐藏或删除，软件其它地方立刻同步。每一行都带一个菜单：编辑、移出笔记本、删除，不用离开这一页就能整理好整个文件夹。

**助手现在有两种模式，各自说了算。** Agent 模式变成了开关，而且有两个：云端模型页一个，本地模型页一个。打开时，助手会思考、调用工具并展示每一步；关闭时，它以服务商默认的推理程度尽快作答，不再有工具往返的等待。两个模型不再互相等待：各自记住自己的记忆设置，云端保留自己的搜索与 API 配置，本地模型保留自己的联网、GPU 与工具开关，原本一方运行时冻结另一方的逻辑已经删除。本地模型现在拥有与云端完全相同的工具集。

**助手能为你的文字排版，设置页也会告诉你身在何处。** 富文本工具到齐了：加粗、细体、斜体、高亮色与文字颜色，都能精确地加在你指定的字句上，笔记与任务皆可。可以往末尾追加文字而不打扰原有内容，可以隐藏、取消隐藏或移动顺序，也可以把笔记或任务显示为 Markdown、富文本或自动。笔记本也有份：封面颜色、书架顺序与回收站。设置页的标题会跟着你沿层级深入——设置、外观、开屏动画，每个词都能点回上一层——离开有未保存改动的页面前会先询问。开启 Material You 动态取色后，主题与背景不再是变灰，而是直接让位。更新卡片提供前往 GitHub 查看更新内容的链接，隐私政策以四种语言发布，在"关于"里一点即达。

开屏动画同样独占屏幕：动态背景会等开屏结束再开始流动，最初几秒因此平滑如初。留下的，是一本握得住的笔记本、一个既能为它归类也能为它落笔的助手，以及两个终于并行工作的模型。
