# ノートブックに長押しが入り、アシスタントが思考の深さを選ぶ

Lucent 2.9.6 は、ノートブックの長押しが他の場所の長押しと同じ働きをする版です。アシスタントも、どれだけ考えるかを推測するのをやめました。各プロバイダー自身の言葉で尋ね、選ぶのはあなたです。

**ノートブックの長押しは、メモと同じになりました。** 表紙を長押しすると本棚が選択モードに入ります。件数が表示され、触れたノートブックがまとまり、バーには固定・全選択・ゴミ箱が並びます。複数の本は一山としてまとめてドラッグでき、並べ替えはこれまでどおり自動でカスタムに切り替わります。ドラッグ中に本の下に出ていた浮き上がりの影は取り除き、表紙は平らに移動します。固定もノートブックの新機能です。どの並べ替えを選んでも固定した本は本棚の先頭に残り、メニューからも選択からも固定できます。

**アシスタントの思考の深さは、各社の言い方で指定できます。** OpenAI のエンドポイントは reasoning_effort を受け取り、オフから最小・低・中・高まで選べます。Claude はトークン予算つきの拡張思考、Gemini はゼロも含む思考予算です。チャット画面のクリップの隣のボタンには、選んだプロバイダーが公開している段階だけが並びます。選択はメッセージごとではなくアプリ全体で記憶されます。公開 API にこのパラメータがないプロバイダーは正直にそう伝え、カスタム接続先には reasoning_effort を送りますが、無視される可能性も添えます。

**ウェブ検索のスイッチは一つ、その背後にエンジンが十。** ウェブ検索はパーソナライズだけに置かれ、隣でエンジンを選びます。Bing、DuckDuckGo、Google、Brave、Yandex、Mojeek、Baidu、Sogou、360 検索、Wikipedia、そして「自動」——自動は順に試し、質問が中国語なら中国語のエンジンを先に、そうでなければ他を先に試します。ローカルモデルをエージェントモードなしで使っている間は、スイッチもエンジンも隠れます。使い道がないからで、条件が変われば元のまま戻ります。

**記憶はクラウドが三段階、ローカルが二段階。** クラウドのアシスタントは会話をまたいで覚えるか、この会話を覚えるか、目の前の一件だけに答えるかを選べます。ローカルモデルは強と弱、つまり会話全体か一件かです。エージェントモードはパーソナライズの打鍵ハプティクスの下へ移り、応答しているモデルに適用されます。アシスタントのページではクラウドモデルとローカルモデルの右側にそれぞれスイッチが付き、排他的です。片方をオンにすると、もう片方は凍結ではなくオフになります。

自動更新はオンであれば十分ごとに確認し、更新後は Android が許す端末では Lucent がひとりでに開き直り、許さない端末ではワンタップで開けます。クラウドのアシスタントはこれまでどおりバックグラウンドで働き続け、探すべきスイッチはありません。リポジトリのルートも整理し、ドキュメントは docs へ、プライバシーポリシーは専用のフォルダーへ移りました。
