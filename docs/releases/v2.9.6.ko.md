# 노트북은 길게 누르기를 배우고, 어시스턴트는 생각의 깊이를 고른다

Lucent 2.9.6은 노트북을 길게 누르면 다른 곳에서 길게 누르는 것과 같은 일이 일어나는 버전입니다. 어시스턴트도 얼마나 깊이 생각할지 스스로 짐작하는 것을 그만두었습니다. 각 제공자 자신의 표현으로 묻고, 고르는 것은 당신입니다.

**노트북의 길게 누르기가 이제 노트와 같습니다.** 표지를 길게 누르면 책장이 선택 모드로 들어갑니다. 개수가 표시되고, 만진 노트북이 함께 묶이며, 막대에는 고정, 전체 선택, 휴지통이 있습니다. 여러 권을 한 묶음으로 끌 수 있고, 정렬은 늘 그렇듯 자동으로 사용자 지정으로 바뀝니다. 끌 때 책 아래에 깔리던 떠오름 그림자는 없애 표지가 평평하게 움직입니다. 고정도 노트북의 새 기능입니다. 어떤 정렬을 고르든 고정한 책은 책장 맨 앞에 남고, 메뉴에서도 선택 상태에서도 고정할 수 있습니다.

**어시스턴트의 생각 깊이는 각 사의 방식대로 지정합니다.** OpenAI 엔드포인트는 reasoning_effort를 받으며 끔부터 최소, 낮음, 보통, 높음까지 있습니다. Claude는 토큰 예산이 있는 확장 사고를, Gemini는 0도 포함하는 사고 예산을 씁니다. 채팅 화면의 클립 옆 버튼에는 선택한 제공자가 공개한 단계만 나옵니다. 선택은 메시지마다가 아니라 앱 전체에 기억됩니다. 공개 API에 이런 파라미터가 없는 제공자는 솔직히 그렇게 알리고, 사용자 지정 엔드포인트에는 reasoning_effort를 보내되 무시될 수 있다는 점도 함께 적습니다.

**웹 검색 스위치는 하나, 그 뒤에 엔진이 열.** 웹 검색은 이제 개인화에만 있고, 옆에서 엔진을 고릅니다. Bing, DuckDuckGo, Google, Brave, Yandex, Mojeek, Baidu, Sogou, 360 검색, Wikipedia, 그리고 '자동'입니다. 자동은 차례로 시도하며, 질문이 중국어면 중국어 엔진을 먼저, 아니면 나머지를 먼저 시도합니다. 로컬 모델을 에이전트 모드 없이 쓰는 동안에는 스위치도 엔진도 숨겨집니다. 쓸 곳이 없기 때문이며, 조건이 풀리면 그대로 돌아옵니다.

**기억은 클라우드가 세 단계, 로컬이 두 단계입니다.** 클라우드 어시스턴트는 대화를 넘어 기억하거나, 이 대화를 기억하거나, 눈앞의 한 메시지에만 답할 수 있습니다. 로컬 모델은 강과 약, 즉 대화 전체와 한 메시지입니다. 에이전트 모드는 개인화의 타이핑 햅틱 아래로 옮겨졌고, 답하는 모델에 적용됩니다. 어시스턴트 페이지에는 클라우드 모델과 로컬 모델 오른쪽에 각각 스위치가 있고 서로 배타적입니다. 하나를 켜면 다른 하나는 얼어붙는 대신 꺼집니다.

자동 업데이트는 켜져 있으면 10분마다 확인하고, 업데이트 뒤에는 Android가 허용하는 기기에서 Lucent가 스스로 다시 열리며, 허용하지 않으면 한 번 탭하면 열립니다. 클라우드 어시스턴트는 늘 그렇듯 백그라운드에서 계속 일하고, 찾아야 할 스위치는 없습니다. 저장소 루트도 정리해 문서는 docs로, 개인정보 처리방침은 전용 폴더로 옮겼습니다.
