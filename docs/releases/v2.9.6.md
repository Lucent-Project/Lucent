# The Notebooks Get a Long Press, and the Assistant Picks Its Depth

Lucent 2.9.6 is the release where a long press on a notebook does what a long press does everywhere else. The assistant, meanwhile, has stopped guessing how hard to think: it asks the provider, in that provider's own words, and lets you choose.

**A notebook now answers a long press the way a note does.** Press and hold a cover and the shelf goes into selection: a count appears, the notebooks you touch gather together, and the bar offers pinning, select-all, and the bin. Several books can be dragged as one stack, and the sort follows them to Custom as it always has. The lift shadow that used to sit under a dragged book is gone, so the cover travels flat. Pinning is new to notebooks as well: a pinned book keeps the front of the shelf whichever order you choose, and it can be pinned from the menu or from a selection.

**The assistant can be told how hard to think, in each vendor's own terms.** OpenAI endpoints take reasoning_effort, from off through minimal, low, medium and high. Claude takes extended thinking with a token budget. Gemini takes a thinking budget, including zero. A button beside the attachment clip in the chat offers exactly the levels the chosen provider publishes, and the choice is remembered per app rather than per message. Models whose public API has no such parameter say so instead of pretending, and a custom endpoint can still be sent reasoning_effort on the understanding that it may be ignored.

**One web-search switch, and ten engines behind it.** Web search now lives only in Personalisation, and beside it sits the engine: Bing, DuckDuckGo, Google, Brave, Yandex, Mojeek, Baidu, Sogou, 360 Search, Wikipedia, or Automatic, which tries them in turn — the Chinese engines first when the question is written in Chinese, the others first when it is not. The switch and the engine hide while the local model runs without agent mode, since nothing can use them then, and come back exactly as they were left.

**Memory is three sizes on the cloud and two on the local model.** The cloud assistant can remember across conversations, across the current one, or only the message in hand. The local model offers strong or weak: this conversation, or this message. Agent mode has moved to Personalisation, under typing haptics, and applies to whichever model is answering. The Assistant page now carries a switch beside the cloud model and another beside the local one, mutually exclusive, so choosing one turns the other off rather than freezing it.

Auto-update also checks every ten minutes while it is on, and after an update Lucent reopens itself where Android allows it and offers a tap where it does not. The cloud assistant keeps working in the background as it always has, with no switch to find. The repository root has been tidied at the same time: documentation lives in docs, the privacy policy in its own folder.
