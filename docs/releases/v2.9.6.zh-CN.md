# 笔记本学会了长按，助手开始自己选择思考深度

Lucent 2.9.6 让笔记本上的长按，终于和其它地方的长按一样好用。助手这边也不再自己揣测该想多深：它按各家服务商自己的说法去问，把选择权交给你。

**笔记本的长按，现在和笔记一样。** 按住封面，书架进入多选：出现计数，你点到的笔记本会聚在一起，操作栏提供置顶、全选和删除。多本书可以当作一摞一起拖动，排序照旧自动切到自定义。拖拽时原本压在书下的抬升阴影已经去掉，封面是平着移动的。置顶也是笔记本的新能力：无论你选哪种排序，置顶的书都停在书架最前面，可以从菜单置顶，也可以在多选里批量置顶。

**助手的思考深度，按每家服务商自己的说法来。** OpenAI 接口接受 reasoning_effort，从关闭到极低、低、中、高。Claude 用的是带预算的扩展思考。Gemini 用的是思考预算，可以设为零。聊天页回形针旁边的按钮，列出的正是当前服务商官方公布的档位，选择在软件内记住，而不是每条消息重设。公开 API 没有这个参数的服务商会如实说明，而不是假装有；自定义接口仍会按 best-effort 发送 reasoning_effort，并注明它可能被忽略。

**一个联网开关，后面站着十个引擎。** 网络搜索现在只放在个性化里，开关旁边就是引擎选择：Bing、DuckDuckGo、Google、Brave、Yandex、Mojeek、百度、搜狗、360 搜索、Wikipedia，以及“自动”——自动会依次尝试，问题用中文写就先试中文引擎，否则先试其它。当本地模型未开启 Agent 模式时，这个开关和引擎选择会一起隐藏，因为那时它们无处可用；条件解除后原样恢复。

**云端三档记忆，本地两档。** 云端助手可以记住跨对话、记住当前对话，或只回应手头这一条消息；本地模型提供强与弱：整段对话，或单条消息。Agent 模式已挪到个性化里、打字触感下面，对正在作答的那个模型生效。助手页在云端模型和本地模型右侧各放了一个开关，二者互斥——打开一个，另一个就关闭，而不是被冻结。

自动更新在开启状态下每十分钟检查一次；更新完成后，Android 允许的机型上 Lucent 会自己重新打开，不允许的则提供一点即开。云端助手一如既往在后台继续工作，没有开关需要你去找。仓库根目录也一并整理：文档进了 docs，隐私政策有了自己的目录。
