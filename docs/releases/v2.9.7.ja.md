# アシスタントは道具一式を借り、ようやく後片付けも覚える

Lucent 2.9.7 は小さな版ですが、三つの片付けを含んでいます。アシスタントの推論のつまみ、アシスタントの書式道具、そしてストレージに住み着いていたインストーラーの山です。

**推論は各社の言い方どおりに。** プロバイダーはそれぞれ思考の深さの一覧を公開していて、しかも互いに言い分が違います。Lucent はその一覧をきちんと読むようになりました。OpenAI はモデルが本当に受け付ける範囲で none、minimal、low、medium、high、xhigh、max を、Claude はアダプティブ思考で low から max を、Gemini 3 は思考レベルを、2.5 系は従来どおりトークン予算を使います。Kimi と DeepSeek は low、high、max と、提供されている場合はオフも選べます。公開 API にこのつまみがないモデルでは、選択肢は説明もなく単に現れません。モデルを切り替えると、新しいモデルが受け付ける段階だけが並びます。

**安くなる会話。** どのプロバイダーもプロンプトキャッシュを用意しており、Lucent はその命中を取りに行きます。決して変わらない部分——指示、ツール定義、それまでの会話——を先頭に、バイト単位で同じまま置き、動くもの（現在時刻、最近触ったもの、他の会話の記憶）は最後に回して接頭辞を壊さないようにしました。Claude のリクエストはツール、指示、最後のメッセージに明示的なキャッシュ区切りを付け、OpenAI と Kimi のリクエストは安定したキャッシュキーと公式のキャッシュ設定を添えます。プロバイダーがどれだけキャッシュから来たかを報告すれば、アシスタントの手順一覧に表示し、ログにも残します。

**考えるモデルの記憶が伸びました。** DeepSeek、Kimi、Claude は、ツールを使う会話では過去のターンの推論をそのまま返すよう求めており、その点に非常に厳格です。そうしたターンを保存して再送するようにしたので、ツールを長く使う会話でも流れが途切れず、毎回ゼロから始まりません。

**もっと豊かな書式道具。** アシスタントは太字と斜体だけでなく、五段階の文字サイズ、九色の文字色、八色のマーカーを扱え、指定した語句にも、メモ全体にも適用できます。どこが既に装飾されているかを知りたいときは、read_note_formatting が先に言葉で教えます。同じサイズと色はエディターのツールバーにもあるので、アシスタントが設定したものを、あとから手で直せます。

**ノートブックの説明。** read_notebook は表紙、固定、日付、収められているもの、そして同じメモやタスクが他にどのノートブックにも入っているかまで書き出します。update_notebook は名前変更、表紙の色替え、固定を一度にこなします。「このノートブックには何が入っている？」と聞けば、実際の答えが返ります。

**後片付け。** ダウンロードしたインストーラーは、腰を上げない客のようにストレージに居座っていました。Lucent は起動時に更新が実際に入ったかを確認し、入っていれば作業フォルダーからもコピー先のフォルダーからも削除します。Android でも Windows でも同じです。サイレントインストールが終わった瞬間にも同じ確認が走ります。

これまでのものはそのまま動きます。メモ、タスク、ノートブック、暗号化バックアップ、そしてあなたの言語で答えるアシスタントです。
