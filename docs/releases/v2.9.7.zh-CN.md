# 助手换上了一整套工具，也终于学会收拾自己的东西

Lucent 2.9.7 是个小版本，但里面收拾了三样东西：助手的推理档位、助手的排版工具，还有过去一直赖在你存储里的那几个安装包。

**推理档位，按每家自己的说法。** 各家服务商都会公布自己的思考深度列表，而且彼此口径并不一致。Lucent 现在会认真按这些列表来：OpenAI 在模型真正支持的范围内提供 none、minimal、low、medium、high、xhigh 与 max；Claude 使用自适应思考，档位从 low 到 max；Gemini 3 用思考档位，2.5 系列继续用 token 预算；Kimi 和 DeepSeek 用 low、high、max，可关闭的就提供关闭。如果某家官方根本没有公布这个参数，选择入口就直接不出现，而不是杵在那里解释一堆；切换模型时，看到的正是新模型支持的档位。

**更省钱的对话。** 各家都提供提示缓存，Lucent 如今会尽力去争取命中：请求里永不变化的部分——指令、工具定义、此前的对话——放在最前且逐字节一致，而会变的部分（当前时间、最近改动的东西、其它对话里的记忆）一律放到最后，免得破坏前缀。Claude 的请求在工具、指令和最后一条消息上都带上缓存断点；OpenAI 与 Kimi 的请求带上稳定的缓存键和官方文档里的缓存设置。服务商报告命中了多少缓存时，助手的步骤列表会写明，日志也会记下来。

**会思考的模型，记性更长了。** DeepSeek、Kimi 和 Claude 都要求：只要用上了工具，后续轮次必须把模型自己的推理原样交回，而且态度很坚决。这些轮次现在会被保存并在之后重新送出，因此一场长时间使用工具的对话能保持思路连贯，而不是每次从冷启动开始。

**更丰富的排版工具。** 助手原本就能把字变粗、变斜，现在还能设置五档字号、从九种文字颜色和八种荧光笔颜色里挑选，并且可以把这些应用到指定的词句，或者整篇笔记。它想先知道哪里已经设过样式时，read_note_formatting 会先用文字告诉它，再动手。同样的字号与颜色就在编辑器自己的工具栏里，助手设成什么样，你之后就能手动改成什么样。

**笔记本，说明白了。** read_notebook 现在会把一本笔记本完整讲清楚——封面色、是否置顶、创建与改动时间、里面有什么，以及这些笔记和任务还同时出现在哪些笔记本里；update_notebook 则一步完成改名、换封面和置顶。现在问助手“这本笔记本里有什么”，能得到真正的回答。

**收拾房间。** 下载下来的安装包过去会赖在你的存储里，像个不肯起身的客人。现在 Lucent 会在启动时检查更新是否真的装上了，如果装上了，就把安装包删掉——工作目录和复制到的目录都会清理——Android 和 Windows 都是如此。静默安装完成的那一刻也会执行同样的检查。

之前的一切照旧：笔记、任务、笔记本、加密备份，以及一个用你的语言回答的助手。
