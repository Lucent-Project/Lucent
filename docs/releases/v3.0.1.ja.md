# 道具箱に礼儀がつき、入力欄も整列した

Lucent 3.0.1 は片づけのリリースです。ノートの中身は何も動いておらず、メモとタスクの挙動も変わりません。作業場にきちんとした作業台と、ラベルの貼られた引き出しと、道具ごとの定位置を与えただけです。説明書を読まなくても見つけられます。

**道具箱に正面の扉ができました。** 設定 → 詳細設定に二つの入口があります。Shizuku と道具箱です。道具箱を開くと、いちばん上にスイッチが一つだけ。それが入るまで下の設定は邪魔をしません。入れると引き出しが現れます。新規インストールでは、頼まれるまで道具箱はオフのままです。刃物の部屋を案内する礼儀としては、それが正しいやり方です。

**引き出しにはラベルがあります。** ワークスペース、権限、ツールグループ、実行方法、GitHub、プラグイン、MCP サーバー、操作ログがそれぞれ独立したページになり、道具箱の下に並びました。パンくずは「設定 → 詳細設定 → 道具箱 → プラグイン」と読みます。以前の並びより、ずっと口に出しやすい。

**ワークスペースは指差すだけ。** フォルダー欄は手書きのパスを求めなくなり、見本のパスも引退しました。ボタンを一つ押すとファイルマネージャーが開き、フォルダーを選べばパスが入ります。保存を押すまで何も書き込まれず、押すと画面下に静かに「保存しました」と出ます。

**ヘルパーと、その仕事を読む場所。** assistant がサブエージェントを呼ぶと、会話の上に一覧が出ます。名前、何をしているか、終わったかどうか。タップすれば、タスク、手順、結果まで全部読めます。レポートの保存は手動です。ボタンを押すとワークスペースの sub-agents フォルダーに Markdown ファイルとして書き出され、同じく静かに確認が出ます。

**トークンは口が堅い。** GitHub のアクセストークンはパスワード欄になりました。入力中は点だけが表示され、保存後は二度と表示されません。最大五つまで、それぞれ名前を付けられます（鉛筆で改名）。タップすれば assistant が使うトークンを選べます。保存は他のものと同じく暗号化されています。

**Shizuku は丁寧に差し出します。** Android では、assistant に Shizuku 経由のコマンド実行を許すかどうかは独立したスイッチで、既定はオフです。オンにすれば assistant はその権限を使えると知らされ、オフのままならシェルは箱の中にいます。

**一直線の入力欄。** チャット画面では添付ボタンが入力欄から離れ、送信ボタンが反対側に収まり、入力欄がその間を存分に使います。モデル選択は欄の内側、マイクと拡大ボタンの隣へ移り、大きさも揃いました。新規会話と会話の消去は入れ替わりました。最初からそこにいるべき場所です。

**モデルメニューの並べ直し。** モデルボタンを押すと、説教なしの二行だけ。上はモデルと、その下に現在の名前。下は推論の深さと、現在の設定。長い名前は省略記号で締め、版面を押し広げません。検索欄はリストの最上部に固定され、スクロールしても付いてきません。モデル探しは探す作業ではなく、打ち込む作業になりました。戻る矢印は所属するタイトルと揃い、パネルは画面中央にゆったり収まります。右の壁にもたれる必要はもうありません。

**Termux は列の先頭。** プラグインページは Termux 自身から始まります。公式ページへ行くダウンロードボタン付きです。本物のターミナルこそ、コマンドが最後に欲しがるものですから。

**スクロールが滑らかに。** 道具箱のページは作業場全体を一列に詰め込まなくなり、スクロール中は背景のアニメーションが静止します。ページはページらしく動きます。
