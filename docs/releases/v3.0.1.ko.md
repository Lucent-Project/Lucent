# 도구함이 예절을 배우고, 입력줄이 정렬되었습니다

Lucent 3.0.1은 정리하는 릴리스입니다. 노트 안의 내용은 하나도 움직이지 않았고 메모와 할 일의 동작도 그대로입니다. 작업실에 제대로 된 작업대와 라벨 붙은 서랍, 도구마다 제자리를 준 것뿐입니다. 설명서를 읽지 않아도 찾을 수 있습니다.

**도구함에 정문이 생겼습니다.** 설정 → 고급에 두 개의 문이 있습니다. Shizuku와 도구함입니다. 도구함을 열면 맨 위에 스위치 하나만 있습니다. 그 스위치를 켜기 전까지 아래 설정은 조용히 물러나 있고, 켜면 서랍이 나타납니다. 새로 설치하면 요청하기 전까지 도구함은 꺼져 있습니다. 날카로운 도구가 가득한 방을 소개하는 예절로는 그것이 맞습니다.

**서랍마다 이름표가 있습니다.** 작업 공간, 권한, 도구 그룹, 실행 방식, GitHub, 플러그인, MCP 서버, 작업 기록이 각각 독립된 페이지가 되어 도구함 아래에 정리되었습니다. 경로 표시는 이제 '설정 → 고급 → 도구함 → 플러그인'으로 읽힙니다. 예전보다 훨씬 말하기 쉽습니다.

**작업 공간은 가리키기만 하면 됩니다.** 폴더 칸은 더 이상 경로를 직접 쓰라고 요구하지 않으며, 예시 경로도 은퇴했습니다. 버튼 하나로 파일 관리자가 열리고, 폴더를 고르면 경로가 들어갑니다. 저장을 누르기 전에는 아무것도 기록되지 않고, 누르면 화면 아래에 조용히 '저장됨'이 나타납니다.

**도우미와, 그들의 작업을 읽는 자리.** assistant가 하위 에이전트를 부르면 대화 위에 목록이 생깁니다. 이름, 하는 일, 끝났는지 여부까지. 눌러 들어가면 작업, 단계, 결과를 모두 읽을 수 있습니다. 보고서 저장은 직접 하는 일입니다. 버튼을 누르면 작업 공간의 sub-agents 폴더에 Markdown 파일로 기록되고, 같은 방식으로 조용히 확인됩니다.

**토큰은 입이 무겁습니다.** GitHub 액세스 토큰은 이제 비밀번호 칸입니다. 입력할 때는 점만 보이고, 저장한 뒤에는 다시 표시되지 않습니다. 최대 다섯 개까지 각자 이름을 붙일 수 있고(연필로 이름 바꾸기), 눌러서 assistant가 쓸 토큰을 고를 수 있습니다. 저장 방식은 다른 것과 마찬가지로 암호화입니다.

**Shizuku는 정중하게 내밉니다.** Android에서 assistant가 Shizuku를 통해 명령을 실행하도록 허용할지는 별도의 스위치이며 기본값은 꺼짐입니다. 켜면 assistant는 그 권한을 쓸 수 있다는 것을 분명히 알고, 끄면 셸은 상자 안에 있습니다.

**한 줄로 정렬된 입력줄.** 채팅 화면에서 첨부 버튼은 입력 상자에서 물러났고, 보내기 버튼은 반대편에 자리했으며, 입력 상자는 그 사이를 넉넉히 씁니다. 모델 선택은 상자 안으로 들어가 마이크, 확대 버튼과 나란히 섰고 크기도 같아졌습니다. 새 대화와 대화 비우기는 자리를 바꿨습니다. 처음부터 있어야 할 자리였습니다.

**모델 메뉴 정리.** 모델 버튼을 누르면 설교 없이 두 줄만 나옵니다. 위는 모델과 그 아래 현재 이름, 아래는 추론 깊이와 현재 설정. 긴 이름은 말줄임표로 끝맺어 판면을 밀어내지 않습니다. 검색창은 목록 맨 위에 고정되어 스크롤해도 따라가지 않습니다. 모델 찾기는 뒤지는 일이 아니라 입력하는 일이 되었습니다. 뒤로 화살표는 자기 제목과 정렬되고, 패널은 화면 가운데에서 넉넉한 너비로 앉습니다. 오른쪽 벽에 기대지 않아도 됩니다.

**Termux는 줄의 맨 앞.** 플러그인 페이지는 Termux 자신으로 시작합니다. 공식 페이지로 가는 다운로드 버튼도 함께. 진짜 터미널이야말로 명령이 마지막에 원하는 것입니다.

**스크롤이 매끄럽게.** 도구함 페이지는 더 이상 작업실 전체를 한 줄에 밀어 넣지 않고, 스크롤하는 동안 배경 애니메이션이 멈춰 섭니다. 페이지는 페이지답게 움직입니다.
