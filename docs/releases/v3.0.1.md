# The Toolkit Learns Its Manners, and the Composer Lines Up

Lucent 3.0.1 is a tidying-up release. Nothing you keep in the notebook has moved; this is the workshop being given a proper bench, labelled drawers, and a place for every tool.

**The toolkit has a front door.** Settings → Advanced now holds two doors of its own: Shizuku, and the Toolkit. The Toolkit opens with a single switch at the top. Until it is on, the rest of the page stays out of the way. A fresh install leaves the toolkit off until you ask for it, which is the polite way to introduce a room full of sharp tools.

**Every drawer has a label.** The workspace, permissions, tool groups, execution, GitHub, plugins, MCP servers and the activity log have each been given a page of their own, filed under the toolkit. The breadcrumb now reads Settings → Advanced → Toolkit → Plugins.

**Choosing a workspace is a matter of pointing at it.** The folder field no longer expects a path composed by hand, and the specimen paths have retired. One button opens the file manager, you pick a folder, and the path appears. Nothing is written down until you press Save, and a quiet "Saved" appears at the bottom of the screen.

**Helpers, and a place to read their work.** When the assistant calls for sub-agents, a strip appears above the conversation listing them by name, what they are doing and whether they have finished. Tap one to read the task, the steps and the result. Saving the report is a deliberate act: press the button and it is written as a Markdown file in the workspace's sub-agents folder.

**Tokens that keep to themselves.** GitHub access tokens are now password fields: they are shown as dots when typed and never displayed again once saved. You may keep up to five, each with a name of your own — tap the pencil to rename — and tap a token to choose which one the assistant uses. They are stored encrypted, like everything else.

**Shizuku, offered politely.** On Android, giving the assistant permission to run commands through Shizuku is a switch of its own, off by default. Turn it on and the assistant is told, plainly, that it may use that reach; leave it off and the shell stays in its box.

**A composer with straight lines.** In the chat screen the attach button has moved clear of the input box, the send button sits opposite it, and the input box takes all the room in between. The model picker has moved inside the box, beside the microphone and the expand button, where it is the same size as its neighbours. New conversation and clear conversation have swapped places, which is where they wanted to be all along.

**The model menu, rearranged.** Tapping the model button now offers two rows and no lecture: the model, with the current one written underneath, and the reasoner's depth, with its current setting underneath. Long names are shortened with an ellipsis rather than shoving the furniture about. A search box sits at the top of the model list and stays there while the list scrolls. The back arrow now lines up with its title, and the panel sits centred at a comfortable width instead of leaning against the right-hand wall.

**Termux, first in the queue.** The plugins page begins with Termux itself, with a download button that takes you to the official page, because a real terminal is the thing most commands end up wanting.

**Smoother to scroll.** The toolkit pages no longer carry the whole workshop in one scrolling column, and the animated background holds still while you scroll.
