# 工具箱学会了规矩，输入栏也排齐了

Lucent 3.0.1 是一次收拾整理。笔记本里的东西一件没动，笔记与任务的行为也没有变化——这一版只是给工作间配了一张合适的台面、贴好标签的抽屉，让每件工具都有归处，不必翻说明书也能找到。

**工具箱有了正门。** 设置 → 高级里现在有两个入口：Shizuku 与工具箱。工具箱打开后最上方只有一个开关，开关没打开时，下面的一切都不打扰你；打开之后抽屉才会出现。全新安装默认保持关闭，这是介绍一屋子锋利工具时该有的礼貌。

**每个抽屉都有标签。** 工作区、权限、工具分组、执行方式、GitHub、插件、MCP 服务器与操作记录各自成页，统一归在工具箱之下。面包屑现在写的是「设置 → 高级 → 工具箱 → 插件」，比从前那一串好念得多。

**选工作区只需指一下。** 文件夹一栏不再要求你手写路径，示例路径也已经退休。按一个按钮唤起文件管理器，选一个文件夹，路径就会填好。在你按下保存之前什么都不会写入，保存后屏幕底部会安静地显示「已保存」。

**帮手，以及读他们工作的地方。** 助手召唤子代理时，对话上方会出现一条列表，写清他们的名字、正在做什么、是否完成。点进去可以看到全过程：任务、步骤与结果。保存报告是一件需要你亲自做的事：按下按钮，它会写成 Markdown 文件放进工作区的 sub-agents 文件夹，同样有安静的确认。

**令牌守口如瓶。** GitHub 访问令牌现在是密码栏：输入时只显示圆点，保存之后不再回显。最多可以保存五个，每个都能自定义名称（点铅笔即可重命名），点一下就能指定助手使用哪一个。它们和别的东西一样，加密保存。

**Shizuku，礼貌地提供。** 在安卓上，「给予助手 Shizuku 权限」是一个独立开关，默认关闭。打开后助手会明确知道自己可以使用这份权限；不打开，终端就老老实实待在盒子里。

**排齐了的输入栏。** 聊天页的附件按钮挪开，不再压到输入框；发送按钮在另一侧相对而立，输入框在中间尽情伸展。模型选择挪进框内，与麦克风、放大输入框并排，大小一致。新建对话与清空对话换了位置——它们本来就该待在那里。

**模型菜单重新摆放。** 点开模型按钮后只有两行，没有说教：上面是模型，下方小字写着当前用的是哪一个；下面是推理程度，同样注明当前档位。名字太长就用省略号收尾，不会把版面顶开。搜索栏固定在模型列表最上方，滑动查找时它不跟着走，找模型靠打字而不是翻找。返回箭头终于与它所属的标题对齐，整个面板居中显示、宽度舒适，不再贴着右边墙壁。

**Termux 排在最前。** 插件页以 Termux 本身开头，提供前往官方页面的下载按钮——真正的终端，往往是命令最后想要的东西。

**滑动更顺。** 工具箱页面不再把整个工作间塞进一列滚动内容；滚动时动态背景会静止下来，页面因此走得像页面该有的样子。
