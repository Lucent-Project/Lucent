# 道具箱は同じ説明を繰り返さず、選択画面はディスク全体を歩く

Lucent 3.0.2 は控えめな番号ですが、手は長く伸びています。道具箱はすっきりした形になり、フォルダー選択はディスク全体を歩けるようになり、プラグインの流れはダウンロードの層から組み直され、harness は手本にしている DeepSeek Harness に追いつきました。ノートの中身は何も動いていません。

**静かになった正面の扉。** 設定 → 詳細設定 → 道具箱を開くと、そこにあるのはスイッチだけです。上に置かれていた説明は、本当に必要な場所へ移りました。道具箱の各ページが、いちばん上に自分のブロックで説明から始まります。説明は、それが属する設定の隣に座ります。サブエージェント、スナップショット、端末操作、画面アクセスには専用のページ「アシスタントの機能」ができ、「ワークスペース」と「権限」の間に並びました。もともと探しに行く場所です。

**ディスク全体を歩く選択画面。** ワークスペースのフォルダー選びは、システムのフォルダーダイアログではなくアプリ内のブラウザーになりました。ホームと各ドライブのルートはワンタップ、「..」で一つ上へ、パス自体はタップして編集、隠しファイルの表示も、新しいフォルダーの作成もその場で——Android でも Windows でも同じです。共有ストレージしか見なかった旧ダイアログは引退し、シェルが届くフォルダーならどこでも指させるようになりました。

**呼吸を続ける背景。** 指を画面に置いても、動く背景はそのまま流れます。スクロールに合わせて止まる連動は引退しました。リストをドラッグしても波は進み、色はその場に留まります。

**自分のしていることを話すプラグインの流れ。** シェルがまだ無くてもダウンロードは行われ、ワークスペースに置かれるので Termux と Shizuku が読めます。展開する場所がまだ無いスマートフォンでも、先に荷物だけ受け取れます。各手順は自分で報告します。気にかけてほしいときは、ダイアログが理由を書き、シェル自身の出力をそのまま見せ、直すべきことを並べます。Termux を入れる、termux-setup-storage を実行する、外部アプリを許可する、すべてのファイルへのアクセスを与える、先に Linux 環境を入れる、別のミラーを試す、あるいはもう一度試す。Ubuntu ルートファイルシステムの導入はきちんと検証され、Windows では winget に本物の確認を添えて進み、ミラーは本当に落とすものがあるときだけ登場します。

**手本にした harness との揃え。** `read_image` で assistant は画像を実際に見られ、結果には `[exit code: N]` が付くので結末を推し量る必要はありません。読み取りは書き込みの前に記録されます。`web_search` は一度にいくつも問いを投げられます。操作ログは何を尋ね、何を決めたかを書き残します。サンドボックスの昇格は理由を添えて一度だけ認められます。保存された記憶とスキルの目録はシステムプロンプトに書き込まれ、assistant はそこで実際に出会います。`ask_user` は本物のダイアログを伴ってデスクトップにも届き、承認ダイアログは Windows でも描かれ、ターンを止めればそのターンが始めたバックグラウンド作業とサブエージェントも止まり、いま進めている会話は再起動を越えてそのまま残ります。

バージョンは 3.0.2、3.0.1 から百分の一だけ進んだ、当店流の言い方をするなら「小さな一歩を、きちんと」。
