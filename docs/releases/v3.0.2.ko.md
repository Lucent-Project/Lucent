# 도구함은 같은 설명을 반복하지 않고, 선택 화면은 디스크 전체를 걷습니다

Lucent 3.0.2는 작은 번호지만 팔은 길게 뻗습니다. 도구함은 더 산뜻한 모양이 되었고, 폴더 선택 화면은 디스크 전체를 걷는 법을 배웠고, 플러그인 흐름은 다운로드 층부터 다시 세워졌고, harness는 본보기로 삼은 DeepSeek Harness를 따라잡았습니다. 노트 안의 내용은 하나도 움직이지 않았습니다.

**조용해진 정문.** 설정 → 고급 → 도구함을 열면 이제 스위치 하나만 있습니다. 위에 서 있던 설명은 정말 필요한 곳으로 옮겼습니다. 도구함의 각 하위 페이지가 맨 위에서 자기 블록으로 설명을 시작합니다. 설명은 그것이 속한 설정 옆에 앉습니다. 하위 에이전트, 스냅숏, 기기 제어, 화면 접근은 전용 페이지인 '어시스턴트 기능'을 얻어 '작업 공간'과 '권한' 사이에 놓였습니다. 원래 찾아가게 되는 자리입니다.

**디스크 전체를 걷는 선택 화면.** 작업 공간 폴더를 고를 때는 이제 시스템 폴더 대화상자 대신 앱 안의 브라우저를 씁니다. 홈과 각 드라이브 루트는 한 번의 탭, '..'은 한 단계 위로, 경로 자체는 눌러서 편집, 숨은 파일 표시도, 새 폴더 만들기도 그 자리에서 — Android와 Windows가 똑같습니다. 공유 저장소만 보던 예전 대화상자는 은퇴했고, 셸이 닿는 폴더라면 어디든 가리킬 수 있습니다.

**계속 숨 쉬는 배경.** 손가락을 화면에 올려도 움직이는 배경은 그대로 흐릅니다. 스크롤에 맞춰 멈추던 연동은 은퇴했습니다. 목록을 끌어도 물결은 나아가고 색은 제자리에 머뭅니다.

**무엇을 하는지 말해 주는 플러그인 흐름.** 셸이 아직 없어도 다운로드는 이루어지고 작업 공간에 놓여 Termux와 Shizuku가 읽을 수 있습니다. 풀어 놓을 곳이 아직 없는 휴대폰도 짐부터 받아 둘 수 있습니다. 각 단계는 스스로 보고합니다. 주의가 필요할 때 대화상자는 이유를 적고, 셸 자체의 출력을 그대로 보여 주며, 손볼 것을 나열합니다. Termux 설치, termux-setup-storage 실행, 외부 앱 허용, 모든 파일 접근 권한 부여, Linux 환경 먼저 설치, 다른 미러 시도, 아니면 그냥 다시 시도. Ubuntu 루트 파일 시스템 설치는 제대로 검증되고, Windows 설치에는 winget과 진짜 확인 절차가 따르며, 미러는 실제로 받을 것이 있을 때만 등장합니다.

**본보기 harness와의 정렬.** `read_image`로 assistant는 그림을 직접 보고, 결과에는 `[exit code: N]`이 붙어 끝을 짐작할 일이 없습니다. 읽기는 쓰기 전에 기록됩니다. `web_search`는 한 번에 여러 질문을 던집니다. 작업 기록은 무엇을 물었고 무엇을 정했는지 적어 둡니다. 샌드박스 승격은 이유와 함께 단 한 번 허용됩니다. 저장된 기억과 스킬 목록은 시스템 프롬프트에 적혀 assistant가 거기서 실제로 만납니다. `ask_user`는 진짜 대화상자를 갖고 데스크톱에도 닿고, 승인 대화상자는 Windows에서도 그려지며, 턴을 멈추면 그 턴이 시작한 백그라운드 작업과 하위 에이전트도 멈추고, 진행 중인 대화는 재시작을 넘어 그대로 남습니다.

버전은 3.0.2, 3.0.1에서 100분의 1만큼 올라간, 이 집 식으로 말하자면 '작은 걸음을 제대로'.
