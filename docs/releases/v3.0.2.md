# The Toolkit Stops Repeating Itself, and the Picker Walks the Whole Disk

Lucent 3.0.2 is a modest number with a long reach. The toolkit has been given a tidier shape, the folder picker has learned to walk the whole disk, the plugin pipeline has been rebuilt from the download upwards, and the harness has caught up with the DeepSeek Harness it takes after. Nothing you keep in the notebook has moved.

**A quieter front door.** Settings → Advanced → Toolkit now opens with the switch and nothing else. The explanation that lived above it has moved to where it is wanted: every toolkit sub-page opens with its own block at the top, so the reading sits beside the setting it belongs to. Sub-agents, snapshots, device control and screen access have a page of their own — Assistant abilities, filed between Workspace and Permissions — which is where you would look for them anyway.

**A picker that walks the whole disk.** Choosing the workspace folder is now an in-app browser rather than the system folder dialog. Home and every drive root are one tap away, ".." climbs a level, the path itself is tap-to-edit, hidden files can be shown, and new folders can be made on the spot — on Android and Windows alike. The storage-only picker has retired, and any folder the shell can reach is now a folder you can point at.

**A background that keeps breathing.** The animated background carries on beneath your finger. The pause-on-scroll coupling has been retired, so the waves keep moving and the colours stay where they were while a list is dragged.

**A plugin pipeline that says what it is doing.** Downloads now happen even when no shell is ready, and land in the workspace where Termux and Shizuku can read them, so a phone can fetch its payload before it has anywhere to unpack it. Every step reports for itself. When something wants your attention, the dialog names the reason, shows the shell's own output, and lists what to put right: install Termux, run termux-setup-storage, allow external apps, grant all-files access, install the Linux userland first, try another mirror, or simply retry. The Ubuntu rootfs install is verified properly, Windows installs go through winget with real probes, and a mirror is consulted only when there is something to download.

**Parity with the harness it takes after.** `read_image` lets the assistant look at a picture, and results carry their `[exit code: N]` so a command's ending is never a guess. Reads are observed before writes. `web_search` takes several queries at once. The activity log records what was asked and what was decided. A sandbox escalation can be justified once, and only once. Saved memory and the skill catalogue are written into the system prompt, where the assistant will actually meet them. `ask_user` reaches the desktop with a real dialog, the approval dialog renders on Windows, stopping a turn also stops the background jobs and sub-agents that turn set going, and the conversation you are in survives a restart.

The version is 3.0.2, one hundredth up from 3.0.1, which is the house way of saying: a small step, taken properly.
