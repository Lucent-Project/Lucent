# 工具箱不再重复自己，选择器走遍整块磁盘

Lucent 3.0.2 是一个不大的版本号，手却伸得很长。工具箱换了更清爽的形状，文件夹选择器学会了走遍整块磁盘，插件流水线从下载那一层重新搭起，harness 也追上了它所效仿的 DeepSeek Harness。笔记本里的东西一件没动。

**更安静的正门。** 设置 → 高级 → 工具箱打开后，就只剩那个开关。原先立在开关上方的说明搬到了真正需要它的地方：每个工具箱子页面都在顶部用自己的板块开篇，于是说明与它所属的设置待在一起。子助手、快照、设备控制与屏幕访问有了自己的页面——助手能力，排在「工作区」与「权限」之间，本来也是你会去找它们的位置。

**走遍整块磁盘的选择器。** 选工作区文件夹现在用的是应用内的浏览器，不再是系统文件夹对话框。主目录与每个盘符根目录只需一点，「..」负责上一级，路径本身可点击编辑，隐藏文件可以显示，新文件夹可以当场建好——安卓与 Windows 都一样。只会翻共享存储的旧选择器已经退休，shell 够得着的文件夹，现在你都指得出来。

**继续呼吸的背景。** 手指放在屏幕上时，动态背景照常流动。随滚动暂停的联动已经退休：拖动列表时，波浪继续走，颜色留在原处。

**会交代自己在做什么的插件流水线。** 即使还没有可用的 shell，下载也会照常进行，并落在工作区里，Termux 与 Shizuku 都能读到——手机在还没有地方解包之前，就能先把东西取回来。每一步都会自己汇报。需要你留意时，对话框会写明原因、原样给出 shell 的输出，并列出要补的课：安装 Termux、运行 termux-setup-storage、允许外部应用、授予所有文件访问、先装 Linux 环境、换一个镜像，或者干脆重试一次。Ubuntu 根文件系统的安装会得到正经校验，Windows 上的安装走 winget 并带真实探测，镜像只在确实有东西要下载时才出场。

**与它所效仿的 harness 对齐。** `read_image` 让助手能亲眼看图，命令结果带着 `[exit code: N]`，结局从不靠猜。读取先于写入被记录。`web_search` 一次可以问好几个问题。操作记录写下被问了什么、决定了什么。沙箱提权可以给出理由，且只此一次。保存的记忆与技能目录会写进系统提示词，助手在那里才真正遇得见它们。`ask_user` 来到桌面端，带一个真正的对话框；审批对话框在 Windows 上也能画出来；停止一轮对话时，这一轮派出的后台任务与子助手一并停下；你正在进行的对话，重启之后还在原处。

版本号是 3.0.2，比 3.0.1 多出百分之一，用本店的话说：一小步，走得规矩。
