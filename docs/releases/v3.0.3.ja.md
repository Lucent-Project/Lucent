# チャット画面は二つから一つへ、選択画面は上へ戻れるようになりました

Lucent 3.0.3 は、席に案内する前に机の上を片づけるような版です。assistant の画面は二重に存在するのをやめ、会話には様子を伝える手段がいくつか増え、小さな引っかかりは退場しました。すでにお使いのものは、何も動いていません。

**ついに一つのチャット画面。** Android と Windows の assistant 画面は約 89% 同じところまで育っていました。同じ意欲的な設計者が仕上げた二つの部屋のようなものです。共通の本体は一か所、`shared/src/main/kotlin/com/lucent/app/ui/AssistantChatBody.kt` に置かれ、各プラットフォームには薄い外側だけが残ります。Android は 270 行、Windows は 196 行。カメラ、ファイル選択、ストレージへの保存という、本当に違う部分だけを担います。これからのチャット改良は、一度書けば済みます。

**返事らしく整う返事。** assistant の返信は Markdown——見出し、リスト、コード——として描画されます。生のテキストで届くことはもうありません。ストリーミング中の文字は素のままで、一字ずつ現れるリズムはそのまま、ちらつきもありません。

**折りたためる思考ブロック。** モデルの思考は専用の折りたたみブロックに収まり、既定では閉じています。気になるときはそこにあり、そうでないときは静かにしています。

**すべてのツールに時計。** トレースの各呼び出しが、所要時間をミリ秒または秒で報告します。承認に使った時間は数えません。人を待つのは道具の落ち度ではないからです。

**ターンを越えて残る ToDo リスト。** assistant は会話ごとに `todo_write` のリスト——保留、進行中、完了——を保てます。一つずつではなく丸ごと差し替え、暗号化して保存し、次のターンにも残ります。`todo_read` が呼び戻します。

**チャット上部の三つのパネル。** ToDo／計画パネル、各ジョブを停止できるバックグラウンドジョブパネル、そして助っ人の仕事をリアルタイムで見せ、停止も追加指示もできるサブエージェントパネル。走っているジョブと助っ人の数は小さなカウンターチップが示すので、「何か動いているか」はいつでも目に入ります。

**メッセージを受け取る助っ人。** 新しい `list_agents`、`send_message`、`interrupt` により、assistant はサブエージェントに話しかけられます。受信箱は助っ人の次のラウンドで読まれるので、指示を一つ足すために仕事をやり直す必要はありません。

**上へ戻れる選択画面。** ワークスペースのパス行はパンくずになりました。ホーム、親フォルダー、ドライブのルートをタップすれば、そこへ直行です。入力した相対パスは、アプリが前回いた場所ではなく、いま画面に映っているフォルダーを基準に解決されます。

**止められるダウンロード。** プラグインのダウンロードやインストール中は、ボタンが「停止」になります。中止すると途中のファイルは削除され、その旨が告げられ、いつもの再試行も用意されます。

**小さなことも、きちんと。** モデル検索欄はプレースホルダーを切り取らなくなり、切り替えがモデルだけに触れるという但し書きは雑音として引退し、設定で切ったシェルは本当に実行されません。

バージョンは 3.0.3、3.0.2 から百分の一だけ進んだ、当店流の言い方なら「小さな一歩を、きちんと」。
