# One Chat Screen Instead of Two, and the Picker Walks Back Up

Lucent 3.0.3 is the sort of release that tidies the desk before inviting anybody to sit at it. The assistant screen has stopped existing twice, the conversation has gained several new ways of keeping you informed, and a few small annoyances have been shown the door. Nothing you already keep has moved.

**One chat screen, at last.** The Android and Windows copies of the assistant screen had grown to be about 89% identical — two rooms furnished by the same enthusiastic decorator. The shared body now lives once, in `shared/src/main/kotlin/com/lucent/app/ui/AssistantChatBody.kt`, and each platform keeps a thin wrapper — 270 lines on Android, 196 on Windows — for the parts that genuinely differ: the camera, the file pickers and saving to storage. Every chat improvement from here on lands once, in one place.

**Replies that read like replies.** Assistant replies now render Markdown — headings, lists and code — rather than arriving as raw text. The streaming text stays plain while it types itself out, so the reveal loop keeps its steady rhythm and nothing flickers.

**A reasoning block you can fold away.** The model's thinking sits in its own collapsible block, closed until you ask for it. It is there when you are curious, and out of the way when you are not.

**A clock on every tool.** Each call in the trace reports how long it took, in milliseconds or seconds. The time you spend approving a call is not counted, since waiting for a human is not the tool's fault.

**A todo list that survives the turn.** The assistant can keep a per-conversation `todo_write` list — pending, active, done — replaced wholesale rather than nibbled at item by item, stored encrypted, and still there next turn. `todo_read` brings it back.

**Three panels in the chat header.** A todo/plan panel, a background-jobs panel where each job can be stopped, and a sub-agent panel that shows a helper's work live, lets you stop it, and lets you send it an extra instruction. A compact counter chip reports how many jobs and helpers are running, so the answer to "is anything happening?" is always in sight.

**Helpers that take messages.** New `list_agents`, `send_message` and `interrupt` tools let the assistant talk to its sub-agents. An inbox is read at the helper's next round, so an added instruction arrives without the whole job being restarted.

**A picker with a way back up.** The workspace path line is now a breadcrumb trail: tap Home, a parent folder or a drive root and you are there. A typed relative path is resolved against the folder on screen rather than against wherever the app last stood.

**A download you can stop.** While a plugin download or install runs, the button becomes Stop. Cancelling removes the partial file, says so, and offers the usual retry.

**Small things, properly done.** The model search box no longer clips its placeholder text, the note about the switcher touching only the model has been retired as noise, and a shell switched off in Settings is now genuinely not run.

The version is 3.0.3, one hundredth up from 3.0.2, which is the house way of saying: a small step, taken properly.
