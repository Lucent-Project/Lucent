# 一块聊天屏取代两块，选择器学会了往回走

Lucent 3.0.3 属于那种先把桌面收拾干净、再请你入座的版本。助手界面不再一式两份，对话多了几种照看你的方式，几处小小的别扭也被请出了门。你已经收着的东西，一件没动。

**终于只剩一块聊天屏。** 安卓与 Windows 的助手界面已经长到约 89% 相同——像同一位热情设计师布置的两个房间。共用主体如今只留一份，放在 `shared/src/main/kotlin/com/lucent/app/ui/AssistantChatBody.kt`，各平台只保留一层薄外壳——安卓 270 行，Windows 196 行——负责真正不同的部分：相机、文件选择与保存到存储。往后的每一次聊天改进，只需落在一个地方。

**会像回话一样排版的回话。** 助手的回复现在渲染 Markdown——标题、列表与代码——不再以原始文本送达。流式输出的文字保持纯文本，逐字显现的节奏不受影响，也不会闪。

**可以折起来的思考块。** 模型的思考待在自己的折叠块里，默认收起。你想看时它在，不想看时它安静。

**每次工具调用都带一块表。** 轨迹里的每一步都会说明自己花了多久，毫秒或秒。你审批所用的时间不计入——等人不算工具的错。

**跨轮存活的任务清单。** 助手可以为每段对话维护一份 `todo_write` 清单——待办、进行、完成——整体替换而不是逐条挪动，加密保存，下一轮还在。`todo_read` 负责把它取回来。

**聊天头部里的三块面板。** 任务/计划面板；后台任务面板，每个任务都能停；子助手面板，实时展示帮手的进展，可以叫停，也可以补一句话给它。一枚紧凑的计数标签显示正在运行的任务与帮手数量，于是「现在有事情在跑吗」随时看得见。

**收得到消息的帮手。** 新增 `list_agents`、`send_message` 与 `interrupt` 三个工具，助手可以和自己的子助手对话。收件箱在帮手下一轮开工时读取，于是补上的指示不必把整件事重开一遍。

**能往回走的选择器。** 工作区路径那一行现在是面包屑：点主目录、上一级文件夹或盘符根目录，说到就到。手输的相对路径会以当前屏幕上的文件夹为基准解析，而不是应用上次站的地方。

**停得下来的下载。** 插件下载或安装进行时，按钮变成「停止」。取消会删掉半截文件，明确告知，并照例再问你要不要试一次。

**小事也做规矩。** 模型搜索框不再截断占位文字；「切换器只管模型」那句说明作为噪音已经退休；在设置里关掉的 shell，现在是真的不会运行。

版本号是 3.0.3，比 3.0.2 多出百分之一，用本店的话说：一小步，走得规矩。
