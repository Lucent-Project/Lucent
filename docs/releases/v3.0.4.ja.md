# 助手が持ち歩ける目標を手にし、自分のファイルも荷造りする

Lucent 3.0.4 は、ポケットがやけに深い小さな版です。assistant は目標を預かって最後まで取り組み、その自分のファイルはバックアップと一緒に旅をし、周辺の細かいところは誰も見ていないうちに静かに整えられました。すでにお使いのものは、何も動いていません。

**助手が持ち歩ける目標。** 新しい三つのツール——`create_goal`、`get_goal`、`update_goal`——により、assistant はこの会話のための目標を引き受け、取り組み続けられます。目標は会話ごとに一つ、ラウンド上限はお好みで。既定は八回、最大で五十回です。更新のたびに読み取った時点のリビジョンを添えるので、古い変更は新しい知らせを上書きせず、丁寧に断られます。編集、一時停止、再開、完了、そして理由つきの「行き詰まり」がそろい、同じ妨げは三ラウンド続けて報告されて初めて受け入れられます——assistant に確かめてほしい、という丁重な頼み方です。目標は端末上で暗号化して保存されます。ターンが終わっても目標が動いていれば次のラウンドはひとりでに始まり、目標が完了・一時停止・行き詰まりになった瞬間、あるいは停止を押した瞬間に止まります。チャット上部には目標チップと目標パネルが並び、目標はシステムプロンプトにも書き込まれるので、assistant は常に何に向かっているかを知っています。

**助手自身のファイルもバックアップを旅します。** 新しい「アシスタントデータ」バックアップモジュールが、ToDo、記憶、スキル、スナップショット、動作ログ、目標という assistant の家財を書き出しと復元に載せます。専用の行とチェックボックスつきです。以前の版で取ったバックアップは、これまでどおりそのまま復元できます。

**ワークスペースはどのフォルダーでも、端末のルートでも。** 「/」や「C:\」には何も入っていないと見なしていたパス接頭辞の判定を直したので、ルートに置いたワークスペースもきちんと動きます。フォルダーを選ぶとその場で適用・保存され、二度目の確認を待つ必要はありません。

**Gemini の返信が戻りました。** Google の API は、配列パラメーターが中身を明示していないツール定義を受け付けず、ツールを含むリクエストは HTTP 400 で止まっていました。配列パラメーターが中身を宣言するようになり、Google のモデルでも assistant は普段どおり答えます。

**整ったチャット上部。** ToDo、ジョブ、サブエージェント、目標のチップは、この行の他のボタンと同じ丸いすりガラスになり、件数は小さな角のバッジで示されます。サブエージェントを有効にすると、助っ人が名前でこの行に並び、タップするとその助っ人自身のページが開きます。ライブの記録、ラウンド、結果、停止、そして実行中に一言足す場所です。

**自分と揃った入力欄。** 添付ボタンは送信ボタンと同じすりガラスを、同じ大きさで、同じ行にまとっています。

**背景をまとったスプラッシュ。** スプラッシュ画面は最初のフレームから動く背景と配色を描きます。単色で始まらないので、アプリはすでに装いを整えて現れます。

**小さなことも、きちんと。** モデル検索欄は高さが半分になり、文字は中央に収まって切れません。README は変更の並びではなく製品全体を語るようになり、謝辞はサードパーティ通知ファイルが挙げるすべての構成要素——必要に応じて取得するものまで——に名前を添えました。

バージョンは 3.0.4、3.0.3 から百分の一だけ進んだ、同じ小さな一歩を、より良い荷物で。
