# The Assistant Gets a Goal to Carry, and Its Own Files Pack Themselves

Lucent 3.0.4 is a small version with unusually deep pockets. The assistant can be handed a goal and left to see it through, its own files now travel inside your backups, and a quiet tidy of details has happened around the edges while nobody was looking. Nothing you already keep has moved.

**A goal the assistant can carry.** Three new tools — `create_goal`, `get_goal` and `update_goal` — let the assistant take an objective for this conversation and keep working at it. One goal per conversation, with a round limit of your choosing: eight by default, fifty at the very outside. Every update quotes the revision it was read at, so a stale change is declined rather than allowed to overwrite fresher news. Edit, pause, resume, complete and blocked-with-a-reason are all present, and a blocker has to be reported in three rounds running before it is accepted, which is a courteous way of asking the assistant to be sure. The goal is persisted encrypted on your device. When a turn finishes and the goal is still active, the next round starts by itself, and stops the moment the goal is complete, paused or blocked, or you press stop. A goal chip and a goal panel sit in the chat header, and the goal is written into the system prompt, so the assistant always knows what it is working towards.

**The assistant's own files travel in backups.** A new "Assistant data" backup module carries the harness home — todos, memory, skills, snapshots, the activity log and goals — through export and restore, with its own line and its own tick box. Backups made by earlier versions restore exactly as they always did.

**The workspace can be any folder, including the root of the device.** A path-prefix check that had concluded "/" and "C:\" contained nothing has been put right, so a workspace at the root works properly. Choosing a folder now applies and saves it on the spot instead of waiting for a second confirmation.

**Gemini replies work again.** Google's API turns away a tool definition whose array parameter does not say what sits inside it, which stopped every tool-bearing request at HTTP 400. Array parameters now declare their contents, and the assistant answers normally with Google models.

**A tidier chat header.** The todo, jobs, sub-agent and goal chips are now the same round frosted buttons as the rest of the row, with their counts as small corner badges. When sub-agents are enabled, the helpers appear by name in that row, and tapping one opens that helper's own page: live transcript, rounds, result, stop, and somewhere to add an instruction while it runs.

**A composer that matches itself.** The attachment button carries the same frosted glass as the send button, at the same size, on the same line.

**A splash with a background.** The splash screen paints the animated backdrop and palette from its first frame rather than a flat colour, so the app arrives already dressed.

**Smaller things.** The model search box is half its old height, with its text nicely centred and uncropped. The README now describes the whole product rather than a series of changes, and its thanks section names every third-party component the notices file credits, including the ones fetched on request.

The version is 3.0.4, one hundredth up from 3.0.3: the same small step, taken with better luggage.
