# 助手有了可以扛着走的目标，它自己的文件也学会了打包

Lucent 3.0.4 是一个口袋格外深的小版本。助手可以接过一个目标并一路做下去；它自己的文件如今也随备份一起旅行；边角上的一批细节则在没人注意时被安静地收拾妥当。你已经收着的东西，一件没动。

**助手可以扛着走的目标。** 三个新工具——`create_goal`、`get_goal` 与 `update_goal`——让助手为这段对话接过一个目标，并持续为之工作。每段对话一个目标，轮数上限由你决定：默认八轮，最多五十轮。每次修改都会带上它读取时的修订号，于是过期的改动会被婉拒，而不会盖掉更新的消息。编辑、暂停、继续、完成、以及带原因报「受阻」一应俱全；同一个阻碍要连续三轮报告才会被接受——这是请助手先确定一下的客气说法。目标在本机加密保存。一轮结束时目标仍在进行，下一轮就自己开始；目标一旦完成、暂停、受阻，或你按下停止，它便立刻停下。聊天头部多了一枚目标标签和一块目标面板，目标还会写进系统提示词，于是助手始终清楚自己正朝着什么努力。

**助手自己的文件也随备份旅行。** 新增的「助手数据」备份模块把助手的家当——待办、记忆、技能、快照、活动日志与目标——一并纳入导出与还原，有自己的条目，也有自己的勾选框。旧版本做出的备份，还原起来与从前一模一样。

**工作区可以是任何文件夹，包括设备根目录。** 一处曾认定「/」和「C:\」里面什么都没有的路径前缀检查已经修正，根目录下的工作区如今运作正常。选定文件夹现在当场生效并保存，不必再等第二次确认。

**Gemini 的回复恢复了。** Google 的接口会退回数组参数没有说明其内容的工具定义，于是所有带工具定义的请求都止步于 HTTP 400。数组参数现在会声明自己装的是什么，助手用 Google 模型也能正常作答。

**更整齐的聊天头部。** 待办、后台任务、子助手与目标标签，如今都换成了这一行里其它按钮同款的圆形磨砂样式，数量以小角标呈现。开启子助手后，帮手会以名字出现在这一行，点开就是那位帮手自己的页面：实时转录、轮次、结果、停止，以及运行中补一句话的地方。

**自己和自己对得上的输入栏。** 附件按钮用上了与发送按钮相同的磨砂玻璃，同样大小，同一行上。

**自带背景的启动画面。** 启动画面从第一帧就画出动态背景与配色，而不是先铺一块纯色，于是应用一登场就已经穿戴整齐。

**小事也做规矩。** 模型搜索框高度减半，文字居中且不再被裁。README 现在描述的是整个产品，而不是一串改动；致谢部分也把第三方声明文件里列出的每个组件都点了名，包括那些按需获取的。

版本号是 3.0.4，比 3.0.3 多出百分之一：同样的一小步，行李收拾得更好了。
