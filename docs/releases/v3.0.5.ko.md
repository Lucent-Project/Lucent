# 도구함은 뛰기 전에 살피고, Termux는 정식으로 소개받다

Lucent 3.0.5는 작은 릴리스지만 담은 생각은 큽니다. 플러그인 설치가 믿음의 도약이어서는 안 된다는 것. 이제 도구함은 한 바이트도 받기 전에 모든 플러그인을 점검하고, 무엇이 가로막고 있는지 정확히 알려 주며, 치우는 방법까지 설명합니다. 당신의 언어로, 늘 그렇듯 담담하게.

**막무가내로 뛰지 말고, 출발 전에 점검을.** 모든 설치는 점검부터 시작합니다. 어시스턴트에 새 도구 `plugin_inspect`가 생겼고, 플러그인 설정 화면도 설치 버튼을 내밀기 전에 같은 점검을 합니다. 가로막는 것이 있다면——이 기기용 설치 방법이 없음, 받을 곳이 없음, 미러가 전부 무응답, 폴더에 쓸 수 없음, Termux가 임시 파일을 읽을 수 없음, 쓸 만한 셸 자체가 없음——실패하고 어깨를 으쓱하는 대신, 미리 이유와 구체적인 해결 단계를 보여 줍니다. 문제마다 고유 번호가 있어 어시스턴트와 설정 화면은 언제나 같은 상황을 같은 말로 설명합니다.

**Termux, 정식으로 소개합니다.** Android에서 설치가 실패하는 일의 대부분은, 실은 Termux 소개가 한 번도 이루어지지 않았기 때문이었습니다. 이제 Lucent는 설치하기 전에 Termux 패키지 목록을 작업마다 한 번씩 새로고침합니다. 그 유명한 "unable to locate package" 미스터리는 이로써 은퇴합니다. 셸 자체가 없을 때의 안내도 마침내 구체적입니다. F-Droid에서 Termux를 설치하고, 한 번 열고, `termux-setup-storage`를 실행하고, `~/.termux/termux.properties`에 `allow-external-apps=true`를 설정하고, Android가 물으면 명령 실행 권한을 허용하세요. Termux가 전혀 응답하지 않으면, 일부 파생판은 패키지 이름이 다르다는 점도 알려 줍니다. 밤을 구하는 건 이런 세부 사항입니다.

**기억하는 다운로드.** 선택한 가장 빠른 미러가 이제 정말로 사용됩니다——예전에는 설정만 저장되고 정중히 무시됐습니다. 다운로드가 중단돼도 임시 파일이 멀쩡하면 다음번에 재사용하고 다시 받지 않습니다. 작은 기록이 각 설치가 어디까지 갔는지 적어 두니, 재시도는 처음부터가 아니라 이어서 시작합니다. 미러가 공시와 다른 크기의 파일을 보내면, 미러가 이미지를 새로 올렸을 수도 있다고 알려 주고 다른 곳을 가리킵니다.

**설명하는 어시스턴트.** `install_plugin` 도구는 먼저 점검하고, 중간에 실패하는 대신 이유를 들어 사양합니다. 진행 표시는 첫 바이트부터 나오고, 20%를 기다리지 않습니다. Termux가 패키지를 찾지 못하면 패키지 목록이 오래됐을 거라고 설명합니다——이제 Lucent가 자동으로 새로고침한다는 말과 함께.

**조용한 기록.** 작업 로그는 디스크에 쓰기 전에 비밀 키처럼 생긴 값과 URL에 박힌 인증 정보를 지웁니다. 누구에게도 읽힐 일이 없던 것은 앞으로도 읽히지 않습니다.

Lucent의 모습은 조금도 달라지지 않았습니다. 도구함이 사용 설명서를 읽은 것처럼 행동하게 됐을 뿐입니다.
