# The Toolbox Looks Before It Leaps, and Termux Gets a Proper Introduction

Lucent 3.0.5 is a small release with one large idea: installing a plugin should never be a leap of faith. The toolbox now inspects every plugin before it downloads a single byte, reports exactly what stands in the way, and tells you how to move it — in your own language, with the same dry patience throughout.

**A preflight check, not a blind leap.** Every install now begins with an inspection. The assistant has a new tool, `plugin_inspect`, and the Plugins settings page runs the same check before offering the install button. If something blocks the way — no install script for this platform, no download source, every mirror silent, a folder that cannot be written, a staged file Termux could never read, or no working shell at all — the check says so up front, with a short list of concrete repair steps instead of a failed download and a shrug. Each problem carries a stable code, so the assistant and the settings screen always describe the same situation in the same words.

**Termux, introduced properly.** On Android, most plugin failures were really Termux introductions that never happened. Lucent now refreshes Termux's package list once per session before installing anything, which retires the classic "unable to locate package" mystery. And when the shell is missing entirely, the guidance is finally specific: install Termux from F-Droid, open it once, run `termux-setup-storage`, set `allow-external-apps=true` in `~/.termux/termux.properties`, and grant the run-command permission when Android asks. If Termux never answers at all, the error now mentions that some forks ship under different package names — the sort of detail that saves an evening.

**Downloads that remember.** The fastest mirror you picked is now actually the one used — previously the preference was stored and then politely ignored. If a download was interrupted, the next attempt reuses the staged file instead of fetching it again, provided it is intact. A small journal keeps notes on where each install got to, so a retry resumes the story rather than restarting it. And when a mirror sends a file of a different size than advertised, the message now suggests the mirror may simply have refreshed its image, and points at another source.

**The assistant explains itself.** The `install_plugin` tool runs the preflight check first and declines with reasons rather than failing halfway through. Progress notes appear from the first byte instead of waiting for twenty percent. When a Termux package cannot be found, the hint explains the package list was probably stale — and that Lucent refreshes it automatically now.

**Quieter logs.** The activity log now redacts secret-shaped values and credentials embedded in URLs before anything is written to disk. What was never meant to be read by anyone keeps it that way.

Nothing about Lucent's look has changed; the toolbox simply behaves as though it has read the manual.
