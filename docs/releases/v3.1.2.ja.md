# 14言語、軽量になったビルド、そして遅延のお詫び

Lucent 3.1.2 は予定より時間がかかってしまいました。まずそのことについて正直にお話しします。3.0.5 から今日までの間、アプリは過去最大の内部再構築を経ました。共有コードベース全体が Kotlin Multiplatform に移行し、ウェブサイトは14言語に拡大し、プロジェクトは新しい GitHub オーガニゼーションに移転しました。これらはあなたの問題ではありませんが、待ち時間が3週間に延びた理由はここにあります。お待たせして申し訳ありませんでした——このリリースがその答えです。

**14言語。** Lucent は14言語を話すようになりました。英語、簡体字・繁体字中国語、スペイン語、アラビア語、ポルトガル語、フランス語、ロシア語、ドイツ語、日本語、トルコ語、韓国語、イタリア語、オランダ語です。言語ピッカーは4.5件分を表示するので、リストがスクロールできることが一目瞭然。アラビア語は正しい右から左レイアウトになり、フォント設定は言語リストの上の独立したカードに移動しました。

**軽量になった Windows ビルド。** JDK モジュールの削減により、デスクトップインストーラは約 86 MB に——100 MB をゆうゆう下回りました。ダウンロードが速く、占有容量も少なく、大事なものは何も削っていません。

**ちゃんと更新されるアップデーター。** 恥ずかしいアップデーターのバグを2件修正しました。プレビュービルドはビルド ID が R000000000000 と表示され、alpha ラベルも消えていました。検証ルールが古い ID 形式を想定したままだったためです。さらに悪いことに、新形式のビルド ID は検証にまったく通らず、アップデーターは "3.1.2" と "3.1.2" を比較して「新着なし」と結論づけていました——自動更新は静かに死んでいたのです。両方修正済みです。安定版はウェブサイトのミラーを経由して更新されるようになり、GitHub がフォールバックになります。

**鮮度を保つ検索。** 自動ではなく特定の検索エンジンを使うと、結果が古くなることがありました。キャッシュされたインスタント回答がフォールバックチェーンを塞ぎ、昨日のウェブを見せられていたのです。今はフォールバックが必ず実行され、新鮮な結果が届きます。

**成長したサブアシスタント。** サブアシスタントはメインチャットと完全に対等になりました。常時有効な入力欄、会話の再開、推論の可視化、会話ごとの番号付け、パンくずナビ、再設計されたツリーポップアップ。思考ステップはデフォルトで折りたたまれ、画面はすっきりです。

**より良いターミナルとブラウザ。** ターミナルは真の PTY になり、複数タブ、キーバー、フォントサイズ調整を備え、adb も同梱。リンクは組み込みブラウザで開き、Lucent の最近のタスクに残ります。メッセージのテキスト（URL 含む）は選択してコピーできます。

**滑らかなナビゲーション。** ホームでのスワイプはノートブックへ直行、ページャーは4ページ、タスクとノートはドロワーのみ、スワイプ方向も自然な感覚に戻りました。ポップアップとダイアログは新しいゼリーガラス風のビジュアルです。

**パスワード付きバックアップ。** 自動バックアップを自分のパスワードで暗号化できるようになり、セキュリティ質問が回復手段になります。

**自分で説明するプラグインインストール。** 地域別のミラーを使い、中断されたパッケージ状態から回復し、キャンセル理由を正確に報告し、既存ツールの再インストールをスキップし、ライブで出力を流します。環境の準備が必要なときはガイド付きセットアップウィザード付きです。

**そして細かな改善。** アシスタントチャットで引用コンテキスト付きのスワイプ返信、連続送信と中断点からの再開、DeepSeek の推論に文字通りの "null" が出なくなり、「このアプリについて」のサポートリンクがあなたの言語で正しいページを開き、ウェブサイトの変更履歴は 1.0.0 以降の全リリースを各言語のノート付きでカバーするようになりました。
