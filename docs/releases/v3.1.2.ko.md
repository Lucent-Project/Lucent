# 열네 가지 언어, 가벼워진 빌드, 그리고 늦어진 사과

Lucent 3.1.2는 예상보다 오래 걸렸습니다. 다른 이야기 전에, 이에 대해 솔직히 말씀드려야겠습니다. 3.0.5부터 오늘까지 앱은 역대 최대 규모의 내부 재구축을 거쳤습니다. 공유 코드베이스 전체가 Kotlin Multiplatform으로 이전되었고, 웹사이트는 열네 가지 언어로 늘어났으며, 프로젝트는 새로운 GitHub 조직으로 이전했습니다. 이 모든 것이 당신의 문제는 아니지만, 기다림이 3주로 늘어난 이유가 바로 여기 있습니다. 기다려 주셔서 감사합니다. 이 릴리스가 그 보답입니다.

**열네 가지 언어.** Lucent는 이제 열네 가지 언어를 구사합니다. 영어, 간체·번체 중국어, 스페인어, 아랍어, 포르투갈어, 프랑스어, 러시아어, 독일어, 일본어, 터키어, 한국어, 이탈리아어, 네덜란드어입니다. 언어 선택기는 한 번에 네 개 반 항목을 보여줘 목록이 스크롤됨을 알 수 있고, 아랍어는 올바른 오른쪽에서 왼쪽 레이아웃을 갖추었으며, 글꼴 설정은 언어 목록 위의 독립 카드로 이동했습니다.

**가벼워진 Windows 빌드.** JDK 모듈 축소 덕분에 데스크톱 설치 프로그램이 약 86MB로 줄었습니다. 100MB 선을 여유 있게 밑돕니다. 다운로드가 빨라지고 차지하는 공간도 줄어들었으며, 중요한 것은 아무것도 빠지지 않았습니다.

**제대로 업데이트되는 업데이터.** 부끄러운 업데이터 버그 두 건을 수정했습니다. 미리보기 빌드는 빌드 ID가 R000000000000으로 표시되고 알파 라벨을 잃었는데, 검증 규칙이 여전히 이전 ID 형식을 기대했기 때문입니다. 더 심각한 것은 새 형식의 빌드 ID가 검증을 전혀 통과하지 못해, 업데이터가 "3.1.2"와 "3.1.2"를 비교하고 "새 소식 없음"이라는 결론을 내렸다는 점입니다. 자동 업데이트가 조용히 죽어 있었던 것입니다. 둘 다 수정되었고, 안정 릴리스는 이제 웹사이트 미러를 통해 업데이트되며 GitHub이 백업으로 대기합니다.

**신선함을 유지하는 검색.** 자동 모드 대신 특정 검색 엔진을 사용하면 결과가 stale해질 수 있었습니다. 캐시된 인스턴트 답변이 폴백 체인을 막아 어제의 웹을 보게 했던 것입니다. 이제 폴백 체인은 항상 실행되어 신선한 결과가 전달됩니다.

**성장한 서브 어시스턴트.** 서브 어시스턴트는 이제 메인 채팅과 완전히 동등합니다. 항상 활성화된 입력창, 대화 이어하기, 보이는 추론 과정, 대화별 번호 매기기, 브레드크럼 탐색, 재설계된 트리 팝업까지. 사고 단계는 기본적으로 접혀 화면이 깔끔합니다.

**더 나은 터미널과 브라우저.** 터미널은 이제 진짜 PTY입니다. 다중 탭, 키 바, 글꼴 크기 조절을 갖추고 adb가 내장됩니다. 링크는 Lucent의 최근 작업에 남는 내장 브라우저에서 열리며, 메시지 텍스트(URL 포함)를 선택해 복사할 수 있습니다.

**부드러워진 탐색.** 홈에서 스와이프하면 노트북으로 바로 이동하고, 페이저는 네 페이지, 할 일과 메모는 서랍에만 있으며, 스와이프 방향도 다시 자연스러워졌습니다. 팝업과 대화상자는 새로운 젤리 글라스 비주얼 스타일을 사용합니다.

**비밀번호가 있는 백업.** 자동 백업을 이제 자신의 비밀번호로 암호화할 수 있고, 보안 질문이 복구 수단이 됩니다.

**스스로 설명하는 플러그인 설치.** 지역별 미러를 사용하고, 중단된 패키지 상태에서 복구하며, 취소 사유를 정확히 보고하고, 이미 있는 도구의 재설치를 건너뛰고, 출력을 실시간으로 보여줍니다. 환경 준비가 필요할 때는 단계별 설정 마법사가 함께합니다.

**그리고 작은 것들.** 어시스턴트 채팅에서 인용 컨텍스트와 함께하는 스와이프 답장, 중단 지점에서 이어지는 연속 전송, DeepSeek 추론에 더 이상 문자 그대로의 "null"이 나타나지 않음, 정보 페이지의 지원 링크가 사용자의 언어로 올바른 페이지를 열, 웹사이트 변경 로그가 1.0.0 이후 모든 릴리스를 각 언어 노트와 함께 다룹니다.
