# Fourteen Languages, a Leaner Build, and an Apology for the Wait

Lucent 3.1.2 took longer than it should have, and I owe you an honest word about that before anything else. Between 3.0.5 and today, the app went through its biggest internal rebuild yet: the entire shared codebase was migrated to Kotlin Multiplatform, the website grew to fourteen languages, and the project moved under a new GitHub organisation. None of that is your problem, but it is the reason the wait stretched to three weeks. Thank you for your patience — this release is the payoff.

**Fourteen languages.** Lucent now speaks fourteen languages: English, Simplified and Traditional Chinese, Spanish, Arabic, Portuguese, French, Russian, German, Japanese, Turkish, Korean, Italian, and Dutch. The language picker shows four and a half entries at a time so it is obvious the list scrolls, Arabic gets a proper right-to-left layout, and font settings now live in their own card above the language list.

**A leaner Windows build.** The desktop installer is down to about 86 MB — comfortably under the 100 MB mark — thanks to JDK module stripping. It downloads faster and takes up less room, with nothing removed that matters.

**Updates that actually update.** Two embarrassing updater bugs are fixed. Preview builds were showing a build ID of R000000000000 and missing their alpha label, because a validation rule still expected the old ID format. Worse, the new-format build IDs failed validation entirely, so the updater fell back to comparing "3.1.2" with "3.1.2" and concluded there was nothing new — auto-update was silently dead. Both are fixed, and stable releases now update through the website mirror with GitHub as a fallback.

**Search that stays fresh.** If you use a specific search engine instead of Auto, results could go stale: a cached instant answer would block the fallback chain and leave you with yesterday's web. The fallback now runs regardless, so fresh results come through.

**Sub-assistants, grown up.** Sub-assistants now have full chat parity — an always-enabled composer, conversation resumption, visible reasoning, per-conversation numbering, breadcrumb navigation, and a redesigned tree popup. Thinking steps collapse by default to keep the view tidy.

**A better terminal and browser.** The terminal is now a real PTY with multiple tabs, a key bar, and font size controls, and adb ships bundled. Links open in an embedded browser that stays in Lucent's recent tasks, and message text — URLs included — can be selected and copied.

**Smoother navigation.** A Home swipe goes straight to Notebooks, the pager is four pages, Tasks and Notes are drawer-only, and swipe directions feel natural again. Popups and dialogs use the new jelly-glass visual style.

**Backups with passwords.** Auto-backups can now be encrypted with your own passwords, with a security question as a recovery path.

**Plugin installs that explain themselves.** Installs use region-aware mirrors, recover interrupted package states, report accurate cancellation reasons, skip reinstalling tools you already have, and stream live output — with a guided setup wizard when the environment needs preparing.

**And the smaller things.** Swipe-to-reply with quoted context in assistant chat, continuous send with breakpoint resume, DeepSeek reasoning no longer showing literal "null" chunks, the About page's Support link opening the right page in your language, and the website changelog now covering every release since 1.0.0 with per-language notes.
