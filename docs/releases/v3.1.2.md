# Fourteen Languages, a Leaner Build, and an Apology for the Wait

Lucent 3.1.2 took longer than it should have, and I owe you an honest explanation before anything else. Between 3.0.5 and today, the app underwent its largest internal rebuild yet: we migrated the entire shared codebase to Kotlin Multiplatform, expanded the website to fourteen languages, and moved the project under a new GitHub organisation. None of that plumbing is your problem, of course, but it is the reason a routine wait stretched into three weeks. Thank you for sticking around — this release is the payoff.

**Fourteen languages.** Lucent now feels at home in fourteen languages: English, Simplified and Traditional Chinese, Spanish, Arabic, Portuguese, French, Russian, German, Japanese, Turkish, Korean, Italian, and Dutch. Small touches make the transition seamless: the language picker frames exactly four and a half entries so you immediately know the list scrolls, Arabic receives a true right-to-left layout, and font settings now sit in their own dedicated card right above the language list.

**A leaner Windows build.** By stripping unused JDK modules, we trimmed the Windows desktop installer down to roughly 86 MB — comfortably below the 100 MB mark. It downloads faster and leaves a lighter footprint on your drive, without sacrificing a single feature that matters.

**Updates that actually update.** We tracked down and fixed two embarrassing updater bugs. First, an outdated validation rule still expected our legacy ID format, causing preview builds to display a placeholder R000000000000 build ID and drop their alpha label. Worse, because the new build IDs failed validation entirely, the updater fell back to comparing the version string "3.1.2" against "3.1.2", concluded nothing had changed, and silently killed auto-updates. Both issues are resolved, and stable releases now pull updates through our website mirror with GitHub standing by as a fallback.

**Search that stays fresh.** Previously, choosing a specific search engine instead of Auto could leave you with stale results: a cached instant answer would halt the fallback chain and serve up yesterday's web. The fallback sequence now runs regardless of cached hits, ensuring fresh results always make it through.

**Sub-assistants, grown up.** Sub-assistants have reached full parity with main chats. They now feature an always-active composer, seamless conversation resumption, visible reasoning, per-conversation numbering, breadcrumb navigation, and a redesigned tree popup. To keep the workspace tidy, thinking steps collapse by default.

**A better terminal and browser.** The terminal has graduated to a true PTY complete with multiple tabs, a dedicated key bar, font-size controls, and a bundled copy of adb. Web links now open inside an embedded browser that stays anchored within Lucent's recent tasks, and message text — URLs included — can be freely selected and copied.

**Smoother navigation.** Getting around the app feels natural again. Swiping from Home takes you straight to Notebooks across a streamlined four-page pager, while Tasks and Notes tuck neatly into the navigation drawer and swipe directions respond the way your thumb expects. Across the app, popups and dialogs now wear our new jelly-glass visual style.

**Backups with passwords.** You can now lock your auto-backups behind custom password encryption, backed by a security question so you always have a way back in.

**Plugin installs that explain themselves.** The plugin installer now routes through region-aware mirrors, recovers cleanly from interrupted package states, reports accurate cancellation reasons, skips reinstalling tools you already have, and streams live console output — complete with a guided setup wizard whenever your environment needs preparing first.

**And the smaller things.** Assistant chats now support swipe-to-reply with quoted context and continuous sending with breakpoint resume. DeepSeek reasoning streams cleanly without literal "null" chunks, the About page's Support link routes directly to the right page for your language, and the website changelog now archives every release all the way back to 1.0.0 with fully localized notes.
