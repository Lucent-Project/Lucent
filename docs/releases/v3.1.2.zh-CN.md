# 十四种语言、更精简的构建，以及一声迟到的道歉

Lucent 3.1.2 来得比预期晚，在说别的之前，我先诚恳地解释一下。从 3.0.5 到今天，应用经历了史上最大的一次内部重构：整个共享代码库迁移到了 Kotlin Multiplatform，网站扩展到了十四种语言，项目也搬到了新的 GitHub 组织下。这些都不是你该操心的事，但等待被拉长到三周，原因就在这里。感谢你的耐心——这个版本就是回报。

**十四种语言。** Lucent 现在会说十四种语言：英语、简体中文、繁体中文、西班牙语、阿拉伯语、葡萄牙语、法语、俄语、德语、日语、土耳其语、韩语、意大利语和荷兰语。语言选择器一次显示四个半选项，一眼就能看出列表可以滚动；阿拉伯语有了真正的从右到左布局；字体设置也搬到了语言列表上方独立的卡片里。

**更精简的 Windows 构建。** 得益于 JDK 模块裁剪，桌面安装包缩小到了约 86 MB——轻松低于 100 MB 线。下载更快，占空间更小，该有的一个不少。

**真正能更新的更新器。** 修了两个让人脸红的更新器 bug。预览版曾显示构建号 R000000000000，还丢了 alpha 标签，因为一条校验规则还停留在旧的编号格式。更糟的是，新格式的构建号根本通不过校验，更新器只好退回去比较 "3.1.2" 和 "3.1.2"，得出"没有新版本"的结论——自动更新就这么悄无声息地死了。两个都修好了，正式版更新现在走网站镜像，GitHub 作为备用。

**搜索保持新鲜。** 如果你用的是指定的搜索引擎而不是自动模式，结果可能会"馊"：一条缓存的即时答案会堵住备用链路，让你看到的是昨天的网页。现在备用链路一定会跑，新鲜结果畅通无阻。

**子助手长大了。** 子助手现在和主聊天完全看齐——输入框常开、会话可恢复、推理过程可见、按会话编号、面包屑导航，还有重新设计的树形弹窗。思考步骤默认折叠，界面清清爽爽。

**更好的终端和浏览器。** 终端现在是真正的 PTY，多标签、按键栏、字号调节，adb 直接内置。链接在内嵌浏览器中打开，会留在 Lucent 的最近任务里；消息文本（含网址）可以选中复制。

**更顺手的导航。** 主页滑动直达笔记本，页面减到四页，任务和笔记只从抽屉进，滑动方向也恢复了自然的手感。弹窗和对话框换上了新的果冻玻璃视觉风格。

**带密码的备份。** 自动备份现在可以用你自己的密码加密，还可以用密保问题找回。

**会解释自己的插件安装。** 安装会用按地区优选的镜像源，能从中断的包管理状态中恢复，会如实报告取消原因，已有的工具不再重复安装，全程实时输出日志——环境需要准备时还有分步向导。

**还有这些小事。** 助手聊天的滑动引用回复、连续发送与断点续发、DeepSeek 推理不再冒出字面 "null"、关于页面的"支持"链接会按你的语言打开正确的页面，网站更新日志也已覆盖从 1.0.0 起的每一个版本，并提供多语言版本。
