# 十四種語言、更精簡的構建，以及一聲遲到的道歉

Lucent 3.1.2 來得比預期晚，在說別的之前，我先誠懇地解釋一下。從 3.0.5 到今天，應用經歷了史上最大的一次內部重構：整個共享代碼庫遷移到了 Kotlin Multiplatform，網站擴展到了十四種語言，項目也搬到了新的 GitHub 組織下。這些都不是你該操心的事，但等待被拉長到三週，原因就在這裡。感謝你的耐心——這個版本就是回報。

**十四種語言。** Lucent 現在會說十四種語言：英語、簡體中文、繁體中文、西班牙語、阿拉伯語、葡萄牙語、法語、俄語、德語、日語、土耳其語、韓語、意大利語和荷蘭語。語言選擇器一次顯示四個半選項，一眼就能看出列表可以滾動；阿拉伯語有了真正的從右到左佈局；字體設置也搬到了語言列表上方獨立的卡片裡。

**更精簡的 Windows 構建。** 得益於 JDK 模塊裁剪，桌面安裝包縮小到了約 86 MB——輕鬆低於 100 MB 線。下載更快，佔空間更小，該有的一個不少。

**真正能更新的更新器。** 修了兩個讓人臉紅的更新器 bug。預覽版曾顯示構建號 R000000000000，還丟了 alpha 標籤，因為一條校驗規則還停留在舊的編號格式。更糟的是，新格式的構建號根本通不過校驗，更新器只好退回去比較 "3.1.2" 和 "3.1.2"，得出"沒有新版本"的結論——自動更新就這麼悄無聲息地死了。兩個都修好了，正式版更新現在走網站鏡像，GitHub 作為備用。

**搜索保持新鮮。** 如果你用的是指定的搜索引擎而不是自動模式，結果可能會"餿"：一條緩存的即時答案會堵住備用鏈路，讓你看到的是昨天的網頁。現在備用鏈路一定會跑，新鮮結果暢通無阻。

**子助手長大了。** 子助手現在和主聊天完全看齊——輸入框常開、會話可恢復、推理過程可見、按會話編號、麵包屑導航，還有重新設計的樹形彈窗。思考步驟默認摺疊，界面清清爽爽。

**更好的終端和瀏覽器。** 終端現在是真正的 PTY，多標籤、按鍵欄、字號調節，adb 直接內置。鏈接在內嵌瀏覽器中打開，會留在 Lucent 的最近任務裡；消息文本（含網址）可以選中複製。

**更順手的導航。** 主頁滑動直達筆記本，頁面減到四頁，任務和筆記只從抽屜進，滑動方向也恢復了自然的手感。彈窗和對話框換上了新的果凍玻璃視覺風格。

**帶密碼的備份。** 自動備份現在可以用你自己的密碼加密，還可以用密保問題找回。

**會解釋自己的插件安裝。** 安裝會用按地區優選的鏡像源，能從中斷的包管理狀態中恢復，會如實報告取消原因，已有的工具不再重複安裝，全程實時輸出日誌——環境需要準備時還有分步嚮導。

**還有這些小事。** 助手聊天的滑動引用回覆、連續發送與斷點續發、DeepSeek 推理不再冒出字面 "null"、關於頁面的"支持"鏈接會按你的語言打開正確的頁面，網站更新日誌也已覆蓋從 1.0.0 起的每一個版本，並提供多語言版本。
